# 日経-3.38%の急落と防御ルール — 債券ETFで4課題同時解決を検討

## 総資産94.9万円、含み損-4.8%

総資産は948,573円で、前回（3/13）の955,453円から約6,900円減少しました。初回100万円からは-5.14%の水準です。3月18日のFOMC金利据置決定で年内利下げ観測が後退し、中東情勢の緊迫化も重なって、日経平均は53,372円（前日比-3.38%）と大幅に下落しました。

## 失速63%でも全銘柄200MA上方を維持

モメンタム分析では、保有比率63.45%にあたる3銘柄（1475・1489・1615）が「失速」ステージにあります。前回の65.6%からわずかに改善したものの、短期的な下方バイアスが続いています。

一方で、5銘柄全てが200日移動平均を上回っており、構造的な下降転換には至っていません。2558は「反転上昇」、1540は「上昇減速」の判定です。全銘柄の200MA乖離率はプラスを維持しているため、テクニカル防御レベルは引き続き「攻撃モード」となっています。

## シャープレシオ3.30 — 分散効果の構造は健在

ポートフォリオ全体のシャープレシオは3.30で、前回の3.45からやや低下しました。個別SR加重平均の1.29に対して大きく上回っており、銘柄間の低相関による分散効果が引き続き機能しています。

特に1540（金ETF）と2558（S&P500）の相関係数0.032がポートフォリオの効率性を支える構造は変わっていません。ただし、データ点数13点（約1年分）での算出であり、信頼度は「中」です。

## 新しい一挙四得 — 短期債券ETFの追加

前回の「現金→2558段階投入」に代わり、今回のマージ会議では**短期債券ETF（デュレーション2-3年）の新規追加**が新たな一挙四得戦略として合意されました。現金5-8万円で1銘柄追加するだけで、以下の4課題を同時に改善できるとされています。

1. **ショック耐性の向上**: 55.9点 → 60点程度へ
2. **国内株式集中の緩和**: 低相関アセットの追加
3. **債券ゼロの解消**: 現在の最大の構造的欠落を埋める
4. **現金比率の適正化**: 20.6% → 15%程度へ

年間コストは39-62円程度の増加にとどまり、SR改善+0.05、VaR改善-0.2%が見込まれています。売買を伴わない新規購入のみのため、税コストはゼロです。

## 1615の出来高枯渇が深刻化

1615（東証銀行業ETF）の出来高レシオが前回0.50から0.46にさらに低下し、「枯渇」判定が継続しています。含み損も-14.2%と大きく、3会議全てで撤退条件の明確化が提案されました。

具体的には、200MA乖離率+10%割れ・ATR 524.16円割れ・出来高レシオ0.30割れ2週間継続のいずれかでポジション半分縮小というルールです。現時点では200MA乖離率+18.14%と余裕がありますが、出来高の細りは流動性リスクの顕在化として注視が必要です。
