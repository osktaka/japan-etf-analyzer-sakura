# タグ付けルール

## 概要

ETF銘柄に対して投資判断の観点でタグを付与するシステム。6カテゴリ43タグで構成される。

## タグカテゴリと付与基準

### 業種（sector）- 9タグ - 青系

| タグ名 | 付与基準 |
|--------|----------|
| 金融 | 銀行、証券、保険、その他金融セクターに連動 |
| テクノロジー | IT、電機、精密機器セクターに連動 |
| ヘルスケア | 医薬品、医療機器、バイオテクノロジーに連動 |
| エネルギー | 石油・ガス、エネルギー資源セクターに連動 |
| 素材 | 化学、鉄鋼、非鉄金属、建設資材に連動 |
| 消費 | 小売、食品、サービス、eコマースに連動 |
| 機械・製造 | 自動車、輸送機器、産業機械に連動 |
| 通信 | 通信サービス、情報サービスに連動 |
| 公益 | 電力、ガス、公益事業セクターに連動 |

### テーマ（theme）- 12タグ - 緑系

| タグ名 | 付与基準 |
|--------|----------|
| AI・半導体 | 半導体、AI関連企業を主要構成銘柄とする |
| EV・自動運転 | 電気自動車、自動運転技術関連に連動 |
| クリーンエネルギー | 再生可能エネルギー、脱炭素関連に連動 |
| DX | デジタルトランスフォーメーション関連に連動 |
| 高配当 | 配当利回りに着目した指数・戦略に連動 |
| ESG | ESG評価に基づく銘柄選定を行う |
| 小型株 | 時価総額が小さい銘柄を対象とする |
| バリュー | PBR、PER等のバリュー指標に着目 |
| グロース | 成長性の高い銘柄を対象とする |
| インデックス | 市場全体を代表する指数に連動（TOPIX、日経225等） |
| レバレッジ | 指数の2倍等、レバレッジをかけた値動きに連動 |
| インバース | 指数の逆方向（ベア）の値動きに連動 |

### 地域（region）- 8タグ - 紫系

| タグ名 | 付与基準 |
|--------|----------|
| 国内 | 日本国内の資産に投資 |
| 米国 | 米国市場の資産に投資 |
| 先進国 | 先進国全般（除く日本含む）に投資 |
| 新興国 | 新興国市場に投資 |
| 全世界 | グローバル分散投資 |
| アジア | アジア地域（インド、東南アジア等）に投資 |
| ヨーロッパ | 欧州市場に投資 |
| 中国 | 中国市場（本土、香港含む）に投資 |

### 資産クラス（asset）- 4タグ - オレンジ系

| タグ名 | 付与基準 |
|--------|----------|
| 株式 | 株式を主要投資対象とする |
| 債券 | 国債、社債等の債券に投資 |
| REIT | 不動産投資信託に投資 |
| コモディティ | 金、原油等の商品に投資 |

### 経済情勢（economic）- 7タグ - 赤系

| タグ名 | 付与基準 |
|--------|----------|
| 円安 | 為替ヘッジなし外貨建て資産（円安時に有利） |
| 円高 | 為替ヘッジあり（円高時に有利） |
| 金利上昇 | 金利上昇局面で恩恵を受ける（銀行等） |
| 金利低下 | 金利低下局面で恩恵を受ける（REIT、長期債券等） |
| インフレヘッジ | インフレ時に価値を維持しやすい（金、REIT等） |
| 景気敏感 | 景気変動の影響を受けやすい |
| ディフェンシブ | 景気変動の影響を受けにくい |

### 政策（policy）- 3タグ - ピンク系

| タグ名 | 付与基準 |
|--------|----------|
| 防衛関連 | 防衛・安全保障関連企業に投資 |
| インフラ | 社会インフラ、建設関連に投資 |
| 半導体政策 | 半導体産業政策の恩恵を受ける銘柄 |

## 銘柄分析の観点

タグ付与時は以下の観点で銘柄を分析する。

### 1. 銘柄名からの判断
- 「TOPIX」「日経225」→ インデックス、国内、株式
- 「S&P500」→ インデックス、米国、株式
- 「高配当」→ 高配当
- 「為替ヘッジあり」→ 円高
- 「為替ヘッジなし」→ 円安
- 「レバレッジ」「2倍」「ブル」→ レバレッジ
- 「インバース」「ベア」「ダブルインバース」→ インバース

### 2. 連動指数からの判断
- 連動する指数の構成銘柄の業種
- 指数の選定基準（配当重視、ESG重視等）
- 対象地域・市場

### 3. 資産クラスからの判断
- ETFカテゴリ（国内株式、外国株式、REIT、債券、コモディティ等）
- 投資対象の特性

### 4. 経済環境との関連
- 為替感応度（外貨建て資産か否か）
- 金利感応度（デュレーション、業種特性）
- 景気感応度（景気敏感 vs ディフェンシブ）

## タグ付与ルール

1. 各銘柄に最低2つ以上のタグを付与する
2. 地域タグと資産クラスタグは原則付与する
3. 該当するテーマ・業種・経済情勢タグを適宜付与する
4. レバレッジ/インバース銘柄には該当タグを必ず付与する

## 運用フロー

### 新規銘柄のタグ付け

1. `/etf-tag` スキルを使用してタグ付け分析を実行
2. 銘柄名、連動指数、投資対象を分析
3. 適切なタグを選定し、`etf_tags_data.py` にマッピングを追加
4. `auto_tag_etfs.py` を実行してDBに反映

### 自動タグ付けスクリプトの実行

```bash
# 開発環境
docker compose exec backend python scripts/auto_tag_etfs.py

# 本番環境
cd ~/www/japan-etf-analyzer && python backend/scripts/auto_tag_etfs.py
```

### マスターデータの更新

新規タグを追加する場合:
1. `seed_data.py` の `TAGS` リストにタグ定義を追加
2. `seed_data.py` を実行してDBに反映
3. `etf_tags_data.py` のマッピングを更新

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `backend/scripts/seed_data.py` | タグ・カテゴリのマスターデータ定義 |
| `backend/scripts/etf_tags_data.py` | ETFコード→タグ名のマッピング定義 |
| `backend/scripts/auto_tag_etfs.py` | 自動タグ付け実行スクリプト |
