# テスト設計書

具体的なテスト実装例は `07a_テストケース詳細.md` を参照。

## 1. テスト戦略

### 1.1 基本方針

| 項目 | 方針 |
|------|------|
| 開発手法 | TDD（テスト駆動開発） |
| カバレッジ目標 | 70%以上 |
| テストフレームワーク | pytest（Backend）、Vitest（Frontend） |

### 1.2 テストピラミッド

```
                    ┌─────────────┐
                    │   E2E Test  │  少数・高コスト
                    │   (手動)    │
                    ├─────────────┤
                ┌───┴─────────────┴───┐
                │   Integration Test  │  中程度
                │  (API・コンポーネント) │
                ├─────────────────────┤
            ┌───┴─────────────────────┴───┐
            │        Unit Test           │  多数・低コスト
            │  (Service・Repository・Hook) │
            └─────────────────────────────┘
```

### 1.3 テストレベル

| レベル | 対象 | ツール | 実行タイミング |
|--------|------|--------|----------------|
| 単体テスト | Service, Repository, Hook | pytest, Vitest | コミット前 |
| 統合テスト | API, Component | pytest, Vitest | プッシュ前 |
| E2Eテスト | 画面操作 | 手動 | リリース前 |

## 4. E2Eテスト（手動）

### 4.1 テストシナリオ

| No | シナリオ | 手順 | 期待結果 |
|----|----------|------|----------|
| 1 | おすすめ表示 | トップページを開く | 高配当のおすすめ銘柄が表示される |
| 2 | 観点切替 | 「低コスト」タブをクリック | 低コストのおすすめ銘柄に切り替わる |
| 3 | おすすめから詳細 | おすすめカードをクリック | 銘柄詳細モーダルが表示される |
| 4 | 基本検索 | 検索バーでキーワード入力 | 該当銘柄が一覧に表示される |
| 5 | カテゴリ絞込 | カテゴリを選択 | 該当カテゴリのみ表示 |
| 6 | タグ絞込 | タグをクリック | 該当タグを持つ銘柄のみ表示 |
| 7 | 一覧から詳細 | 一覧のカードをクリック | 銘柄詳細モーダルが表示される |
| 8 | チャート表示 | モーダル内で期間選択 | 選択期間のチャートが表示 |
| 9 | モーダルを閉じる | ×ボタンまたはオーバーレイクリック | モーダルが閉じ、一覧に戻る |
| 10 | お気に入り登録 | 一覧の☆ボタンをクリック | ★に変化し、登録される |
| 11 | お気に入り解除 | 一覧の★ボタンをクリック | ☆に変化し、解除される |
| 12 | モーダル内お気に入り | モーダル内の★/☆ボタンをクリック | 状態がトグルされ、一覧にも反映 |

### 4.2 リリース前チェックリスト

- [ ] 全機能が正常に動作する
- [ ] レスポンシブ表示が正常（PC/タブレット/モバイル）
- [ ] エラー時に適切なメッセージが表示される
- [ ] ローディング表示が適切
- [ ] 本番環境でAPIが正常に動作する

## 5. テスト実行コマンド

### 5.1 バックエンド

```bash
# 全テスト実行
docker compose exec backend pytest

# 単体テストのみ
docker compose exec backend pytest tests/unit/

# 統合テストのみ
docker compose exec backend pytest tests/integration/

# カバレッジ計測
docker compose exec backend pytest --cov=src --cov-report=html

# 特定テスト実行
docker compose exec backend pytest tests/unit/services/test_etf_service.py -v
```

### 5.2 フロントエンド

```bash
# 全テスト実行
docker compose exec frontend npm test

# ウォッチモード
docker compose exec frontend npm run test:watch

# カバレッジ計測
docker compose exec frontend npm run test:coverage

# 特定ファイルのテスト
docker compose exec frontend npm test -- SearchBar.test.tsx
```

## 6. CI/CD（将来）

### 6.1 GitHub Actions設定例

```yaml
# .github/workflows/test.yml

name: Test

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  backend-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.8'
      - name: Install dependencies
        run: |
          cd backend
          pip install -r requirements.txt
          pip install -r requirements-dev.txt
      - name: Run tests
        run: |
          cd backend
          pytest --cov=src --cov-report=xml
      - name: Upload coverage
        uses: codecov/codecov-action@v3

  frontend-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Install dependencies
        run: |
          cd frontend
          npm ci
      - name: Run tests
        run: |
          cd frontend
          npm run test:coverage
```

### 6.2 コミット前フック（pre-commit）

```yaml
# .pre-commit-config.yaml

repos:
  - repo: local
    hooks:
      - id: backend-test
        name: Backend Tests
        entry: docker compose exec -T backend pytest
        language: system
        pass_filenames: false

      - id: frontend-test
        name: Frontend Tests
        entry: docker compose exec -T frontend npm test
        language: system
        pass_filenames: false
```
