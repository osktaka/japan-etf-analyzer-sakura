# データベース設計書

## 1. 概要

### 1.1 データベース選定

| 項目 | 内容 |
|------|------|
| DBMS | SQLite 3 |
| ORM | SQLAlchemy 2.x |
| マイグレーション | Flask-Migrate (Alembic) |

### 1.2 選定理由

- さくらレンタルサーバーでMySQL利用可能だが、開発環境との一貫性を重視
- 個人利用で同時接続が少ないため、ファイルベースDBで十分
- デプロイ・バックアップが容易

## 3. テーブル定義

### 3.1 etfs（ETF銘柄マスタ）

ETF銘柄の基本情報と最新の指標データを保持する。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|----------|----------|------|------------|------|
| code | VARCHAR(10) | NO | - | 銘柄コード（PK） |
| name | VARCHAR(100) | NO | - | 銘柄名 |
| description | TEXT | YES | NULL | 銘柄の説明・特徴 |
| category_id | INTEGER | YES | NULL | カテゴリID（FK） |
| expense_ratio | DECIMAL(5,3) | YES | NULL | 信託報酬（%） |
| dividend_yield | DECIMAL(5,2) | YES | NULL | 配当利回り（%） |
| nav | DECIMAL(12,2) | YES | NULL | 基準価額（円） |
| market_price | DECIMAL(12,2) | YES | NULL | 市場価格（円） |
| deviation_rate | DECIMAL(5,2) | YES | NULL | 乖離率（%） |
| total_assets | DECIMAL(15,0) | YES | NULL | 純資産総額（億円） |
| listing_date | DATE | YES | NULL | 上場日 |
| index_name | VARCHAR(100) | YES | NULL | 連動指数名 |
| manager | VARCHAR(100) | YES | NULL | 運用会社名 |
| type | VARCHAR(10) | NO | 'ETF' | 銘柄種別（ETF/ETN等） |
| momentum_label | VARCHAR(10) | YES | NULL | モメンタムラベル（上昇加速/上昇維持/上昇減速/反転上昇/失速/下降減速/下降維持/下降加速） |
| created_at | DATETIME | NO | CURRENT_TIMESTAMP | 作成日時 |
| updated_at | DATETIME | NO | CURRENT_TIMESTAMP | 更新日時 |

### 3.2 categories（カテゴリマスタ）

ETFのカテゴリ（資産クラス）を管理する。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|----------|----------|------|------------|------|
| id | INTEGER | NO | AUTO | カテゴリID（PK） |
| name | VARCHAR(50) | NO | - | カテゴリ名（UNIQUE） |
| description | TEXT | YES | NULL | カテゴリの説明 |
| sort_order | INTEGER | NO | 0 | 表示順 |
| created_at | DATETIME | NO | CURRENT_TIMESTAMP | 作成日時 |
| updated_at | DATETIME | NO | CURRENT_TIMESTAMP | 更新日時 |

**制約:**
- UNIQUE (name) - カテゴリ名の重複を防止

ETFに付与するタグを管理する。

| name | VARCHAR(50) | NO | - | タグ名（UNIQUE） |
| color | VARCHAR(7) | YES | '#6B7280' | 表示色（HEX） |
| category | VARCHAR(20) | YES | NULL | タグカテゴリ（投資対象/地域/テーマ等） |
| created_at | DATETIME | NO | CURRENT_TIMESTAMP | 作成日時 |
| updated_at | DATETIME | NO | CURRENT_TIMESTAMP | 更新日時 |

**制約:**
- UNIQUE (name) - タグ名の重複を防止

### 3.4 etf_tag_relations（銘柄-タグ紐付け）

ETFとタグの多対多関係を管理する。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|----------|----------|------|------------|------|
| id | INTEGER | NO | AUTO | リレーションID（PK） |
| etf_code | VARCHAR(10) | NO | - | 銘柄コード（FK） |
| tag_id | INTEGER | NO | - | タグID（FK） |
| created_at | DATETIME | NO | CURRENT_TIMESTAMP | 作成日時 |

### 3.5 users（ユーザー）

### 3.6 favorites（お気に入り）

ユーザーのお気に入りETFを管理する。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|----------|----------|------|------------|------|
| id | INTEGER | NO | AUTO | お気に入りID（PK） |
| user_id | INTEGER | NO | - | ユーザーID（FK） |
| etf_code | VARCHAR(10) | NO | - | 銘柄コード（FK） |
| created_at | DATETIME | NO | CURRENT_TIMESTAMP | 作成日時 |
| updated_at | DATETIME | NO | CURRENT_TIMESTAMP | 更新日時 |

**制約:**
- UNIQUE (user_id, etf_code) - 同一ユーザーの重複登録を防止

- ON DELETE CASCADE (etf_code) - ETF削除時にお気に入りも削除

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|----------|----------|------|------------|------|

| split_date | DATE | NO | - | 分割実施日 |
| ratio | FLOAT | NO | - | 分割比率（2分割=2.0、2:1併合=0.5） |
| is_applied | BOOLEAN | NO | FALSE | ポートフォリオへの適用状態（true=適用済み、false=非適用） |
| is_chart_applied | BOOLEAN | NO | FALSE | チャート表示への適用状態（true=適用済み、false=非適用） |
| detected_at | DATETIME | NO | - | 検知日時 |
| reviewed_at | DATETIME | YES | NULL | 適用変更日時 |

| created_at | DATETIME | NO | CURRENT_TIMESTAMP | 作成日時 |
| updated_at | DATETIME | NO | CURRENT_TIMESTAMP | 更新日時 |

**制約:**
- UNIQUE (etf_code, split_date) - 同一銘柄・分割日の重複を防止

> **注記**: etf_codeおよびreviewed_byは設計上の参照先はあるが、実装ではFK制約を設けていない（indexのみ）。

**インデックス:**
- ix_stock_splits_etf_code (etf_code)

- ix_stock_splits_is_applied (is_applied)

## 8. SQLAlchemyモデル定義例

```python
# models/etf.py
from sqlalchemy import Column, String, Integer, Numeric, Date, DateTime, ForeignKey
from sqlalchemy.orm import relationship
from datetime import datetime
from .base import Base

class ETF(Base):
    __tablename__ = 'etfs'

    code = Column(String(10), primary_key=True)
    name = Column(String(100), nullable=False)
    description = Column(String)
    category_id = Column(Integer, ForeignKey('categories.id'))
    expense_ratio = Column(Numeric(5, 3))
    dividend_yield = Column(Numeric(5, 2))
    nav = Column(Numeric(12, 2))
    market_price = Column(Numeric(12, 2))
    deviation_rate = Column(Numeric(5, 2))
    total_assets = Column(Numeric(15, 0))
    listing_date = Column(Date)
    created_at = Column(DateTime, default=datetime.utcnow, nullable=False)
    updated_at = Column(DateTime, default=datetime.utcnow,
                        onupdate=datetime.utcnow, nullable=False)

    category = relationship("Category", back_populates="etfs")
    tags = relationship("Tag", secondary="etf_tag_relations", back_populates="etfs")
```

## 9. 注意事項

### 9.1 SQLite固有の制約

| 制約 | 対応 |
|------|------|
| 同時書き込み | 単一接続での利用を想定 |
| 外部キー制約 | `PRAGMA foreign_keys = ON` を設定 |
| DECIMALの精度 | SQLiteはREALとして保存、アプリ層で変換 |

### 9.2 本番環境の注意

- データベースファイルのパーミッション設定（書き込み可能に）
- バックアップディレクトリの確保
- WALモードの検討（読み取り性能向上）
