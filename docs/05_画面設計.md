# 画面設計書

## 1. 画面構成

### 1.1 設計コンセプト

**「能動的に探さなくても、システムがヒントや提案を与えてくれる」**

- トップページでシステムからのおすすめ銘柄を提案
- 複数の観点（高配当、低コスト等）から分析された提案
- 情報閲覧はモーダルで素早く確認
- お気に入り機能で気になる銘柄を保存

### 1.2 画面・モーダル一覧（MVP）

| ID | 種別 | 名称 | URL | 機能ID | 認証 |
|----|------|------|-----|--------|------|
| S-001 | 画面 | トップページ | / | F-001, F-002, F-006 | 不要 |
| S-002 | 画面 | パフォーマンス比較 | /compare | F-005 | 不要 |
| M-001 | モーダル | 銘柄詳細モーダル | - | F-003, F-004, F-006 | 不要 |
| M-002 | モーダル | ログイン促進モーダル | - | F-006 | - |

### 1.3 設計方針

| 用途 | 表示方式 | 理由 |
|------|----------|------|
| 情報閲覧（詳細確認） | モーダル | 元画面のコンテキストを維持、素早く戻れる |
| おすすめ・検索操作 | 画面 | メイン機能として常時表示 |
| 将来の編集機能 | 画面 | 複雑な操作が必要な場合は独立画面 |

#### 3.1.3 おすすめの観点一覧

| 観点ID | 観点名 | 説明 | ソート基準 |
|--------|--------|------|-----------|
| high-dividend | 高配当 | 配当利回りが高い銘柄 | 配当利回り降順 |
| low-cost | 低コスト | 信託報酬が低い銘柄 | 信託報酬昇順 |
| domestic | 国内株式 | 日本株式に連動する銘柄 | 純資産降順 |
| foreign | 外国株式 | 海外株式に連動する銘柄 | 純資産降順 |
| emerging | 新興国 | 新興国に投資する銘柄 | 配当利回り降順 |
| esg | ESG | ESG投資関連の銘柄 | 純資産降順 |
| reit | REIT | 不動産関連の銘柄 | 配当利回り降順 |
| commodity | コモディティ | 金・原油等に連動する銘柄 | 出来高降順 |
