## 1. GET /recommendations - おすすめ銘柄取得

指定した観点（perspective）に基づくおすすめ銘柄を取得する。

### クエリパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------------|-----|------|------|
| perspective | string | No | 観点ID（デフォルト: balance） |
| limit | integer | No | 取得件数（デフォルト: 5、最大: 20） |
| scoring_mode | string | No | スコア計算モード（デフォルト: full）<br>`full`: 総合評価（5軸の重み付け平均）<br>`partial`: 軸別評価（perspective重視軸のみ） |
| custom_weights | string | No | カスタム重みJSON（例: `{"dividend_power": 0.3, ...}`）。カスタム切り口用 |

### 指定可能な観点（perspective）

| 観点ID | 観点名 | 説明 | 重み付け |
|--------|--------|------|---------|
| balance | バランス | 複数の観点でバランス良く評価された銘柄 | 全5軸均等（各0.2） |
| dividend | 配当収入 | 配当利回りが高く、定期的な配当収入を期待できる銘柄 | 配当力0.5、規模0.2、他0.1 |
| low-cost | 低コスト | 信託報酬が低く、長期保有でコストを抑えられる銘柄 | コスト効率0.5、規模0.2、他0.1 |
| stability | 安定性 | 純資産規模が大きく、安心して保有できる銘柄 | 規模0.4、コスト効率0.2、取引品質0.2、他0.1 |
| volume | 取引規模 | 出来高が多く、売買が成立しやすい銘柄 | 取引品質0.5、規模0.2、他0.1 |
| growth | 成長性 | 過去の値上がり実績が良好な銘柄 | リターン0.5、規模0.2、他0.1 |
| custom | カスタム | ユーザーが設定した重みで評価された銘柄 | ユーザー設定による（custom_weightsパラメータ必須） |

### リクエスト例

```
GET /api/v1/recommendations?perspective=balance&limit=4&scoring_mode=full
```

## 3. GET /etfs - ETF一覧・検索

ETF銘柄を検索・絞り込み・一覧取得する。

### リクエスト

| パラメータ | 型 | 必須 | 説明 |
|------------|-----|------|------|
| keyword | string | No | 検索キーワード（コード、名前、説明） |
| category_id | integer | No | カテゴリIDでフィルタ |
| tag_ids | string | No | タグIDでフィルタ（カンマ区切り） |
| momentum_labels | string | No | 勢いラベルでフィルタリング（カンマ区切り、例: "上昇加速,上昇維持"）。8パターン: 上昇加速/上昇維持/上昇減速/反転上昇/失速/下降減速/下降維持/下降加速 |
| min_dividend_yield | float | No | 配当利回り下限（%） |
| max_expense_ratio | float | No | 信託報酬上限（%） |
| favorite_codes | string | No | お気に入りコードでフィルタ（カンマ区切り） |
| holding_codes | string | No | 保有銘柄コードでフィルタ（カンマ区切り） |
| sort | string | No | ソート項目（code, name, dividend_yield, expense_ratio, total_assets, return_1m, return_3m, return_6m, return_1y, return_3y, return_5y, return_10y, return_20y, score_balance, score_dividend, score_low_cost, score_stability, score_volume, score_growth） |
| order | string | No | ソート順（asc, desc）デフォルト: asc |
| return_type | string | No | パフォーマンス計算方法（price, regression）デフォルト: price |
| scoring_mode | string | No | スコア計算モード（full, partial）デフォルト: full<br>`full`: 総合評価（5軸の重み付け平均）<br>`partial`: 軸別評価（perspective重視軸のみ） |
| perspective | string | No | スコア計算の切り口ID（balance, dividend等）デフォルト: balance |
| custom_weights | string | No | カスタム重みJSON（例: `{"dividend_power": 0.3, ...}`） |
| limit | integer | No | 取得件数（デフォルト: 50、最大: 100） |
| offset | integer | No | 取得開始位置（デフォルト: 0） |

## 5. GET /etfs/{code}/chart - チャートデータ取得

指定した銘柄の価格チャートデータを取得する。

### パスパラメータ

| パラメータ | 型 | 説明 |
|------------|-----|------|
| code | string | 銘柄コード |

### クエリパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------------|-----|------|------|
| period | string | No | 取得期間（デフォルト: 1m） |

**periodの指定可能値:**
- `1m`: 1ヶ月
- `3m`: 3ヶ月
- `6m`: 6ヶ月
- `1y`: 1年
- `3y`: 3年
- `5y`: 5年
- `10y`: 10年
- `20y`: 20年

### リクエスト例

```
GET /api/v1/etfs/1306/chart?period=1y
```

### レスポンス

```json
{
  "data": {
    "code": "1306",
    "name": "NEXT FUNDS TOPIX連動型上場投信",
    "period": "1y",
    "data": [
      { "date": "2024-01-28", "open": 2200.0, "high": 2210.0, "low": 2195.0, "close": 2205.0, "volume": 1500000 },
      { "date": "2024-01-29", "open": 2205.0, "high": 2220.0, "low": 2200.0, "close": 2215.0, "volume": 1200000 }
    ]
  }
}
```

### 注意事項

- DBキャッシュ優先で取得（当日データがあればキャッシュ使用）
- キャッシュがない場合はyfinance経由で取得

## 5a. GET /etfs/{code}/chart/batch - 複数期間チャートデータ一括取得

単一銘柄の複数期間チャートデータを1リクエストで取得する。
銘柄詳細モーダルの6期間チャート表示で使用。

### パスパラメータ

| パラメータ | 型 | 説明 |
|------------|-----|------|
| code | string | 銘柄コード |

### クエリパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------------|-----|------|------|
| periods | string | Yes | 取得期間（カンマ区切り、最大10個） |

### リクエスト例

```
GET /api/v1/etfs/1306/chart/batch?periods=3m,6m,1y,3y,5y,10y
```

### レスポンス

```json
{
  "data": {
    "code": "1306",
    "name": "NEXT FUNDS TOPIX連動型上場投信",
    "charts": {
      "3m": [
        { "date": "2025-10-28", "open": 2200.0, "high": 2210.0, "low": 2195.0, "close": 2205.0, "volume": 1500000 }
      ],
      "6m": [...],
      "1y": [...],
      "3y": [...],
      "5y": [...],
      "10y": [...]
    }
  }
}
```

### エラーレスポンス

```json
// periodsパラメータがない場合 (400)
{ "error": { "message": "periods parameter is required" } }

// 銘柄が見つからない場合 (404)
{ "error": { "message": "ETF not found" } }
```
