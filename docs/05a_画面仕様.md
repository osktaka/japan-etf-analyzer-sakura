#### 1.1.3 おすすめの観点一覧（5軸評価ベース）

| 観点ID | 観点名 | 説明 | 評価の重みづけ |
|--------|--------|------|---------------|
| balance | バランス | 5軸を均等に評価した総合おすすめ | 配当20 コスト20 安定20 規模20 リターン20 |
| dividend | 配当収入 | 配当利回りを重視した銘柄 | 配当50 コスト10 安定20 規模10 リターン10 |
| low-cost | 低コスト | 信託報酬の低さを重視した銘柄 | 配当10 コスト50 安定20 規模10 リターン10 |
| stability | 安定性 | 純資産総額の大きさを重視した銘柄 | 配当10 コスト20 安定40 規模20 リターン10 |
| volume | 取引規模 | 売買代金・出来高を重視した銘柄 | 配当10 コスト10 安定20 規模50 リターン10 |
| growth | 成長性 | リターン実績を重視した銘柄 | 配当10 コスト10 安定20 規模10 リターン50 |
| custom | カスタム | ユーザーが5軸の重みを自由に設定（ログイン必要） | ユーザー設定値（合計100%） |

**表示モード切替（SectionControls）:**

検索・一覧セクション上部に表示切替コントロールを配置。

| コントロール | 説明 |
|-------------|------|
| ViewModeToggle | カード表示 / テーブル表示の切り替え |
| TableDisplayToggle | テーブル表示時の表示モード: 基本 / 株価傾向 / スコア |
| ScoringModeToggle | スコア表示時のスコア算出方式切り替え |
| PerspectiveSelector | カード・スコアモード時の切り口選択 |
| ReturnTypeToggle | 株価傾向モード時のリターン種別切り替え（回帰上昇率 / 株価上昇率） |
| AnnualizedToggle | 株価傾向モード時の年率化ON/OFF |

**テーブル表示モード:**

テーブル表示では、ColumnVisibilitySelectorで列の表示/非表示を切り替え可能。

| 表示モード | 表示列 |
|-----------|--------|
| 基本 | 銘柄コード、銘柄名、株価、配当利回り、信託報酬、勢い |
| 株価傾向 | 銘柄コード、銘柄名、株価、配当利回り、信託報酬、勢い、各期間のリターン（1M〜20Yから選択） |
| スコア | 銘柄コード、銘柄名、株価、配当利回り、信託報酬、勢い、評価スコア、5軸スコア（配当力、コスト、安定性、取引規模、リターン） |

**株価傾向モード:**

ETFテーブルの表示モードを「株価傾向」に切り替えると、以下の列が表示される。

| 列名 | 説明 |
|------|------|
| 勢い | 1M/3Mの年率回帰上昇率を比較し判定した8パターンのモメンタムラベルをバッジ表示（MomentumBadge）。比率ベース判定: ratio = \|1M年率\| / \|3M年率\| で算出し、RATIO_UPPER(1.45)超なら「加速」、RATIO_LOWER(0.55)未満なら「減速」、0.55〜1.45なら「維持」と判定 |

勢いラベルの8パターン判定ロジック:

| 1M | 3M | 条件 | ラベル |
|----|----|----|--------|
| >0 | >0 | ratio > 1.45 | 上昇加速 |
| >0 | >0 | 0.55 ≤ ratio ≤ 1.45 | 上昇維持 |
| >0 | >0 | ratio < 0.55 | 上昇減速 |
| >0 | ≤0 | - | 反転上昇 |
| ≤0 | >0 | - | 失速 |
| ≤0 | ≤0 | ratio < 0.55 | 下降減速 |
| ≤0 | ≤0 | 0.55 ≤ ratio ≤ 1.45 | 下降維持 |
| ≤0 | ≤0 | ratio > 1.45 | 下降加速 |

**勢い絞り込み:**

タグ絞り込みの下に勢いボタン（8パターン）を配置。複数選択可能で、バックエンドAPIフィルタリング（momentum_labelsパラメータ）により該当する勢いラベルの銘柄のみ表示する。タグ絞り込みと同様、全銘柄を対象にサーバーサイドで絞り込みを行う。

#### 1.1.5 おすすめ銘柄の重みづけ設定

おすすめ銘柄の評価スコア計算には、5軸（配当力、コスト効率、安定性、取引規模、リターン実績）の重みづけを使用する。重みづけモーダルで各観点（切り口）ごとに設定可能。

##### カスタム行の表示仕様

| 状態 | カスタム行 | 値の表示 | 「カスタムを編集」ボタン |
|------|-----------|---------|----------------------|
| 未ログイン | 表示 | `-` | 非表示 |
| ログイン済み（未設定） | 表示 | `-` | 表示 |
| ログイン済み（設定済み） | 表示 | 重み値（0-100） | 表示 |

#### 2.1.4 チャート表示仕様

**レイアウト:** ChartPeriodSelectorでユーザーが表示期間を選択し、選択された期間のチャートをMultiPeriodChartで表示。年率回帰上昇率カード（AnnualizedReturnCards）をチャート上部に表示。

**ChartPeriodSelector:**
- 8期間（1M, 3M, 6M, 1Y, 3Y, 5Y, 10Y, 20Y）から複数選択可能
- 選択状態はlocalStorageに永続化（キー: `chart-periods`）
- デフォルト: 3M, 1Y, 5Y

| 期間 | ラベル | データ間隔 |
|------|--------|-----------|
| 1M | 1ヶ月 | 日次 |
| 3M | 3ヶ月 | 日次 |
| 6M | 6ヶ月 | 日次 |
| 1Y | 1年 | 週次 |
| 3Y | 3年 | 週次 |
| 5Y | 5年 | 月次 |
| 10Y | 10年 | 月次 |
| 20Y | 20年 | 月次 |

**レスポンシブ対応:**
- PC（768px超）: 選択期間数に応じたグリッド表示
- タブレット（480px〜768px）: 2列グリッド
- モバイル（480px以下）: 1列

**取引履歴マーカー（ログインユーザーのみ）:**

チャート上の終値（close）ライン上に、ログインユーザーの売買取引日をマーカーとして表示する。

| マーカー種別 | 形状 | 色（fill / stroke） | 説明 |
|-------------|------|---------------------|------|
| 買い取引日 | 上向き三角（▲） | #34d399 / #10b981 | 買い注文が約定した日に表示 |
| 売り取引日 | 下向き三角（▼） | #f87171 / #ef4444 | 売り注文が約定した日に表示 |

- **休日対応:** 取引日がチャート上のデータポイントにない場合（休場日等）、次の営業日にスナップして表示
- **クリック時:** ポップオーバーで取引詳細（取引日・銘柄コード・数量・金額）を表示。同日に複数取引がある場合はリスト表示
- **ポップオーバー閉じ:** ポップオーバー外クリック、または別マーカークリックで閉じる

#### 4.1.4 適用トグルスイッチ

**2つのトグルスイッチ:**
1. **ポートフォリオ適用（PF適用）**: ユーザーのポートフォリオ計算（保有数量・平均取得単価）への適用
2. **チャート適用（CH適用）**: チャート表示・株価上昇率などの表示への適用

**トグルスイッチの状態:**
- OFF（デフォルト）: グレー背景、スイッチは左側、該当機能への適用なし
- ON: プライマリカラー背景、スイッチは右側、該当機能に適用

**動作:**
- クリック時: is_applied または is_chart_applied フラグをトグル（true ⇔ false）
- 即座にAPI経由でバックエンドに反映
- 成功時: 行を自動更新
- 失敗時: エラーメッセージ表示、元の状態に戻る
- 2つのトグルは独立して動作（片方のみONも可能）

**デザイン:**
- 既存の `.toggle` / `.toggleSlider` CSSクラスを使用
- AdminPage.module.css の 116-164行目で定義済み

**背景:**
- yfinanceは銘柄によって株価データが調整済み/未調整で混在
- チャート適用を手動制御することで、正確な表示を実現

### 5.1 M-004: カスタム重みづけモーダル（CustomWeightsModal）

5軸評価の重みをユーザーが自由に設定するモーダル。ログインユーザーのみ利用可能。

| 項目 | 仕様 |
|------|------|
| 表示トリガー | おすすめセクションまたは銘柄詳細モーダルの「カスタム」タブクリック（未設定時） |
| 5軸 | 配当力、コスト効率、安定性、取引規模、リターン実績 |
| 入力方式 | スライダー（0〜100、5刻み）+ 数値入力（0〜100、1刻み） |
| バリデーション | 合計が100%になること。不一致時はエラー表示・保存ボタン無効 |
| 保存 | API経由でサーバーに保存。成功時はモーダルを閉じる |
| 各軸のツールチップ | ラベルクリックで説明テキストをポップオーバー表示 |

### 5.2 M-005: 重みづけヘルプモーダル（WeightsHelpModal）

各切り口の5軸重みづけ配分を表形式で表示するヘルプモーダル。

| 項目 | 仕様 |
|------|------|
| 表示トリガー | おすすめセクション・比較画面の「?ヘルプ」ボタンクリック |
| テーブル内容 | 行: 切り口（バランス〜カスタム）、列: 5軸（配当・コスト・安定・規模・リターン） |
| カスタム行 | 未ログイン: 全て「-」、ログイン済み(未設定): 全て「-」、ログイン済み(設定済み): 重み値表示 |
| 「カスタムを編集」ボタン | ログイン済みの場合のみ表示。クリックでCustomWeightsModal表示 |

### 5.3 M-006: カスタム重みづけ未設定モーダル（CustomWeightsPromptModal）

カスタム重みづけが未設定のユーザーに設定を促すモーダル。

| 項目 | 仕様 |
|------|------|
| 表示トリガー | ログイン済みユーザーが「カスタム」タブをクリック（重み未設定時） |

### 5.4 M-007: 取引登録モーダル（TradeFormModal）

ETFの売買取引を登録・編集するモーダル。

| 項目 | 仕様 |

### 5.5 M-008: 取引履歴モーダル（TradeHistoryModal）

全取引履歴の表示・検索・管理モーダル。取引（売買）と入出金を時系列で統合表示する。

| 項目 | 仕様 |
|------|------|

| 「入出金」ボタン | CashFlowFormModalを表示（「取引を追加」ボタンの隣に配置） |
| 未ログイン時 | ログイン促進表示（ログイン/新規登録ボタン） |

**入出金の統合表示:**

| 項目 | 仕様 |
|------|------|
| 表示形式 | 取引一覧に入金・出金行が時系列で統合表示される |
| 入出金バッジ | グレー背景、入金=青文字（deposit）、出金=オレンジ文字（withdrawal） |
| 入出金行の操作 | 編集・削除可能（CashFlowFormModalで編集） |
| 銘柄列 | 入出金行は「-」を表示（ETFに紐づかないため） |

```
└─────────────────────────────────────────────────────────────┘
```

#### 7.2.3 UI要素

| 要素 | 説明 | アクション |
|------|------|-----------|
| 戻るリンク | 「← ノート一覧に戻る」リンク | クリックで /notes へ遷移 |
| 記事タイトル | 記事のタイトルを大見出しで表示 | - |
| 公開日/更新日 | 公開日を表示。更新日がある場合は併記 | - |
| Markdownコンテンツ | react-markdown + remark-gfm でレンダリング。見出し、段落、リスト、テーブル、コードブロック等に対応 | - |

#### 7.2.4 レスポンシブ対応

| サイズ | レイアウト |
|--------|-----------|
| sm (< 640px) | コンテンツ幅100%、余白縮小、テーブル横スクロール |
| md (640px - 1024px) | コンテンツ幅100%、適度な余白 |
| lg (> 1024px) | コンテンツ幅を中央寄せ、最大幅制限（読みやすさ確保） |

#### 7.2.5 状態

| 状態 | 表示内容 |
|------|----------|
| 正常表示 | 記事タイトル + 日付 + Markdownコンテンツ |
| 記事なし（404） | 「記事が見つかりません」メッセージ + ノート一覧へのリンク |

#### 7.2.6 予約投稿

- `publishedAt`が未来日時の記事はランタイムで非表示となる（URLを直接指定しても表示されない）
- 公開日時（JST基準）以降に自動表示される
- sitemap/OGPはビルド時に除外され、再ビルド（再デプロイ）で反映される
- 管理者（is_admin=true）でログイン時、未公開記事もURL直接指定で表示可能となる
- 未公開記事には日付メタ情報の横に「未公開」バッジが表示される

## 8. デモページ

### 8.1 S-601: デモページ

#### 8.1.1 概要

未ログインユーザー向けにMyPage（S-003）の読み取り専用プレビューを表示するページ。デモユーザーのデータを使い、ポートフォリオ管理機能の使用感を体験できる。

| 項目 | 仕様 |
|------|------|
| URL | /demo |
| 認証 | 不要（ログイン済みの場合は /mypage へリダイレクト） |
| データソース | デモ用API（`/api/v1/demo/*`） |
| モード | readOnly（編集・登録操作は全て無効化） |

#### 8.1.2 構成要素

| 要素 | 説明 | MyPageとの差異 |
|------|------|---------------|
| デモバナー | ページ上部に「これはデモです」の案内バナーを表示 | デモページのみ |
| ポートフォリオサマリー | 総資産額・評価額・評価損益・現金残高の4カード | 同一（readOnly） |
| 総資産推移チャート | 積み上げ面グラフ + 期間セレクタ | 同一（readOnly） |
| 勢いヒートマップ（ツリーマップ） | 保有銘柄の構成比をツリーマップで可視化。現金残高も表示 | 同一（readOnly） |
| 保有銘柄セクション | テーブル/カード形式の保有銘柄リスト | 取引追加・入出金ボタン非表示 |
| お気に入り一覧 | 切り口タブ付きカード表示 | 同一（readOnly） |

#### 8.1.3 デモバナー

| 項目 | 仕様 |
|------|------|
| 表示位置 | ページ最上部（サマリーセクションの上） |
| 内容 | デモデータである旨の説明 + ログイン/新規登録への誘導リンク |
| スタイル | 情報バナー（青系背景） |

#### 8.1.4 readOnlyモード

MyPageコンポーネントを readOnly プロパティで再利用する。

| 操作 | 通常MyPage | デモページ |
|------|-----------|-----------|
| 取引追加ボタン | 表示 | 非表示 |
| 取引履歴ボタン | 表示 | 非表示 |
| 入出金ボタン | 表示 | 非表示 |
| お気に入り解除 | 可能 | 不可 |
| チャート期間切替 | 可能 | 可能 |
| 表示形式切替 | 可能 | 可能 |
| 銘柄詳細モーダル | 表示可能 | 表示可能 |

#### 8.1.5 状態

| 状態 | 表示内容 |
|------|----------|
| ログイン済み | /mypage へリダイレクト |
| 正常表示 | デモバナー + ポートフォリオサマリー + チャート + 保有銘柄 + お気に入り |
| デモデータなし | 空状態表示（0件のリスト、サマリーは0値） |
