#### 1.1.3 おすすめの観点一覧

| 観点ID | 観点名 | 説明 | ソート基準 |
|--------|--------|------|-----------|
| high-dividend | 高配当 | 配当利回りが高い銘柄 | 配当利回り降順 |
| low-cost | 低コスト | 信託報酬が低い銘柄 | 信託報酬昇順 |
| domestic | 国内株式 | 日本株式に連動する銘柄 | 純資産降順 |
| foreign | 外国株式 | 海外株式に連動する銘柄 | 純資産降順 |
| emerging | 新興国 | 新興国に投資する銘柄 | 配当利回り降順 |
| esg | ESG | ESG投資関連の銘柄 | 純資産降順 |
| reit | REIT | 不動産関連の銘柄 | 配当利回り降順 |
| commodity | コモディティ | 金・原油等に連動する銘柄 | 出来高降順 |

#### 3.6.2 お気に入り一覧セクション

**UI構成:**
- セクションタイトル: 「お気に入り一覧」

**ソートトグル仕様:**
- 位置: 切り口タブの右側
- 表示: 「ソートON」または「ソートOFF」
- 機能:
  - OFF（デフォルト）: API取得順で表示
  - ON: 評価スコア（`etf.score`）の降順でソート
- 永続化: localStorageに状態を保存（キー: `mypage-sort-enabled`）
- スタイル:
  - OFF: グレーボーダー、セカンダリテキスト色
  - ON: プライマリカラー背景、白文字
  - ホバー時: ボーダー・テキストがプライマリカラーに変化

**レイアウト:**
- 切り口タブとソートトグルは `flex` で横並び（`justify-content: space-between`）
- タブとグリッドの間に `margin-bottom: 1rem` の余白
- モバイル表示: 縦並び、ソートトグルは全幅表示

**データフロー:**
- `useFavorites(perspective, 'full')` でお気に入り取得（スコア含む）
- ソートON時: `[...favorites].sort((a, b) => (b.etf.score ?? 0) - (a.etf.score ?? 0))`
- ソート結果を `useMemo` でメモ化

#### 4.1.4 適用トグルスイッチ

**2つのトグルスイッチ:**
1. **ポートフォリオ適用（PF適用）**: ユーザーのポートフォリオ計算（保有数量・平均取得単価）への適用
2. **チャート適用（CH適用）**: チャート表示・株価上昇率などの表示への適用

**トグルスイッチの状態:**
- OFF（デフォルト）: グレー背景、スイッチは左側、該当機能への適用なし
- ON: プライマリカラー背景、スイッチは右側、該当機能に適用

**動作:**
- クリック時: is_applied または is_chart_applied フラグをトグル（true ⇔ false）
- 即座にAPI経由でバックエンドに反映
- 成功時: 行を自動更新
- 失敗時: エラーメッセージ表示、元の状態に戻る
- 2つのトグルは独立して動作（片方のみONも可能）

**デザイン:**
- 既存の `.toggle` / `.toggleSlider` CSSクラスを使用
- AdminPage.module.css の 116-164行目で定義済み

**背景:**
- yfinanceは銘柄によって株価データが調整済み/未調整で混在
- チャート適用を手動制御することで、正確な表示を実現

#### 4.1.7 ソート機能

**デフォルト:** 検出日時（降順）

**ソート対象列:**
- 検出日時 ← デフォルト（降順）
- 銘柄コード（昇順/降順）
- 分割日（昇順/降順）
- 変動率（昇順/降順）
- 分割比率（昇順/降順）

#### 4.1.8 UI要素

| 要素 | 説明 | アクション |
|------|------|-----------|
| ステータスフィルター | ドロップダウン | 選択で一覧自動更新 |
| 検出日時カラムヘッダー | クリック可能 | クリックでソート切替 |
| 銘柄コード | リンク | クリックで詳細モーダル表示 |
| 承認ボタン [✓] | pending状態のみ表示 | クリックで承認確認ダイアログ |
| 却下ボタン [✗] | pending状態のみ表示 | クリックで却下理由ダイアログ |
| テーブル行 | - | リアルタイム更新 |

#### 4.1.9 状態

| 状態 | 表示内容 |
|------|---------|
| 初期表示 | pending一覧（検出日時降順） |
| 読み込み中 | ローディングスピナー |
| 操作中 | ボタン無効化、プログレス表示 |
| 完了 | 行の自動更新、トースト通知 |
| エラー | エラーメッセージ+リトライ |
| データなし | 「該当する分割情報がありません」 |

#### 4.1.10 リアルタイム更新

- 承認/却下操作完了後、APIが成功応答を返すと行を即座に更新
- ステータスバッジの色と操作ボタンの表示/非表示を変更
- トースト通知（成功/失敗）をユーザーに表示

#### 4.1.11 モバイル表示

タブレット/モバイル表示時は、テーブルをカード形式に変更:

```
┌─────────────────────────────────┐
│ ━━ 検出日時: 2025-01-28 ━━     │
│                                 │
│ 銘柄コード: 1306                 │
│ 銘柄名: NEXT FUNDS TOPIX...     │
│                                 │
│ 分割日: 2025-02-01              │
│ 変動率: -50.0%                  │
│ 比率: 2.0                       │
│ 状態: 承認待ち                   │
│                                 │
│ [✓ 承認] [✗ 却下]              │
│                                 │
└─────────────────────────────────┘
```
