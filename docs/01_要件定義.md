# 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名

japan-etf-analyzer-sakura

### 1.2 概要

日本のETF（上場投資信託）銘柄を探して分析するためのWebアプリケーション。

### 1.3 背景・目的

ETF銘柄を探すときに「どこを探して何を見ていいのかわからない」という課題を解決する。自分の興味や目的に沿った銘柄を効率的に見つけ、根拠となる情報をもとに投資判断ができるツールを提供する。

## 2. ユーザー要件

### 2.1 ターゲットユーザー

- 主要ユーザー: 開発者自身（個人投資家）
- 将来的に一般公開を視野に入れた設計

### 2.2 ユーザーストーリー

- ユーザーとして、銘柄コードや名前でETFを検索したい。なぜなら特定の銘柄を素早く見つけたいから。
- ユーザーとして、カテゴリやタグでETFを絞り込みたい。なぜなら興味のある分野のETFを探したいから。
- ユーザーとして、銘柄の詳細情報と指標を確認したい。なぜなら投資判断の材料が必要だから。
- ユーザーとして、複数期間のチャートを並べて見たい。なぜなら短期・長期のトレンドを同時に把握したいから。

## 3. 機能要件

### 3.1 MVP機能（Phase 1）

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-001 | 銘柄検索 | コード、名前、カテゴリ、タグ、特徴でETFを検索 | Must |
| F-002 | 銘柄詳細表示 | 銘柄の特徴、各種指標を表示 | Must |
| F-003 | チャート表示 | 1か月、3か月、6か月、1年、3年、5年、10年のチャートを並列表示 | Must |

### 3.2 将来機能（Phase 2以降）

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-101 | レコメンド機能 | 複数の視点（配当利回り、コスト、テーマ別等）でおすすめ銘柄を提示 | Want |
| F-102 | お気に入り機能 | 気になる銘柄を登録して管理 | Want |
| F-103 | 比較機能 | 複数銘柄のパフォーマンスを比較表示 | Want |
| F-104 | ユーザー認証 | ログイン/ログアウト機能 | Want |

## 4. 非機能要件

### 4.1 性能要件

- レスポンス時間: 検索結果表示 3秒以内
- 同時接続数: 当面は1〜数名（個人利用）

### 4.2 セキュリティ要件

- Phase 1: 認証なし（公開情報のみ扱う）
- Phase 2以降: セッションベース認証を実装予定

### 4.3 可用性要件

- 稼働時間: ベストエフォート（個人プロジェクト）
- バックアップ: データベースの定期バックアップ

### 4.4 運用要件

- デプロイ先: さくらレンタルサーバー スタンダード（FreeBSD）
- 開発環境: Docker

## 6. 制約事項

### 6.1 技術的制約

- さくらレンタルサーバー（共用）ではDockerが使用不可
- Python 3.8はサポート終了済みだが、環境制約により使用
- Node.jsはビルド時のみ使用、サーバーサイドでは動作不可
- CGI/FastCGI経由でのPython実行が必要

### 6.2 データ取得の制約

- Yahoo Finance APIは非公式、レート制限あり
- リアルタイムデータではなく、一定間隔でのバッチ取得を想定

## 7. 用語集

| 用語 | 説明 |
|------|------|
| ETF | Exchange Traded Fund（上場投資信託）。証券取引所で売買できる投資信託 |
| 信託報酬 | ETFの運用コスト。低いほど有利 |
| 配当利回り | 年間配当金÷株価。高いほど配当収入が多い |
| NAV | Net Asset Value（純資産価値）。ETFの理論価格 |
| 乖離率 | 市場価格とNAVの差。小さいほど適正価格で取引されている |
