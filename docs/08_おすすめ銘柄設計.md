# おすすめ銘柄設計

## 1. 概要

### 目的
投資家の異なる投資目的や関心に基づいて、最適なETF銘柄を提案する機能を提供する。

### 設計思想
- **統一評価軸**: すべての銘柄を同じ5つの評価軸で評価し、一貫性を確保
- **重み付けモデル**: 切り口（投資目的）に応じて評価軸の重要度を変えることで、異なるニーズに対応
- **透明性**: スコア計算の根拠が明確で、「なぜこの銘柄が選ばれたか」を説明可能
- **拡張性**: 新しい切り口の追加は重み付けを定義するだけで実現可能

### 以前の設計からの変更点
- **タグベースの排除**: 「分散投資」「人気」のようなタグベースの選定を廃止し、すべてスコアリングベースに統一
- **切り口の見直し**: 5つの切り口から6つに拡張（high-dividend → dividend、beginner → stabilityに名称変更、volume/growth/balanceを追加）
- **評価軸の体系化**: バラバラだった指標を5軸に統一し、各軸の正規化方法を明確化

---

## 2. 統一評価軸（5軸）

すべての銘柄を以下の5つの軸で評価します。各軸は0〜1の範囲に正規化され、切り口ごとの重み付けによって総合スコアを算出します。

### 2.1 配当力（Dividend Power）

**定義**: 配当金による収益性を評価する軸

**指標**: `dividend_yield`（配当利回り）

**正規化方法**:
```
score = min(dividend_yield / 10.0, 1.0)
```
- 10%を上限として正規化（10%以上は1.0）
- 配当利回りが高いほどスコアが高い

**データ例**:
- 3%の場合: 0.3
- 5%の場合: 0.5
- 10%以上の場合: 1.0

---

### 2.2 コスト効率（Cost Efficiency）

**定義**: 保有コストの低さを評価する軸

**指標**: `expense_ratio`（信託報酬率）

**正規化方法**:
```
score = max(0.0, 1.0 - (expense_ratio / 1.0))
```
- 反転スコア（低いほど高スコア）
- 1.0%を下限として正規化（1.0%以上は0.0）

**データ例**:
- 0.1%の場合: 0.9
- 0.5%の場合: 0.5
- 1.0%以上の場合: 0.0

---

### 2.3 規模・信頼性（Scale & Reliability）

**定義**: 純資産規模による安定性・信頼性を評価する軸

**指標**: `total_assets`（純資産総額、単位:百万円）

**正規化方法**:
```
log_assets = log10(total_assets)
score = min(max((log_assets - 8) / 4, 0.0), 1.0)
```
- 対数スケールで正規化
- 100億円（log10 = 10）を中央値、1兆円（log10 = 12）を上限に設定

**データ例**:
- 1億円（10^8）の場合: 0.0
- 100億円（10^10）の場合: 0.5
- 1兆円（10^12）以上の場合: 1.0

---

### 2.4 取引品質（Trading Quality）

**定義**: 売買のしやすさを評価する軸

**指標**:
- `average_volume`（平均出来高、30日移動平均）
- `deviation_rate`（乖離率の絶対値）

**正規化方法**:
```
# 出来高スコア（対数スケール）
log_volume = log10(average_volume)
volume_score = min(max((log_volume - 3) / 3, 0.0), 1.0)

# 乖離率スコア（低いほど良い）
deviation_score = max(0.0, 1.0 - (abs(deviation_rate) / 5.0))

# 加重平均（出来高70%、乖離率30%）
score = volume_score * 0.7 + deviation_score * 0.3
```

**データ例**:
- 出来高10万口、乖離率0.5%の場合: 0.7 * 0.67 + 0.3 * 0.9 = 0.74
- 出来高1万口、乖離率2.0%の場合: 0.7 * 0.33 + 0.3 * 0.6 = 0.41

---

### 2.5 リターン実績（Return Performance）

**定義**: 過去のパフォーマンス実績を評価する軸

**指標**:
- `return_1y`（1年リターン）
- `return_3y`（3年リターン）

**正規化方法**:
```
# 各リターンを-50%〜+100%の範囲で0〜1に正規化
normalized_return = (return_rate + 50) / 150

# 加重平均（1年40%、3年60%）
score = normalized_1y * 0.4 + normalized_3y * 0.6
```

**データ例**:
- 1年+20%、3年+50%の場合: (0.47 * 0.4 + 0.67 * 0.6) = 0.59
- 1年-10%、3年+10%の場合: (0.27 * 0.4 + 0.40 * 0.6) = 0.35

## 3. 切り口の定義（6つ）

各切り口は、5つの評価軸に対する重み付けの組み合わせとして定義されます。

### 3.1 配当収入（dividend）

**説明**: 配当利回りが高く、定期的な配当収入を期待できる銘柄

**対象ユーザー**: 配当金による定期収入を重視する投資家

**重み付け**:
| 評価軸 | 重み | 理由 |
|--------|------|------|
| 配当力 | **50%** | 配当利回りが最優先 |
| コスト効率 | 10% | 長期保有を考慮 |
| 規模・信頼性 | 20% | 安定配当の裏付け |
| 取引品質 | 10% | 売買のしやすさ |
| リターン実績 | 10% | 参考程度 |

**期待される結果**: 高配当ETF（例: TOPIX高配当40指数、日経高配当50など）が上位

---

### 3.2 低コスト（low-cost）

**説明**: 信託報酬が低く、長期保有でコストを抑えられる銘柄

**対象ユーザー**: 保有コストを最小化したい長期投資家

**重み付け**:
| 評価軸 | 重み | 理由 |
|--------|------|------|
| 配当力 | 10% | 参考程度 |
| コスト効率 | **50%** | 信託報酬が最優先 |
| 規模・信頼性 | 20% | 運用の安定性 |
| 取引品質 | 10% | 売買のしやすさ |
| リターン実績 | 10% | 参考程度 |

**期待される結果**: 超低コストETF（例: TOPIXインデックス、日経225インデックスなど）が上位

---

### 3.3 安定性（stability）

**説明**: 純資産規模が大きく、安心して保有できる銘柄

**対象ユーザー**: リスクを抑えたい初心者・保守的な投資家

**重み付け**:
| 評価軸 | 重み | 理由 |
|--------|------|------|
| 配当力 | 10% | 参考程度 |
| コスト効率 | 20% | 長期保有を考慮 |
| 規模・信頼性 | **40%** | 純資産規模が最優先 |
| 取引品質 | 20% | 流動性の確保 |
| リターン実績 | 10% | 参考程度 |

**期待される結果**: 大型ETF（例: TOPIX連動型、日経225連動型など）が上位

---

### 3.4 取引規模（volume）

**説明**: 出来高が多く、売買が成立しやすい銘柄

**対象ユーザー**: 流動性を重視する短期トレーダー・アクティブ投資家

**重み付け**:
| 評価軸 | 重み | 理由 |
|--------|------|------|
| 配当力 | 10% | 参考程度 |
| コスト効率 | 10% | 参考程度 |
| 規模・信頼性 | 20% | 市場での信頼性 |
| 取引品質 | **50%** | 出来高・流動性が最優先 |
| リターン実績 | 10% | 参考程度 |

**期待される結果**: 取引量の多い主要ETF（例: 日経レバレッジ、日経ダブルインバースなど）が上位

---

### 3.5 成長性（growth）

**説明**: 過去の値上がり実績が良好な銘柄

**対象ユーザー**: キャピタルゲインを重視する成長志向の投資家

**重み付け**:
| 評価軸 | 重み | 理由 |
|--------|------|------|
| 配当力 | 10% | 参考程度 |
| コスト効率 | 10% | 長期保有を考慮 |
| 規模・信頼性 | 20% | 運用の安定性 |
| 取引品質 | 10% | 売買のしやすさ |
| リターン実績 | **50%** | 過去リターンが最優先 |

**期待される結果**: 高リターンETF（例: グロース株指数、テーマ型ETFなど）が上位

**注意**: UIで「過去の実績は将来を保証しません」の注意書きを表示推奨

---

### 3.6 バランス（balance）

**説明**: 複数の観点でバランス良く評価された銘柄

**対象ユーザー**: 特定の軸に偏らず、総合的に優れた銘柄を探している投資家

**重み付け**:
| 評価軸 | 重み | 理由 |
|--------|------|------|
| 配当力 | 20% | 均等配分 |
| コスト効率 | 20% | 均等配分 |
| 規模・信頼性 | 20% | 均等配分 |
| 取引品質 | 20% | 均等配分 |
| リターン実績 | 20% | 均等配分 |

**期待される結果**: 総合力の高いETF（例: 主要インデックス連動型など）が上位

## 4. 評価ロジックの詳細

### 4.1 スコア計算式

各銘柄の総合スコアは以下の式で計算されます:

```
total_score = Σ(normalized_score_i × weight_i) / Σ(weight_i) × 100
```

ここで:
- `normalized_score_i`: 各評価軸の正規化スコア（0〜1）
- `weight_i`: 切り口ごとの重み（0〜1）
- 総合スコアは0〜100の範囲に正規化

### 4.2 データ不足時の対応

- 各評価軸でデータが取得できない場合、その軸はスコア計算から除外
- 除外された軸の重みを除いた合計で正規化（partial scoring）
- 例: 配当力のデータがない場合、残り4軸で計算し、それぞれの重みの合計で割る

### 4.3 候補銘柄の絞り込み

スコアリング対象を効率化するため、切り口ごとに事前絞り込みを実施:

| 切り口 | 絞り込み条件 |
|--------|-------------|
| dividend | 配当利回りがNULLでない銘柄 |
| low-cost | 信託報酬がNULLでない銘柄 |
| stability | 純資産総額が上位の銘柄 |
| volume | 平均出来高が上位の銘柄 |
| growth | リターンデータがある銘柄 |
| balance | 全銘柄（フィルタなし） |

### 4.4 正規化の根拠

各評価軸の正規化範囲は、日本のETF市場の実態に基づいて設定:

- **配当力**: 日本株ETFの配当利回りは通常0〜5%、10%を超えるケースは稀
- **コスト効率**: 信託報酬は0.03%〜1.0%の範囲が一般的
- **規模・信頼性**: 対数スケールを使用し、1億円〜1兆円の範囲をカバー
- **取引品質**: 出来高は銘柄間で桁違いの差があるため対数スケールを採用
- **リターン実績**: -50%〜+100%で大半のケースをカバー

## 5. 実装の詳細

### 5.1 データ要件

**必要なデータ**:
- ETFマスタデータ: `code`, `name`, `dividend_yield`, `expense_ratio`, `total_assets`, `deviation_rate`
- パフォーマンスデータ: `return_1y`, `return_3y`（performance_cacheテーブル）
- 出来高データ: `average_volume`（新規追加が必要）

**データ更新頻度**:
- ETFマスタ: 日次（Yahoo Finance APIから取得）
- パフォーマンスデータ: 日次（既存のsync_performance.pyで対応）
- 出来高データ: 日次（新規スクリプトが必要）

### 5.2 モジュール構成

```
backend/src/services/
├── scoring_service.py      # 5軸評価 + 重み付けロジック
└── recommend_service.py    # 切り口定義 + おすすめ取得

backend/src/repositories/
└── etf_repository.py       # 出来高・リターン取得メソッド追加
```

### 5.3 API仕様

**エンドポイント**: `GET /api/v1/recommend?perspective={perspective_id}`

**レスポンス例**:
```json
{
  "perspective": {
    "id": "dividend",
    "name": "配当収入",
    "description": "配当利回りが高く、定期的な配当収入を期待できる銘柄"
  },
  "items": [
    {
      "code": "1489",
      "name": "NEXT FUNDS 日経平均高配当株50指数連動型ETF",
      "dividend_yield": 4.5,
      "expense_ratio": 0.32,
      "total_assets": 245000,
      "score": 78.5
    }
  ]
}
```
