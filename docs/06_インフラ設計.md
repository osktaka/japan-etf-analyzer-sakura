## 2. 開発環境

### 2.1 Docker Compose構成

```yaml
# docker-compose.yml
version: '3.8'

services:
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    ports:
      - "5000:5000"
    volumes:
      - ./backend:/app
      - backend_data:/app/data
    environment:
      - FLASK_ENV=development
      - FLASK_DEBUG=1
      - DATABASE_URL=sqlite:///data/etf.db
    command: flask run --host=0.0.0.0

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    ports:
      - "3000:3000"
    volumes:
      - ./frontend:/app
      - /app/node_modules
    environment:
      - VITE_API_URL=http://localhost:5000/api/v1
    command: npm run dev -- --host

volumes:
  backend_data:
```

### 2.2 Backend Dockerfile

```dockerfile
# backend/Dockerfile
FROM python:3.8-slim

WORKDIR /app

# 依存関係インストール
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# アプリケーションコピー
COPY . .

# ポート公開
EXPOSE 5000

# 環境変数
ENV FLASK_APP=src/app.py
ENV PYTHONPATH=/app/src

CMD ["flask", "run", "--host=0.0.0.0"]
```

### 2.3 Frontend Dockerfile

```dockerfile
# frontend/Dockerfile
FROM node:20-slim

WORKDIR /app

# 依存関係インストール
COPY package*.json .
RUN npm ci

# アプリケーションコピー
COPY . .

# ポート公開
EXPOSE 3000

CMD ["npm", "run", "dev", "--", "--host"]
```

## 3. 本番環境（さくらレンタルサーバー）

### 3.1 サーバー仕様

| 項目 | 内容 |
|------|------|
| プラン | スタンダード |
| OS | FreeBSD |
| Webサーバー | Apache |
| Python | 3.8（サーバー提供） |
| Node.js | 利用不可（ビルドは別環境で実施） |
| Docker | 利用不可 |

### 3.2 制約事項

| 制約 | 対応策 |
|------|--------|
| Docker不可 | CGI/FastCGI経由でFlask実行 |
| Python固定 | 3.8対応のライブラリを使用 |
| Node.js不可 | ローカルでビルドし、静的ファイルをアップロード |
| プロセス常駐不可 | CGIで都度起動、またはFastCGI |
| ファイル数制限 | node_modulesは転送しない |

### 3.3 ディレクトリ構成


### 3.4 .htaccess設定

```apache
# www/.htaccess

# CGI有効化
Options +ExecCGI
AddHandler cgi-script .cgi

# APIへのリクエストをCGIにルーティング
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^api/v1/(.*)$ /api/index.cgi/$1 [L,QSA]

# SPAルーティング（React用）
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_URI} !^/api/
RewriteRule ^ /index.html [L]

# セキュリティヘッダー
Header set X-Content-Type-Options "nosniff"
Header set X-Frame-Options "DENY"
Header set X-XSS-Protection "1; mode=block"
```

### 3.5 CGIエントリポイント

```python
#!/usr/local/bin/python3.8
# www/api/index.cgi

import sys
import os

# パス設定
sys.path.insert(0, os.path.expanduser('~/app/backend/src'))
sys.path.insert(0, os.path.expanduser('~/app/backend/venv/lib/python3.8/site-packages'))

# 環境変数設定
os.environ['FLASK_ENV'] = 'production'
os.environ['DATABASE_URL'] = 'sqlite:///' + os.path.expanduser('~/app/data/etf.db')

from wsgiref.handlers import CGIHandler
from app import create_app

app = create_app()

# PATH_INFO修正（/api/index.cgiを除去）
if 'PATH_INFO' in os.environ:
    path_info = os.environ['PATH_INFO']
    os.environ['PATH_INFO'] = '/api/v1' + path_info

CGIHandler().run(app)
```

## 4. デプロイ手順

### 4.1 初回セットアップ

```bash
# 1. SSH接続
ssh user@example.sakura.ne.jp

# 2. ディレクトリ作成
mkdir -p ~/app/backend ~/app/data ~/logs

# 3. Python仮想環境作成
cd ~/app/backend
python3.8 -m venv venv

# 4. 依存関係インストール
source venv/bin/activate
pip install -r requirements.txt
```

### 4.2 デプロイスクリプト

```bash
#!/bin/bash
# deploy.sh

set -e

# 設定
SERVER="user@example.sakura.ne.jp"
REMOTE_WWW="~/www"
REMOTE_APP="~/app/backend"

echo "=== Frontend Build ==="
cd frontend
npm run build

echo "=== Upload Frontend ==="
rsync -avz --delete dist/ $SERVER:$REMOTE_WWW/

echo "=== Upload Backend ==="
cd ../backend
rsync -avz --exclude='venv' --exclude='__pycache__' --exclude='*.pyc' \
    src/ $SERVER:$REMOTE_APP/src/
rsync -avz requirements.txt $SERVER:$REMOTE_APP/

echo "=== Install Dependencies ==="
ssh $SERVER "cd $REMOTE_APP && source venv/bin/activate && pip install -r requirements.txt"

echo "=== Set Permissions ==="
ssh $SERVER "chmod 755 $REMOTE_WWW/api/index.cgi"

echo "=== Deploy Complete ==="
```

## 5. バックアップ戦略

### 5.1 バックアップ対象

| 対象 | 頻度 | 保持期間 |
|------|------|----------|
| SQLiteデータベース | 日次 | 7日間 |
| アプリケーションコード | Git管理 | 無期限 |
| ログファイル | 週次アーカイブ | 30日間 |

### 5.2 バックアップスクリプト

```bash
#!/bin/bash
# backup.sh

BACKUP_DIR=~/backup
DATE=$(date +%Y%m%d_%H%M%S)
DB_FILE=~/app/data/etf.db

# ディレクトリ作成
mkdir -p $BACKUP_DIR

# データベースバックアップ
cp $DB_FILE $BACKUP_DIR/etf_${DATE}.db

# 古いバックアップ削除（7日以上前）
find $BACKUP_DIR -name "etf_*.db" -mtime +7 -delete

# ログアーカイブ（週次）
if [ $(date +%u) -eq 7 ]; then
    tar -czf $BACKUP_DIR/logs_${DATE}.tar.gz ~/logs/*.log
    > ~/logs/app.log  # ログファイルクリア
fi
```

### 5.3 cron設定


### 6.2 ログ設定（Flask）

```python
# backend/src/config/logging.py

import logging
import os
from logging.handlers import RotatingFileHandler

def setup_logging(app):
    if not app.debug:
        log_dir = os.path.expanduser('~/logs')
        os.makedirs(log_dir, exist_ok=True)

        file_handler = RotatingFileHandler(
            os.path.join(log_dir, 'app.log'),
            maxBytes=10240000,  # 10MB
            backupCount=5
        )
        file_handler.setFormatter(logging.Formatter(
            '%(asctime)s %(levelname)s: %(message)s [in %(pathname)s:%(lineno)d]'
        ))
        file_handler.setLevel(logging.INFO)
        app.logger.addHandler(file_handler)
        app.logger.setLevel(logging.INFO)
```

## 8. トラブルシューティング

### 8.1 よくある問題

| 問題 | 原因 | 対処 |
|------|------|------|
| 500 Internal Server Error | CGIパーミッション | `chmod 755 index.cgi` |
| ModuleNotFoundError | パス設定 | sys.pathを確認 |
| データベースエラー | パーミッション | `chmod 666 etf.db` |
| 文字化け | エンコーディング | `# -*- coding: utf-8 -*-` 追加 |

### 8.2 デバッグ方法

```bash
# CGIを直接実行してエラー確認
cd ~/www/api
./index.cgi

# ログ確認
tail -f ~/logs/app.log

# Apacheエラーログ確認
tail -f ~/logs/error.log
```
