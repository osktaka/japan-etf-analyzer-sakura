      context: ./frontend

      - VITE_API_URL=http://localhost:8902
    command: npm run dev -- --host

  backend_data:

## 3. 本番環境（さくらレンタルサーバー）

### 3.1 サーバー仕様

| 項目 | 内容 |
|------|------|
| プラン | スタンダード |
| OS | FreeBSD 13.0 |
| Webサーバー | Apache |
| Python | 3.9.18（pyenv経由） |
| OpenSSL | 1.0.2-chacha（重要制約） |
| Node.js | 利用不可（ビルドは別環境で実施） |
| Docker | 利用不可 |

### 3.2 制約事項

| 制約 | 詳細 | 対応策 |
|------|------|--------|
| Docker不可 | さくらサーバーではコンテナ未対応 | CGI/FastCGI経由でFlask実行 |
| Python 3.9.18固定 | pyenv経由でインストール | 3.9対応のライブラリを使用 |
| OpenSSL 1.0.2 | urllib3 v2はOpenSSL 1.1.1+が必要 | urllib3<2.0, requests<2.29.0で制約 |
| Node.js不可 | サーバーにNode.js環境なし | ローカルでビルドし、静的ファイルをgit管理 |
| プロセス常駐不可 | CGIは都度起動 | CGIで都度起動（FastCGIは未対応） |
| ファイル数制限 | アップロード時の制限 | node_modulesは転送せず、venvのみ本番構築 |
| cryptography Rustビルド | FreeBSD環境でRustコンパイラなし | CRYPTOGRAPHY_DONT_BUILD_RUST=1で回避 |

### 3.3 依存ライブラリのバージョン制約

#### OpenSSL 1.0.2互換性

FreeBSD 13.0のOpenSSL 1.0.2により、以下のバージョン制約が必要:

| ライブラリ | バージョン | 理由 |
|-----------|-----------|------|
| urllib3 | < 2.0 | v2.0以降はOpenSSL 1.1.1+が必要 |
| requests | < 2.29.0 | urllib3 v2依存を避けるため |

#### FreeBSDビルド制約

| ライブラリ | バージョン | 理由 |
|-----------|-----------|------|
| numpy | 1.19.5 | メモリ消費が少なく、FreeBSD環境でビルド可能 |
| pandas | 1.3.5 | numpy 1.19.5との互換性 |
| yfinance | 0.1.63 | 市場価格・チャート取得用（cryptography 2.x系と互換性あり）。配当利回りはみんかぶスクレイピングで取得 |
| cryptography | ビルド時スキップ | CRYPTOGRAPHY_DONT_BUILD_RUST=1を設定 |

#### 本番環境用

| ライブラリ | バージョン | 用途 |
|-----------|-----------|------|
| Flask | 3.0.3 | Webフレームワーク |
| SQLAlchemy | 2.0.23 | ORM |
| gunicorn | 21.2.0 | 本番WSGIサーバー（FastCGI用、未使用） |

**重要**: requirements.txtの変更後は必ずvenvを再構築（`rm -rf backend/venv && ./setup.sh`）

### 3.5 .htaccess設定

```apache
# CGI有効化
Options +ExecCGI
AddHandler cgi-script .cgi

# セキュリティヘッダー
Header set X-Content-Type-Options "nosniff"
Header set X-Frame-Options "DENY"
Header set X-XSS-Protection "1; mode=block"

# API リクエスト処理
RewriteEngine On
RewriteBase /japan-etf-analyzer/

# APIリクエストをindex.cgiにルーティング（index.cgi自体は除外）
RewriteCond %{REQUEST_URI} !index\.cgi
RewriteRule ^api/(.*)$ api/index.cgi/$1 [L,QSA]

# SPAルーティング（フロントエンド）
# 既存ファイル・ディレクトリは直接配信
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
# APIリクエストは除外
RewriteCond %{REQUEST_URI} !^/japan-etf-analyzer/api/
# index.htmlにフォールバック
RewriteRule . index.html [L]

# エラーページ
ErrorDocument 404 /japan-etf-analyzer/index.html
ErrorDocument 500 /japan-etf-analyzer/error.html
```

実ファイル: `<project_root>/.htaccess`

### 3.6 CGIエントリポイント

```python
#!/home/kima3/.pyenv/versions/3.9.18/bin/python3
# -*- coding: utf-8 -*-
# api/index.cgi

import os
import sys
from pathlib import Path

# プロジェクトルートを特定
APP_ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(APP_ROOT / "backend"))

# venv有効化（本番環境）
venv_site_packages = APP_ROOT / "backend" / "venv" / "lib" / "python3.9" / "site-packages"
if venv_site_packages.exists():
    sys.path.insert(0, str(venv_site_packages))

# .env読み込み
env_file = APP_ROOT / ".env"
if env_file.exists():
    with open(env_file) as f:
        for line in f:
            line = line.strip()
            if line and not line.startswith("#"):
                key, _, value = line.partition("=")
                os.environ.setdefault(key.strip(), value.strip())

# 環境変数設定（本番環境用）
os.environ.setdefault("FLASK_ENV", "production")
os.environ.setdefault("APP_BASE_DIR", str(APP_ROOT))
os.environ.setdefault("APP_DATA_DIR", str(APP_ROOT / "data"))

# DATABASE_URLを絶対パスに変更（CGI環境での相対パス問題を回避）
db_path = APP_ROOT / "data" / "etf.db"
os.environ["DATABASE_URL"] = f"sqlite:///{db_path}"

# カレントディレクトリをプロジェクトルートに変更（相対パス解決用）
os.chdir(APP_ROOT)

# Flaskアプリケーション読み込み
from src.app import app
from wsgiref.handlers import CGIHandler


# WSGI middleware to adjust PATH_INFO for CGI environment
class PrefixMiddleware:
    """Add prefix to PATH_INFO to match Flask route definitions."""

    def __init__(self, app, prefix=""):
        self.app = app
        self.prefix = prefix

    def __call__(self, environ, start_response):
        if "PATH_INFO" in environ:
            environ["PATH_INFO"] = self.prefix + environ["PATH_INFO"]
        return self.app(environ, start_response)


# Wrap app with middleware to add /api prefix
app = PrefixMiddleware(app, "/api")

# CGIハンドラーで実行
if __name__ == "__main__":
    CGIHandler().run(app)
```

実ファイル: `<project_root>/api/index.cgi`

**重要な変更点**:
- shebang: `#!/home/kima3/.pyenv/versions/3.9.18/bin/python3`（環境に応じて調整）
- DATABASE_URLを絶対パスに設定（CGI環境での相対パス問題を回避）
- os.chdir()でカレントディレクトリをプロジェクトルートに変更
- **PrefixMiddleware**: PATH_INFOに`/api`を追加（CGI環境でのルーティング一致のため）

## 5. バックアップ戦略

### 5.1 バックアップ対象

| 対象 | 頻度 | 保持期間 |
|------|------|----------|
| SQLiteデータベース | 日次 | 7日間 |
| アプリケーションコード | Git管理 | 無期限 |
| ログファイル | 週次アーカイブ | 30日間 |

### 5.2 バックアップスクリプト

```bash
#!/bin/bash
# backup.sh

BACKUP_DIR=~/backup
DATE=$(date +%Y%m%d_%H%M%S)
DB_FILE=~/app/data/etf.db

# ディレクトリ作成
mkdir -p $BACKUP_DIR

# データベースバックアップ
cp $DB_FILE $BACKUP_DIR/etf_${DATE}.db

# 古いバックアップ削除（7日以上前）
find $BACKUP_DIR -name "etf_*.db" -mtime +7 -delete

# ログアーカイブ（週次）
if [ $(date +%u) -eq 7 ]; then
    tar -czf $BACKUP_DIR/logs_${DATE}.tar.gz ~/logs/*.log
    > ~/logs/app.log  # ログファイルクリア
fi
```

### 6.2 ログ設定（Flask）

```python
# backend/src/config/logging.py

import logging
import os
from logging.handlers import RotatingFileHandler

def setup_logging(app):
    if not app.debug:
        log_dir = os.path.expanduser('~/logs')
        os.makedirs(log_dir, exist_ok=True)

        file_handler = RotatingFileHandler(
            os.path.join(log_dir, 'app.log'),
            maxBytes=10240000,  # 10MB
            backupCount=5
        )
        file_handler.setFormatter(logging.Formatter(
            '%(asctime)s %(levelname)s: %(message)s [in %(pathname)s:%(lineno)d]'
        ))
        file_handler.setLevel(logging.INFO)
        app.logger.addHandler(file_handler)
        app.logger.setLevel(logging.INFO)
```

## 8. トラブルシューティング

### 8.1 よくある問題

| 問題 | 原因 | 対処 |
|------|------|------|
| 500 Internal Server Error（無限リダイレクト） | .htaccessでindex.cgiがループ | RewriteCondで`!index\.cgi`を追加 |
| 500 Internal Server Error（CGI実行） | CGIパーミッション | `chmod 755 api/index.cgi` |
| 404 Not Found（APIエンドポイント） | PATH_INFOミスマッチ | api/index.cgiにPrefixMiddleware追加済み |
| 403 Forbidden（フロントエンド） | index.htmlシンボリックリンク不足 | `./setup.sh`を実行（自動作成） |
| sqlite3.OperationalError | DATABASE_URLが相対パス | api/index.cgiで絶対パス設定済み |
| ModuleNotFoundError | パス設定 | sys.pathを確認 |
| データベースエラー | パーミッション | `chmod 666 etf.db` |
| 文字化け | エンコーディング | `# -*- coding: utf-8 -*-` 追加 |
