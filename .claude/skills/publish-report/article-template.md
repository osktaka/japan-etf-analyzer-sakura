# ノート記事テンプレート

記事は以下の構成で生成する。各セクションの文字数目安に従うこと。
記事の主旨: 「今週の市場→ポートフォリオの改善点→具体的な提案→その根拠」を一貫した構成で伝える。

## frontmatter

title: 30字以内。具体的なアクション・テーマを先に、補足を後に（例: 「デモポートフォリオ構築 - 100万円で始める成長志向のETF投資」）
summary: 80字以内。記事の要点を1文で
publishedAt: レポートの分析日（YYYY-MM-DD）

## 記事構成（通常回）

### 今週の市場環境（150-250字）

レポート §0 市場環境サマリーから、主要指標（日経平均・ドル円・金利等）のうち最も動きが大きかったものを1-2個取り上げる。
前週比の数字を含め、市場の方向感を簡潔に示す。

### ポートフォリオ診断（400-600字）

レポート §10 最適化提案から、最も優先度の高い改善ポイントを1-2個取り上げる。
- 改善すべき点を具体的に示す（どの銘柄の何が問題か）
- 具体的な提案を述べる（何をどう変えるか）
- **銘柄一覧や比較は表形式で示す**（保有銘柄テーブル: 銘柄・役割・配分・選定理由など）
- 表の後に各銘柄の補足説明を加える

### 根拠（300-500字）

提案を裏付けるデータを、レポートの以下セクションから最も説得力のあるものを2-3個選んで示す。
**当サイトの分析機能名を明示**し、どのデータから判断したかを読者に伝える:

| レポートセクション | こういう提案の根拠に使う |
|------------------|------------------------|
| §0 市場環境 | マクロ要因による銘柄変更提案 |
| §2 シャープレシオ | リスク効率の悪い銘柄の入替提案 |
| §3 相関分析 | 分散不足による銘柄追加提案 |
| §5 ストレスシナリオ | リスク耐性強化の提案 |
| §6 スコア分析 | 総合力での銘柄比較 |
| §7 モメンタム | 勢い変化による売買タイミング提案 |
| §8 アロケーション | セクター/地域の偏り是正提案 |

「事実提示 → 視点提示」の流れで書く。断定は避ける。

### まとめ（150-250字）

記事のポイントを1-2文で振り返り、今後の方針を述べる。
「マイページ（デモ）」でデモポートフォリオの保有銘柄・損益をログインなしで確認できることを案内する。
サイトの機能（おすすめ銘柄、比較機能など）への自然な誘導を1文添える。
**注意**: おすすめ銘柄機能で確認できるのは5軸スコア・モメンタム等。シャープレシオは確認できないため言及しない。

### 免責事項

*この記事はデモポートフォリオの分析記録です。特定の銘柄の売買を推奨するものではありません。投資判断はご自身の責任でお願いいたします。*

## 記事構成（初回構築レポートの場合）

前回比や改善点が存在しない初回は、以下の構成に切り替える:

### 今週の市場環境（150-250字）
通常回と同じ。

### この取り組みについて（250-350字）
- ETF分析システムと生成AI（Claude Code）を組み合わせた実験的な運用であることを説明
- 当サイトが保持するデータ（5軸スコア、シャープレシオ、モメンタム等）をAIが横断分析する仕組みを紹介
- 今後の運用記録をノートで公開していく旨を述べる
- **このセクションは初回記事のみ**。2回目以降は不要

### ポートフォリオ構築の考え方（400-600字）
- なぜこの銘柄構成にしたか
- **銘柄一覧を表形式で示す**（銘柄・役割・配分・選定理由）
- 表の後に各銘柄の補足説明を加える
- 配分比率の意図、投資方針との整合性

### 根拠（300-500字）
構築理由を裏付けるデータ（スコア分析・シャープレシオ・アロケーション等）。
当サイトの分析機能名を明示する。

### まとめ（150-250字）
通常回と同じ。

### 免責事項
通常回と同じ。

| この取り組みについて | - | 250-350字 |

| 根拠 | 300-500字 | 300-500字 |
| まとめ | 150-250字 | 150-250字 |
| **合計** | **1500-2000字** | **1500-2000字** |

## 書き方のルール

- **銘柄一覧や比較は表形式で示す**（3-5行程度）
- 専門用語には括弧書きで補足（例: シャープレシオ（リスクに対するリターンの効率性を示す指標））
- **当サイトの分析機能名を根拠に明示する**（5軸スコア分析、モメンタム分析、相関分析など）
- 「〇〇すべき」「〇〇が有望」のような断定的表現は使わない
- 「こういう見方もできます」「一つの選択肢として検討できそうです」のような表現を使う
