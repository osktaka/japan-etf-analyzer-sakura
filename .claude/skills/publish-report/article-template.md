# ノート記事テンプレート

記事は「本文 + 直近アクション + 免責事項」の構成で生成する。
セクション構成は固定せず、レポート内容に応じて見出し・段落を柔軟に構成すること。

## frontmatter

title: 30字以内。具体的なアクション・テーマを先に、補足を後に（例: 「デモポートフォリオ構築 - 100万円で始める成長志向のETF投資」）
summary: 80字以内。記事の要点を1文で
publishedAt: レポートの分析日（YYYY-MM-DD）

## 記事構成（通常回: 2,000-2,500字）

### 本文（1,400-1,800字）

レポートのエグゼクティブサマリー・各セクションから要点を抽出し、端的にまとめる。

- **章の数を増やして文字数を確保する**（各章は200-400字程度に抑え、4-6章で構成）
- 各章は1つのトピックに絞り、端的に記述する。章内の文章を膨らませて文字数を稼がない
- セクション構成は固定しない（レポートの内容次第で見出しや段落を柔軟に構成）
- 保有銘柄テーブルは本文中に1回含める
- AI議論はレポートに記載があれば本文中に含めてよい（独立セクション不要）
- 段落は3-4行以内（Web記事向け）

**廃止した要素**（使わないこと）:
- 固定セクション構成（市場環境/AI議論/診断/次のステップ）
- 改善後テーブル・改善効果の補足
- セクション間の接続文テンプレート（「このような環境下で〜」等）
- 「次のステップ」セクション（サイト誘導文含む）

### 直近アクション（400-600字）

レポートの §10 最適化提案、§12 アクションプラン、HISTORY.md の未実行アクションから、具体的な売買指示レベルのアクションを抽出する。

```
## 直近アクション

※以下はAI分析に基づく例示であり、推奨する売買ではありません。

**今週やること**（合意度100%）

1. **1329を2口売却**（約12,000円を現金化）
   - 目的: 現金比率7.4%→10%に引き上げ（8回連続指摘）
   - 期限: 3月3日（関税発動前の最終営業日）

**条件付きで検討**（合意度80%）

2. **1615を100口売却**（約65,000円を現金化）
   - 条件: 3/4関税発動後の市場反応を確認してから判断
   - 目的: 1489との高相関（0.857）解消
```

- 合意度100% →「今週やること」、80%以上 →「条件付きで検討」、60%以下 → 記載しない
- 各アクション: 1行目に銘柄コード・口数・売買方向・金額、2行以内で目的+期限/条件

### デモページリンク

免責事項の直前に、デモポートフォリオへのリンクを含む案内文を記載する。

```
デモポートフォリオの詳細は[マイページ（デモ）](../demo)でご確認いただけます。
```

### 免責事項

*この記事はデモポートフォリオの分析記録であり、特定の銘柄の売買を推奨するものではありません。記事内で言及した銘柄や配分比率、シナリオ分析の数値等はあくまで分析の例示であり、将来の投資成果を保証するものではありません。投資判断はご自身の責任において、最新の情報を確認の上、行ってください。*

## 記事構成（初回構築レポートの場合: 1,800-2,200字）

### 本文（1,200-1,500字）

- 構築の考え方・銘柄選定根拠を端的にまとめる
- 保有銘柄テーブルは本文中に1回含める
- 「この取り組みについて」（システム×AI運用の説明）は初回のみ本文に含める

### 直近アクション（350-450字）

初回は売買がないため「モニタリング計画」として記載する。

### デモページリンク

通常回と同じ。

### 免責事項

通常回と同じ。

## 書き方のルール

### 表形式のルール
- **銘柄一覧や比較は表形式で示す**（3-5行程度）
- **銘柄コードを銘柄名の前に記載**: `| コード | 銘柄名 |` の列順にする
- `銘柄名(コード)` の形式は使わない

### 金融コンテンツ表現のルール
- 「致命的欠陥」「致命的な問題」→「重要な改善点」「重要な課題」を使う
- 「〜できます」「〜を解消できます」→「〜が考えられます」「〜の手段の一つとされています」を使う
- 「〇〇すべき」「〇〇が有望」のような断定的表現は使わない
- 「こういう見方もできます」「一つの選択肢として検討できそうです」のような表現を使う
- 運用会社破綻リスクに言及する場合、ETFの信託財産分別管理にも言及する
- ストレスシナリオの損失は比率表現を主とし、金額は補足として記載
