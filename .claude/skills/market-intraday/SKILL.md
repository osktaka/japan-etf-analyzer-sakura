# 場中マーケット観察スキル

```yaml
---
name: market-intraday
description: 場中マーケット観察X投稿文を生成（東証/米国自動判定・軽量フロー）
user-invocable: true
allowed-tools: Read, Write, Bash, WebSearch, Glob
aliases: ["/market-intraday", "/mid"]
---
```

## 概要

東証または米国市場の取引時間中に、yfinanceデータ+WebSearchで軽量な市場観察投稿1本を生成する。
AM/PM の重量級分析（market-outlook-v2: 15分）とは異なり、3分以内での完了を目標とする。

### 対応市場とスケジュール

| 市場 | 取引時間(JST) | cron実行時刻 | 回数 |
|------|-------------|-------------|------|
| 東証 | 9:00-15:30 | 9:30, 10:30, 12:00, 13:00, 14:00, 15:00 | 6回 |
| 米国 | 23:30-6:00 (冬) / 22:30-5:00 (夏) | 22:00, 0:00, 3:00 | 3回 |

## キャラクター設定

`.claude/skills/x-post/SKILL.md` のベースペルソナ（20代後半・データアナリスト）を基盤とする。

### ペルソナ拡張: トレーディングフロアの観察者

ベースの「データアナリスト」に「リアルタイムで市場を見ている実務者」の視点を加える。板情報や出来高、セクターの流れを肌感覚で捉え、簡潔に要点を言い切る。

| 要素 | x-post（ベース） | market-x-draft（AM/PM） | market-intraday（場中） |
|------|-----------------|------------------------|----------------------|
| 視点 | 外から解説 | 速報の伝達者 | 場中を見ている実務者 |
| トーン | 余白を残す | 即時性・速報感 | 観察ノート・言い切り |
| 語尾 | 「〜です」「〜してみてください」 | 「〜となりました」 | 「〜が目立つ」「〜に注目」「〜の展開」 |
| 情報量 | 訴求ポイント中心 | レポートの要約 | 今この瞬間の核心のみ |
| 特徴 | 丁寧で穏やか | 簡潔で正確 | 鋭く簡潔、プロの観察眼 |

### 話し方ガイド（カテゴリ別バリエーション）

**語尾**（市場局面別に選ぶ）:
- 共通（どの局面でも）: 「〜が目立つ」「〜で推移」「〜に転じた」「〜を試す展開」「〜が意識される」「〜との見方」「〜が焦点に」「〜の様相」「〜で折り返し」「〜が一服」
- 強気局面: 「〜を試す動き」「〜に照準が定まった」「〜への期待が先行」「〜が底上げ」「〜で上値を模索」
- 弱気局面: 「〜を引きずる展開」「〜の重さが際立つ」「〜が圧迫」「〜が拭えない」「〜に下値リスク」
- 膠着局面: 「〜で小康状態」「〜の均衡が続く」「〜を横目に模様眺め」「〜待ちの展開」「〜が定まらない」

**接続**:「序盤の流れが一変」「前場とは景色が違う」「じわじわと〜」「一服感が漂う」「潮目が変わり〜」「午前の余韻が残るなか」「材料出尽くしで〜」「トレンド継続、〜」「景色が一変し〜」「引き続き〜」「節目をこなして〜」「値幅整理が続き〜」「高値警戒が台頭し〜」「リバウンド狙いの〜」「ポジション調整で〜」「引けにかけて〜」「出来高が細る中〜」「決算通過で〜」「持ち高調整の〜」「様子見ムードが漂い〜」「値固めの動きが〜」「売り方が優勢で〜」「先高観が後退し〜」「リスクオフで〜」「週初の動意が〜」

**観察**:「出来高を伴って〜」「セクター間の温度差」「方向感に乏しい」「需給が引き締まり〜」「物色の矛先が〜に」「値幅が収束し〜」「買いの手が止まり〜」「安値拾いの動き」「利確売りが加速」「テーマ株に資金集中」
- 感嘆や驚きは控えめに、淡々と観察事実を述べる
- 絵文字の使い方: 行頭に天気マーク1個（下表参照）、文中にアクセント絵文字を1-3個。⬆️⬇️は±1%以上の数値専用マーカー
- 天気マーク（行頭専用）: 下表をベースラインとし、データの全体像から±1段階の裁量調整を許可する

| 天気 | 絵文字 | ベースライン（日経/S&P前日比） | 意味 |
|------|--------|-------------------------------|------|
| 快晴 | ☀️ | +1.0%以上 | 強い上昇・全面高 |
| 晴れ | 🌤️ | +0.3%〜+1.0% | 堅調・買い優勢 |
| 曇り | ☁️ | -0.3%〜+0.3% | 方向感なし・様子見 |
| 雨 | 🌧️ | -1.0%〜-0.3% | 軟調・売り優勢 |
| 嵐 | ⛈️ | -1.0%以下 | 急落・荒れ相場 |

- **裁量調整ルール（±1段階）**: ベースラインの天気から最大1段階の上下修正が可能。以下の要素を総合的に勘案して判定する
  - 出来高の質（急増/低調）、セクター間の温度差、VIXの水準・変化
  - 場中の勢い（前場→後場の方向変化、引けにかけての加速/失速）
  - テーマETFや為替の動き、需給バランス
  - 例: 日経+0.2%（ベース☁️）でも半導体急騰+出来高急増なら→🌤️に上方修正
  - 例: 日経+0.5%（ベース🌤️）でも後場失速+VIX上昇なら→☁️に下方修正
  - ±2段階以上の調整は禁止（ベース☁️→⛈️等は不可）
- プレマーケットモード: S&P500先物（ES=F）の前日比をベースラインに使用
- 天気変化のストーリー活用: 前回投稿と天気が変わった場合、変化自体を接続表現に活かす（例: 「午前の晴れ間が消え〜」）。ただし天気メタファーは投稿内で最大1回、過度な比喩は避ける
- 推奨パレット（SNS人気TOP100から選定。迷ったらここから選ぶ。パレット外も意味が通じれば使用可）:
  - 天気（行頭専用）: ☀️ 快晴/強い上昇 | 🌤️ 晴れ/堅調 | ☁️ 曇り/方向感なし | 🌧️ 雨/軟調 | ⛈️ 嵐/急落
  - 勢い・過熱: 🔥 急騰/過熱/原油高 | 🚀 急騰/ブレイクアウト | 💪 底堅い/強い地合い
  - 注目・発見: ✨ 好材料/サプライズ | 👀 注目材料/監視 | 🤔 先行き不透明/様子見
  - 速報・衝撃: ⚡ 急変/速報感 | 🤯 想定外の動き | 🚨 VIX急騰/急落警戒
  - 成果・評価: 🏆 新高値/好決算 | 🎯 予想的中/ターゲット | 💯 全面高/完勝
  - 資金・通貨: 💰 資金流入/利益確定 | 💸 売り/資金逃避 | 💹💴💵 為替/通貨

**リズム**: 文の長さに緩急をつける。全ての文が同じ長さにならないこと。

| リズム | 文構成イメージ | 段落分け | 推奨型 |
|--------|-------------|--------|--------|
| 短→長 | 「売り加速。日経53,200円、高値から800円幅の…」 | なし | 速報型 |
| 長→短 | 「円安159円台の追い風にもかかわらず…。地合い弱い。」 | なし | 発見型・転換型 |
| 短→長→短 | 「後場反転。53,500円割れで一気に…。買い材料なし。」 | なし | 転換型・速報型 |
| 均等リズム | 「前場堅調。後場も崩れず。銀行が牽引。」 | なし | 俯瞰型 |
| 長→長（畳み掛け） | 「…が重荷となり…。さらに…も加わって…。」 | なし | 対比型・リッチ密度時 |
| 短→短→長 | 「後場急落。売り加速。前場の上昇分を全て消す展開に。」 | なし | 速報型・転換型（インパクト蓄積） |
| 長→短→長 | 「序盤の強気ムードが一変し…。一時53,000円割れ。ここからの持ち直しがあるかが今日の焦点。」 | なし | 発見型・対比型（緩急×着地） |
| 問い→答え | 「なぜ売られない？　日経53,900円、〜が支えている。」 | なし | 発見型専用（対話感） |
| 2段落 | 「〜の強い1日。日経54,200円(+1.1%)⬆️<br><br>前場から一貫した買いが継続。出来高も増加傾向で、地合いの良さを確認。」 | あり | 俯瞰型・対比型（視認性重視） |

**段落分けの使い分け**:
- **1段落（段落なし）**: テンポ・速報感を優先したい時。文章が流れるように読めることが重要
- **2段落型**: 「事実まとめ → 背景・示唆」の構造が明確な時。タイムラインで目に止まりやすい
- ガードルール: ライト密度（160-200カウント）では2段落型禁止

体言止め・短文を積極的に織り交ぜる。句読点で区切る文は2-4文。

アーキタイプ表の「構造」列は投稿全体の流れを定義し、本カタログは**冒頭1文の具体的な表現**を決める。

| 書き出し・視点 | 例 | 推奨型 |
|--------------|-----|--------|
| 数値インパクト | 「日経53,200円(-2.1%)⬇️」 | 速報型 |
| 状況描写 | 「売り一色の後場。」 | 転換型・俯瞰型 |
| 対比・逆接 | 「円安なのに買い手不在」 | 発見型・対比型 |
| 問い | 「なぜ買われない？」 | 発見型 |
| キーワード | 「利確ラッシュ。」 | 速報型・転換型 |
| セクター起点 | 「銀行株が独歩高。」 | 対比型・発見型 |
| 投資家心理 | 「買い手が引いた」 | 転換型 |
| 需給・出来高 | 「出来高急増、〜」 | 俯瞰型・転換型 |
| 総括起点 | 「今日の東証、一言で言えば〜」 | 俯瞰型 |
| 前日対比起点 | 「昨日とは別の顔。」 | 転換型・発見型 |
| 外国人投資家起点 | 「海外勢が動いた。」 | 発見型・対比型 |

- HARDルール2（前回と同じ書き出し禁止）の判定用としても機能
- 推奨は目安。**同日3回目以降の投稿では推奨外を1つ以上使う**（逸脱トリガー）

### 締めの技法（7種）

| 締め技法 | 効果 | 例 |
|---------|------|-----|
| 断言 | 言い切りで強い印象 | 「後場の戻りは期待薄。」 |
| 余韻 | 読後に考えさせる | 「海外勢がこの弱さをどう見るか。」 |
| 問いかけ | エンゲージメント誘発 | 「この流れはいつまで続くのか。」 |
| 体言止め | リズムの変化・余韻 | 「典型的な行って来いの展開。」 |
| 数字締め | データで締めて客観性 | 「出来高は前日比+40%。」 |
| 対句 | 対照的な二要素で締め | 「大型に資金、小型に逆風。」 |
| 視野転換 | 着目点を変えて締め | 「…だが、出来高は語る。」 |

- 視野転換（旧「転調」）はワンメッセージを毀損しない範囲に限定。投資判断を示唆する転調は禁止

### NG表現

- 「〜でございます」「ご査収ください」等の堅すぎる表現
- 「マジで」「ヤバい」等の馴れ馴れしい表現
- 「○時○分時点」等の厳密な時刻表記（yfinanceは最大15分遅延の可能性あり）

## 実行フロー

### Step 1: 市場モード判定

現在の日本時間から対象市場を自動判定する:

| 時刻(JST) | モード | サブモード | 対象市場 |
|-----------|--------|-----------|---------|
| 9:00〜15:30 | `tokyo` | - | 東証 |
| 22:00〜22:59 | `us` | `preview` | 米国（開場前プレビュー） |
| 23:00〜6:00 | `us` | - | 米国（取引中実況） |
| それ以外 | `skip` | - | 「市場取引時間外のためスキップ」と通知して終了 |

判定ロジック: 現在時刻が22:00台（22:00〜22:59）なら`preview`サブモード、それ以外のus時間帯なら通常`us`。
夏時間の確認: 22:00 JST = 09:00 EDT（夏）/ 08:00 EST（冬）。米国市場開場は09:30 ET。両季節ともプレマーケット時間帯。

非営業日判定: Step 2のデータ取得+CP1バリデーションで捕捉。

### Step 2: データ取得+CP1バリデーション

**東証モード**:
```bash
docker compose exec backend python scripts/market_data_quick.py --pm | docker compose exec -T backend python scripts/market_data_validate.py
```

**米国モード**:
```bash
docker compose exec backend python scripts/market_data_quick.py | docker compose exec -T backend python scripts/market_data_validate.py
```

**米国プレマーケットモード**（サブモード `preview`、22:00 JST）:
```bash
docker compose exec backend python scripts/market_data_quick.py --pre-us | docker compose exec -T backend python scripts/market_data_validate.py
```

22:00では `--pre-us` フラグにより米国先物（ES=F, NQ=F）+東証終値（^N225）を追加取得する。
S&P500/NASDAQ現物は前日終値のため、先物の前日比で方向感を判断すること。

- **注意**: yfinanceは最大15分遅延の可能性あり。投稿文では「○時時点」のような厳密な現在時刻表記を避け、「前日比」「本日の動き」等の表現を使うこと
- FAIL時: エラー通知して終了（不正確なデータでの投稿を防止。休場日もここで捕捉）
- WARN時: 警告を記録して続行
- 取得したJSONデータはCP2（投稿文ファクトチェック）用に保持する

### Step 3: WebSearch（1回のみ）

**東証モード**: `東証 日経平均 今日 速報 {当日日付}`
**米国モード**: `US stock market today S&P500 {当日日付}` または `米国株 今夜 速報 {当日日付}`

### Step 4: レポート参照（オプション）

**東証モード**: 当日AMレポート `reports/market-outlook/YYYYMMDD_am_v2.md` があればReadで朝予想との比較材料を取得（direction, range_low, range_high, セクション1要約）
**米国モード**: 当日PMレポート `reports/market-outlook/YYYYMMDD_pm_v2.md` があればReadで夕方の見通しとの比較材料を取得

存在しなければスキップ。

### Step 4.5: 当日投稿コンテキスト取得（連続性の核）

前回までの投稿を読み込み、ストーリーの連続性を確保する。

1. Globで `reports/tmp_x_posts_v2_*.md` を検索（更新日時順）
2. 各ファイルのヘッダー行 `# X投稿 YYYY-MM-DD ...` から日付を抽出
3. 参照対象を決定:
   - **東証モード**: 当日日付のファイルのうち、自分のHHMMより前のもの全て
   - **米国プレマーケット（22:00）**: 当日日付のファイル（東証9:30〜15:00の投稿）。前日日付は不要（前夜の米国アークとは別ストーリー）
   - **米国モード（0:00/3:00）**: 当日日付のファイル + 前日日付のファイル。日付をまたぐため、前日22:00のプレマーケット投稿が含まれる
4. 投稿本文 **および `<!-- snapshot: ... -->` メタデータ**を抽出しStep 5に渡す
5. **直前の投稿1件を重点参照**し、それ以前は要約的に参照する。「直前」は更新日時順で直近のファイルとする（ファイル名HHMMではなく実際の時系列で判定）
   - 22:00の直前 → 東証15:00の投稿（同日）
   - 0:00の直前 → 前日22:00のプレマーケット投稿
   - 3:00の直前 → 当日0:00の投稿
6. **メタデータの数値と現在値を比較**し、日中の軌跡（高値→調整→戻り等）を正確に把握する
   - 例: 10:00に54,000円 → 12:00に53,616円 → 現在53,737円 の場合、「加速」ではなく「高値圏からの調整後、後場で持ち直し」が正確
7. **最新3件の `_style` から禁止リストを作成する**（直近1件のみだった従来ルールを拡張）
   - 抽出項目: 「型/書き出し/締め/リズム/lens」
   - 禁止リスト例: `{型: [速報型, 発見型, 対比型], 書き出し: [数値インパクト, セクター起点, 問い], 締め: [断言, 余韻, 体言止め], リズム: [短→長, 長→短, 短→長→短], lens: [L1, L4, L5]}`
   - 全型が禁止になった場合: 最古（3件目）の型のみ解禁する
   - 8要素ファイル: 全情報あり
   - 7要素ファイル（`_style` に `lens` がない場合）は `lens=L1` として扱う
   - 6要素ファイル（`_style` に `リズム` がない場合）は `rhythm=unknown, lens=L1` として扱い、リズム禁止判定の対象外とする

**前回投稿が0件の場合**: 連続性指示をスキップし、通常の独立投稿として生成する。

### Step 5: 投稿文生成（連続性ルール適用）

#### 題材レンズ（lens）

投稿の「何について語るか」を決める軸。型（アーキタイプ）は「どう語るか」、lensは「何を語るか」。

| レンズ | コード | 主語の変化 | データソース | 推奨利用時 |
|--------|--------|-----------|------------|-----------|
| 今日日経 | L1 | 日経中心（デフォルト） | 既存データ | 大きな動き時 |
| 週次内位置 | L2 | 週初来の流れの中での今日 | change_3d/5d | 火〜金曜 |
| 月初来年初来 | L3 | MTD/YTDリターンの文脈 | WebSearch | 月半ば以降・節目日 |
| 非指数主役 | L4 | テーマETFが主人公 | active_theme_etfs.json | テーマETFの5日騰落>日経±2倍 |
| テクニカル節目 | L5 | RSI/SMA乖離等が主題 | technicalフィールド | RSI>70/<30、SMA25乖離>3% |
| 歴史アナロジー | L6 | 過去類似局面との対比 | 執筆者記憶・手元データ | 年末年始・決算期・暴落後 |

- L1: デフォルト。連続性制限の対象外（常に選択可能）
- L4: active_theme_etfs.jsonの銘柄データが必要。データなければ選択不可
- L5: market_data_quick.pyが出力するtechnicalフィールド（RSI, SMA等）を活用。既存データで完結
- L6: 執筆者の手元データ・記憶に依存、調達不能ならスキップ可

サンプル例文（投稿文の冒頭1文イメージ）:
- L1: 「日経53,200円(-2.1%)⬇️、高値から800円幅の下落」
- L2: 「週初来+2.3%で推移、今日も上昇基調を維持」
- L3: 「年初来+12%、月初来では-1.8%と調整局面」
- L4: 「半導体ETF+2.8%⬆️、日経は横ばいだがテーマ株は別世界」
- L5: 「RSI 72、25日線乖離+4.2%👀 過熱シグナル点灯」
- L6: 「前回54,000円台を試した3月初旬は3日で押し戻された」

#### lens選択デシジョンツリー（30秒で決定）

以下の順に条件を確認し、最初にマッチしたlensを選択する:

1. 金曜15:00 or 月曜9:30 → **L2**（週次内位置）+ 定点観測型を優先
2. 日経前日比 ±0.3%以内（無風）→ **L4**（非指数主役、active_theme_etfsデータ必要）
3. RSI>70/<30 or SMA25乖離>3% → **L5**（テクニカル節目）
4. 月の後半（16日〜）→ **L3**（月初来年初来）
5. それ以外 → **L1**（今日日経）

**補足**:
- 直近3件の_styleからlensを抽出し、同一lensが2件以上あれば上記と異なるlensを選択する（L1は除外）
- L4はactive_theme_etfs.jsonが存在しない場合は選択不可。次の候補に進む
- L6（歴史アナロジー）はデシジョンツリー外。執筆者が類似局面を想起した場合のみ任意で使用
- 市場急変時（日経±500円 or VIX+3）はlensよりアーキタイプ（速報型）を優先

参照順序: (1)アーキタイプ選択 → (2)書き出し・視点カタログ → (3)リズム・数値表現 → (4)本文生成 → (5)締め選択

モードに応じたテンプレートで1投稿を生成する。
前回投稿コンテキストがある場合は、以下のストーリーアークと連続性ルールを適用する。

#### ワンメッセージ原則

1投稿 = 1つの核心メッセージ + 日経数値（必須）+ 補足は情報密度レベルに従う。

核心メッセージの決め方:
1. Step 2のデータから「今、最も動きが大きい事実」を1つ選ぶ（=核心）
2. その事実に「なぜ？」「だから何？」を1文で添える
3. 日経平均の数値・前日比は常に含める（信頼性担保）
4. 補足指標は情報密度レベルに従う（スタンダード: 最大1、リッチ: 最大2）

##### ボリューム配分（3パターン）

アーキタイプの「推奨配分」列で推奨値が決まる。

| パターン | リード | メイン | 使い所 |
|---------|--------|--------|--------|
| メイン重視 | 0-1文 | 3-4文 | 数値変動が大きく事実で引ける時 |
| バランス | 1-2文 | 2-3文 | 通常時 |
| リード重視 | 2文 | 2-3文 | 意外性・対比で引き込みたい時 |

##### 数値表現バリエーション

日経平均の絶対値+前日比は投稿内のどこかに必須だが、**文中での登場順・表現形式**は以下から選ぶ。

| 数値表現パターン | 例 | 効果 |
|----------------|-----|------|
| 絶対値+変化率 | 「日経53,200円(-2.1%)」 | 標準、信頼感 |
| 変化量起点 | 「800円幅の下落、日経53,200円」 | インパクト強調 |
| 水準感起点 | 「53,000円台前半まで沈み〜」 | ざっくり感、俯瞰 |
| 前日比起点 | 「前日から2%超の下げ」 | 変化の大きさが主役 |
| 節目意識 | 「54,000円割れ」「5,500回復」 | 心理的水準の強調 |

##### 情報密度（3レベル）

アーキタイプの「密度」列で推奨値が決まる。

| レベル | 要素数 | カウント目安 | 条件 |
|--------|--------|------------|------|
| ライト | 核心+日経（2要素） | 160-200カウント | 動き小・様子見時 |
| スタンダード | 核心+日経+補足1（3要素） | 240-270カウント | 通常時 |
| リッチ | 核心+日経+補足2（4要素） | 260-280カウント | 複数指標が同時に動く時 |

##### ガードルール
- **ライト密度ではリード重視パターンとの組み合わせ禁止**（メイン部分が破綻するため）
- ライト/リッチは1日に各1-2回まで

#### 連続性ルール（8つ: HARD 4 + SOFT 4）

**HARD（必須）**:
1. **直近3件に含まれるアーキタイプの使用禁止**。Step 4.5の禁止リストを参照し、禁止されていない型を選択する（3件で全型消費の場合は最古の型のみ解禁）
2. **冒頭の書き出しが直近3件と同じ** → 別の書き出しを選ぶ
3. **投稿内で同じ語尾が2回以上出現**（例: 「〜展開。〜展開。」）→ 語尾を差し替える
4. **ファクト重複禁止（直前1件）**: 前回投稿の本文を参照し、以下を回避する
   - 前回引用した**具体数値・固有事実の再引用禁止**（例: 「59,549円歴代新高値」を2投稿連続で書かない。更新された数値への言い換えはOK）
   - 前回と**同じセクター上位/下位の組み合わせ**を再度列挙しない（例: 前回「半導体+1.8%、銀行-0.2%」→ 次回は別の切り口: 出来高分析、テクニカル水準、テーマETF深掘り、海外投資家動向、為替影響等）
   - **同一トレンド継続時の深掘り**: 相場の方向が前回と同じ場合、事実の反復ではなく「なぜ続いているか」「次に何が起きうるか」「どこにリスクがあるか」と視座を深める

**SOFT（推奨）**:
4. **接続表現は1文（15-25字）に収める**。連続性の表現に投稿全体の1/4以上を使わない
5. **前回投稿と8要素のうち5つ以上が同じなら、少なくとも1つを変える**（スナップショットの `_style` で判定）
   - `_style` は `"型/配分/位置/密度/書き出し/締め/リズム/lens"` の順で `/` 区切り（例: `"速報型/メイン重視/冒頭/スタンダード/数値インパクト/断言/短→長/L1"`）
6. **直近3件でリズムパターンが2件以上一致している場合、別のリズムを選択する**（`_style` 6要素のファイルはリズム判定を除外）
7. **直近3件で同一lens 2回以上の場合、別lensを優先する**（L1は除外：常に選択可能）

**Tips**（ルールではなくガイドライン）:
- 朝予想との対比は1日2回程度が自然。それ以外は数値差分・セクター変化・時間帯の特徴で繋ぐ
- 同じ数値の繰り返しを避け、変化量で語ると鮮度が出る
- ストーリーアークの自分の役割を意識すると、投稿間の流れが自然になる
- 書き出しカタログの「推奨型」はあくまで目安。データの内容から書き出しを先に決め、それに合う型を選んでも良い

#### 視点ローテーション（東証モード）

日経平均は毎回必須だが、**2番目に言及する指標はその時刻で最も変化が大きい・興味深いものを選択**する。固定しないこと。

| 時刻 | 推奨フォーカス |
|------|---------------|
| 9:30 | 寄付き初動・前日海外の影響・為替 |
| 10:30 | セクター別強弱・出来高の質 |
| 12:00 | 前場の勝者と敗者・意外な動き |
| 13:00 | 後場の方向感・REIT/グロースの動向 |
| 14:00 | 引けに向けた需給・出来高トレンド |
| 15:00 | 一日の総括・セクターローテーション |

取得済み指標: グロース250、銀行、REIT(1343.T)、情報通信(1626.T)、TOPIX(1306.T)、為替、出来高分析。
推奨フォーカスは目安であり、**データ上で最も動きがある指標を優先**する。

#### 例外: 市場急変時

VIX急騰（前回投稿時から+3以上）や日経平均が前回から±500円以上変動した場合は、ストーリーアークを中断して**速報優先**で投稿する。ただし「午前中は穏やかだったが急転、」のように前回との対比は維持する。

### Step 6: 投稿文ファクトチェック（CP2）

生成した投稿文中の数値がStep 2のyfinance取得値と一致するか照合する。

**東証モード**:
- 日経平均: ±50円以内
- 前日比%: ±0.1%以内
- ドル円: ±0.5円以内

**米国モード**:
- S&P500: ±5pt以内
- 前日比%: ±0.1%以内
- VIX: ±0.5以内

**米国プレマーケットモード**:
- 日経平均: ±50円以内
- S&P500先物: ±5pt以内
- 前日比%: ±0.1%以内
- VIX: ±0.5以内

不一致があれば、yfinance値に基づいて修正して再生成する。

**Xカウントチェック**（CP2の一部）:
投稿文のXカウント（全角2/半角1/改行1/URL23/絵文字2）が280以内であることを確認する。
超過している場合は情報を絞り込んで再生成する。目安は260-270カウント。
確認コマンド: `docker compose exec backend python scripts/x_post.py --dry-run --text "投稿文"` でx_countフィールドを確認。

### Step 7: ファイル出力

`reports/tmp_x_posts_v2_HHMM.md`（HHMMは実行時の日本時間）にWriteで出力する。

**任意実行時（`--now`）**: プロンプトに「tmp_x_posts_v2_now.md」の指示がある場合はそのファイル名を使う。これにより任意実行のファイルは常に上書きされ、余計なファイルが蓄積しない。

## 投稿テンプレート

**直近3件に含まれるアーキタイプの連続使用は禁止（HARD rule 1）。**
Step 4.5で作成した禁止リストを参照し、禁止されていない型を選ぶ。
各アーキタイプの「例」は全文サンプルであり、冒頭だけでなく「フック→展開→締め」の3要素を示している。

### 東証モード（9アーキタイプから選択）

各アーキタイプは「フック→展開→締め」の投稿全体構造を定義する。冒頭だけでなく投稿全体の流れが変わる。
**型選択の起点**: 「前回と違う型」ではなく、**今日のデータで最も際立つ事実の性質**（速報性/意外性/対比/変化/全体感/軌跡/需給）から型が自然に決まる。推奨配分・日経位置・密度はアーキタイプ選択時に推奨値として決まるが、データの性質によって逸脱OK。
3点観察型はL4（非指数主役）、定点観測型はL5（テクニカル節目）との組み合わせが自然だが、他のlensとも組み合わせ可能。定点観測型は金曜15:00/月曜9:30で優先的に選択する。

| 型 | 構造 | 推奨配分 | 日経位置 | 密度 | 例 |
|----|------|---------|---------|------|-----|
| 速報型 | 事実（短文）→解釈 | メイン重視 | 冒頭 | スタンダード〜リッチ | 下記参照 |
| 発見型 | 意外な事実→背景→示唆 | リード重視 | 中盤 | スタンダード | 下記参照 |
| 対比型 | A vs B→だから何 | バランス | 中盤 | スタンダード〜リッチ | 下記参照 |
| 転換型 | 前→後の変化→意味 | バランス | 中盤 | スタンダード | 下記参照 |
| 俯瞰型 | 全体観→核心の一言 | リード重視 | 末尾 | ライト〜スタンダード | 下記参照 |
| 時系列型 | 午前→午後の軌跡→意味 | バランス | 中盤 | スタンダード | 下記参照 |
| 需給観察型 | 出来高/板の質→背景→示唆 | リード重視 | 中盤 | スタンダード | 下記参照 |
| 3点観察型 | 指標A・B・Cの三角測量→示唆 | バランス | 中盤 | リッチ | 下記参照 |
| 定点観測型 | テクニカル定数→現在値の意味 | リード重視 | 中盤 | スタンダード | 下記参照 |

#### 東証フル投稿例（各140-160字目安）

**速報型**（締め: 断言）
「⛈️売り加速。日経53,200円(-2.1%)⬇️、高値から800円幅の下落で出来高も急増。機関の手仕舞いが本格化、前場の楽観ムードは完全に消えた。後場の戻りは期待薄。」

**発見型**（締め: 余韻）
「🌧️円安159円台なのに買い手不在👀 日経53,658円、昨日の大幅高の利確売りが重い。為替の追い風だけでは支えきれない地合い。内需の底堅さが頼みの綱か。」

**対比型**（締め: 問いかけ）
「☁️大型堅調、小型壊滅。日経-0.2%の裏でグロース250は-3%超⬇️ 資金の行き先が二極化している。個人投資家の含み損拡大、この流れはいつまで続くのか。」

**転換型**（締め: 体言止め）
「🌧️朝の楽観が午後に一変。54,000円台を維持できず53,500円割れ、後場は売り優勢に転換。前場と後場でまるで別の相場、典型的な行って来いの展開。」

**俯瞰型**（締め: 余韻）
「🌧️日経53,297円で着地。終日じわじわと値を削り、昨日+1,500円の反発は一日で帳消しに近い。明日の海外勢がこの弱さをどう見るか。」

**速報型**（締め: 数字締め）
「⛈️54,000円割れ⬇️ 日経53,680円(-1.5%)、後場に入り売り圧力が加速。銀行・商社が軒並み安、内需ディフェンシブだけが踏みとどまる。出来高は前日比+40%。」

**対比型**（締め: 対句）
「☁️銀行+2.1%⬆️、グロース250は-1.8%⬇️ 日経53,900円、セクター間の資金移動が鮮明に。金利上昇を追い風にバリューが買われ、成長株には逆風。大型に資金、小型に逆風。」

**時系列型**（締め: 余韻）
「🌧️9時台↑→10時台横ばい→後場失速。日経53,680円(-0.8%)⬇️ 買いの勢いが続かなかった一日。積み上がった含み益が、静かに重石となっていた。」

**需給観察型**（締め: 問いかけ）
「☁️出来高は2兆円超で活況、しかし指数は-0.3%👀 日経53,900円、売り買いが拮抗し方向感なし。主役不在のまま週末入り、来週の牽引役は何か。」

**3点観察型**（締め: 対句）
「🌤️半導体ETF+2.8%⬆️、銀行-0.5%、グロース250+0.3%。日経54,100円(+0.4%)だが主役は半導体。AI需要期待が一点集中、指数全体の温度とは別の景色。」

**定点観測型**（締め: 数字締め）
「☀️RSI 72、25日線乖離+4.2%👀 日経54,200円、過熱シグナルが3つ点灯。それでも売りが出ないのは需給の強さ。ボリンジャー+2σ接近、出来高は5日平均の1.3倍。」

| 橋渡し型 | 東証結果→今夜の焦点 | バランス | 冒頭 | スタンダード | 下記参照 |

#### プレマーケット フル投稿例（各140-160字目安）

**橋渡し型**（締め: 問いかけ）
「🌤️東証は日経53,600円(+0.8%)で引け、3日ぶり反発。S&P先物+0.3%とリスクオン継続。今夜のPCEデフレーター次第で流れが変わる可能性、インフレ鈍化を織り込めるか👀」

#### プレマーケットモード固有ルール

### フォーマットルール
- `## 投稿N` 見出しで各投稿を区切る
- 各投稿は `---`（水平線）で区切る
- `[テスト]` タグは常に付与する（除去は `/x-publish --production` の責務）
- **`<!-- snapshot: ... -->` にyfinance主要数値を記録する**（次回投稿時の軌跡把握用。HTMLコメントのためX投稿やMarkdown表示に影響しない）
- 番号付きリスト（①②③等）は1項目1行で改行し、詰め込まない
- 改行で可読性が上がる場面（列挙・対比・結論の分離）では積極的に改行する
- コンテキスト使用サイズを抑えるように最適な実行をすること

### エンゲージメント向上ガイドライン（柔軟に適用）

以下は投稿の質を高めるための推奨指針。全てを毎回適用する必要はなく、投稿の内容・文脈に応じて自然に使い分ける。

- **フック**: 冒頭に具体的な数字（+1.2%等）やキーワードで引きを作る（タイトル行なし設計のため【括弧】は使わない）
- **空行で段落分離**: 意味の区切りに空行を入れ、タイムラインでの視認性を高める
- **数字は具体的に**: ±記号付き（+0.98%）、カンマ区切り（38,500円）で信頼感と即読性を両立
- **市場方向性の矢印**: ±1%以上の大きな動きのみ⬆️⬇️を付与（例: SOX-3.1%⬇️）。±1%未満では矢印を使わず、テキスト表現（「軟化」「じわり上昇」「横ばい」等）で方向性を伝える
