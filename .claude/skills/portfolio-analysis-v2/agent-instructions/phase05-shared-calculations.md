### 1. シャープレシオ分析・リスク調整後ランキング

|-----------|--------|------------|--------------|--------------|--------|

#### ポートフォリオ全体のシャープレシオ（正式計算）

個別銘柄SRの加重平均は分散効果を反映しないため、ポートフォリオ全体のSRは月次リターンデータから直接計算する。

**計算手順**（項目2の月次リターンデータを先に算出し、以下を実行する）:
1. 項目2の相関分析で算出する各銘柄の月次リターン × 保有比率（小数）を全銘柄分合算し、ポートフォリオ月次リターン系列を算出
2. ポートフォリオ月次リターンの平均を年率換算: `μ_p = 月次平均 × 12`
3. ポートフォリオ月次リターンの標準偏差を年率換算: `σ_p = 月次標準偏差 × √12`
4. `SR_portfolio = (μ_p - Rf) / σ_p`

**出力形式**:
```
ポートフォリオ全体シャープレシオ（正式値）: X.XX
  算出方法: ポートフォリオ月次リターン系列から直接計算（分散効果を反映）
参考値（個別SR加重平均）: X.XX
  算出方法: Σ(銘柄iのSR × 保有比率i)。分散効果を反映しないため正式値と乖離する
```

**注意**: 項目2の月次リターンデータが必要なため、計算順序は「項目2の月次リターン算出 → 本計算 → 項目2の残りの相関分析」となる。スクリプト実行時はこの依存関係を考慮すること。

### 2. 相関分析

#### 相関分析 閾値定義（他ファイルから参照）
- CORR_HIGH: 0.85（高相関判定）
  - 根拠: ポートフォリオ理論で「高相関」とされる一般的閾値。日本ETF市場では同一インデックス連動ETF間で0.95以上、異なるインデックス間で0.7-0.9が典型的
- CORR_LOW: 0.3（低相関判定）
  - 根拠: 分散効果が有意に期待できる閾値。Markowitz理論に基づき、相関0.3以下で分散投資の恩恵が顕著になる
- RETURN_GAP_THRESHOLD: 15%（年率リターン格差）
  - 根拠: 経験的設定値。高相関ペアでも年率15%以上のリターン格差がある場合、同一資産クラスの「実質重複」とは言えないため除外する目的。日本ETFの実データで検証推奨
- BETA_DIFF_THRESHOLD: 0.3（ベータ差）
  - 根拠: 経験的設定値。ベータ差0.3以上は市場感応度が有意に異なることを示す。リスク・リターン特性の実質的な違いを識別する閾値として設定
- TE_THRESHOLD: 7%（年率追跡誤差 ≒ 月次2% × √12）
  - 根拠: 年率追跡誤差7%は月次約2%（= 7%/√12）に相当。パッシブETFの許容乖離の上限目安。これを超えると異なるリスク特性を持つと判断
- STABILITY_DIFF: 0.3（前後半相関差）
  - 根拠: 経験的設定値。前半・後半の相関差が0.3を超える場合、構造変化やレジームシフトの可能性を示唆する。日本ETFの実データで検証推奨
- MIN_MONTHS_FULL: 14（相関安定性の算出に必要な最小データ点数）
  - 根拠: 前後半分割（各7点以上）で相関係数の統計的信頼性を確保するための最低要件。7点未満の相関係数は自由度不足で不安定
- MIN_MONTHS_BASIC: 6（相関・ベータの算出に必要な最小データ点数）
  - 根拠: 相関係数の統計的信頼性の最低要件。6点未満では自由度不足により相関・ベータの推定が不安定になる
- MIN_HOLDINGS_COMPOSITE: 5（複合判定の最小保有銘柄数）
  - 根拠: 経験的設定値。5銘柄未満では複合判定（5条件分岐）の識別力が低下し、誤分類リスクが高まるため、簡易判定にフォールバックする

#### 市場代理ETFの確定（Phase 0.5冒頭で1回決定・固定）

以下の優先順で市場代理ETFを決定し、出力冒頭に明記する:

1. 1306（TOPIX連動）を保有していれば使用
2. なければ国内インデックスETFのうち信託報酬最低のものを使用
3. いずれも非保有: 全保有銘柄の等加重月次リターン平均を使用
   → この場合ベータ差条件は無効化（同一セクター集中時の誤分類防止）

→ 「市場代理: {コード}（フォールバック: {1/2/3}）」として冒頭に明記

#### 計算内容

1. **相関係数（既存）**: `00_portfolio_data.json` の `price_data` から月初価格を抽出し、月次リターンを計算。全ペアのピアソン相関係数を算出
2. **ベータ**: β_i = ρ_im × (σ_i / σ_m) ← 市場代理を使用。ベータ差 = |β_i - β_j|。MIN_MONTHS_BASIC（6ヶ月）未満のデータの銘柄を含むペアはスキップ（「算出不可」と記録）
3. **年率リターン格差**: |1y_return_i - 1y_return_j|（performance_cacheから差分）
4. **年率追跡誤差**: std(R_it - R_jt) × √12（月次リターン差のSDを年率換算）。MIN_MONTHS_BASIC（6ヶ月）未満のデータの銘柄を含むペアはスキップ
5. **相関安定性**: データ点数 ≥ MIN_MONTHS_FULL（14）の場合のみ計算。|ρ_前半 - ρ_後半|、差 > STABILITY_DIFF（0.3） → 「不安定」。データ点数 < 14: 「算出不可」と記録

#### 複合判定ロジック

**前提条件**: 保有銘柄数 ≥ MIN_HOLDINGS_COMPOSITE（5銘柄）の場合のみ適用。5銘柄未満は複合判定をスキップし「相関+リターン格差の2軸表示」にフォールバック。

**判定順序（この順で評価し最初に一致したラベルを採用）**:

1. **「高リスク連動型」**: 相関 > CORR_HIGH AND (リターン格差 ≥ RETURN_GAP_THRESHOLD OR ベータ差 ≥ 0.5)
2. **「実質重複」**: 相関 > CORR_HIGH AND リターン格差 < RETURN_GAP_THRESHOLD AND ベータ差 < BETA_DIFF_THRESHOLD AND 追跡誤差 < TE_THRESHOLD
   ※市場代理フォールバック3の場合: ベータ差条件を除外し3条件で判定
3. **「不安定相関」**: 相関 > 0.7 AND 相関安定性 = 不安定
4. **「高相関（要確認）」**: 相関 > 0.7（上記いずれにも非該当）
5. **「低相関（分散効果）」**: 相関 < CORR_LOW

#### 中相関ペア（監視要）: 相関係数 0.5 ≤ r < 0.7

### 5. 加重平均スコア表

2つのテーブルを出力する:

**保有比率の算出（共通）**:
- `holdings` の各銘柄の `current_value` からポートフォリオ総額を算出
- 保有比率 = `current_value / 総額`（**小数値 0.0〜1.0** で扱う。例: 32.2% → 0.322）
- **絶対禁止**: パーセンテージ値（32.2等）をそのまま掛け算しないこと。必ず100で割って小数に変換する

**テーブル1: 5軸加重平均**（視点に依存しない）
- `00_portfolio_data.json` の `score_cache` と保有比率から、5軸（配当力・コスト効率・規模信頼性・売買品質・リターン）の加重平均を計算
- 計算式: `Σ(銘柄iの軸Xスコア × 銘柄iの保有比率)` ※保有比率は小数（0-1）、スコアは0-100点
- **5軸すべてのスコアが揃っていることを確認する**。score_cacheの各銘柄レコードから5軸（dividend_power, cost_efficiency, scale_reliability, trading_quality, return_performance）を取得し、欠落している軸がある場合はスキップせず、score_cacheの別のperspectiveレコードや`_metadata.score_cache.axes`を参照して取得する（5軸スコアは視点によらず同一値のため）
- 最弱軸・最強軸を特定し、差分を算出

**テーブル2: 視点別総合スコア加重平均**（視点ごとに異なる）
- `score_cache` の各銘柄の `total_score` を視点別に保有比率で加重平均
- 計算式: `Σ(銘柄iのtotal_score(視点Y) × 銘柄iの保有比率)` ※保有比率は小数（0-1）
- 6視点（balance, dividend, growth, low-cost, stability, volume）それぞれの値を出力

**バリデーション（必須）**:
- 計算結果が **0〜100の範囲** に収まることを確認する
- 範囲外の場合は保有比率のスケール誤り（パーセンテージと小数の混同）を疑い、計算を見直す

- 出力形式:

**テーブル1: 5軸加重平均（ポートフォリオ全体）**

| 配当力 | コスト効率 | 規模信頼性 | 売買品質 | リターン |

最弱軸: XX（YY点）、最強軸: XX（YY点）、差分: ZZ点

|------|----------|
| バランス | XX.X |
| 高配当 | XX.X |
| 低コスト | XX.X |

### 7. VaR/CVaR分析

- 相関分析（項目2）で算出した月次リターンデータを再利用
- 各銘柄の保有比率（**小数 0-1**。項目5と同じ算出方法）で加重し、ポートフォリオ月次リターンを算出
- VaR(95%) = ポートフォリオ月次リターンの5パーセンタイル
- CVaR(95%) = VaR以下の月次リターンの平均値
- 想定損失額 = VaR（またはCVaR）× ポートフォリオ総評価額
- 出力形式:

```
月次VaR(95%): -X.X%（月間で95%の確率でこの損失率以内）
月次CVaR(95%): -X.X%（最悪5%の平均損失率）
想定損失額（VaR基準）: -XX万円
想定損失額（CVaR基準）: -XX万円
算出期間: 直近Nヶ月（データ点数: N点）
```
- 各計算結果セクションの冒頭に `<!-- DO_NOT_RECALCULATE: var_cvar -->` マーカーを付与する

**スキップ条件（5段階）**:
- 月次リターンデータが6ヶ月未満: スキップ（「データ不足のためスキップ」と記載）
- 6-11ヶ月: 算出するが「参考値（データ点数: N点、信頼度: 低。N点中下位1点のみが5%タイルに該当するため、VaRとCVaRが同値になります。テールリスクの推定精度は極めて限定的です）」と注記
- 12-23ヶ月: 算出（「データ点数: N点、信頼度: 中（N点中下位M点が5%タイルに該当。サンプル数の増加に伴い推定精度は改善しますが、依然として参考値です）」と注記。Mは ceil(N*0.05) で算出）
- 24-35ヶ月: 算出（「データ点数: N点、信頼度: 中（テールリスク推定には依然として不十分。参考値として利用してください）」と注記）
- 36ヶ月以上: 算出（「データ点数: N点、信頼度: 高」と注記）

### [G] SR文脈テーブル（SELL推奨時の定量根拠義務化）

**実行条件**:
- 保有銘柄数 ≥ 2（相関ペアが1組以上存在する場合のみ実行）
- 1銘柄のみ保有の場合はセクションGをスキップし「相関ペア不足のためスキップ」と記載

**計算手順**:
1. 相関分析（セクションC）の結果から、各銘柄の「最高相関対銘柄」を特定
   - 相関ペアが存在しない銘柄は「相関ペアなし」として実効リターン差列を「-」と記載
2. 実効リターン差を計算:
   `実効リターン差 = (対象銘柄1年リターン - 信託報酬) - (最高相関対銘柄1年リターン - 対銘柄信託報酬)`
   - 信託報酬データが不明な銘柄は「信託報酬不明のため算出不可」と記載
3. SRが算出可能な銘柄の上位3銘柄をSR文脈テーブルとして出力
   - SR算出不可の銘柄（データ不足等）は「SR: 算出不可」として除外し、その旨を注記する
   - 銘柄数が3未満の場合は全銘柄を出力

**出力フォーマット**:
| コード | SR | SRランク | 最高相関対銘柄（相関係数） | 実効リターン差 | SELL推奨時必須根拠 |
|-------|-----|---------|----------------------|------------|-----------------|
| XXXX | X.XX | X位 | XXXX（X.XXX） | +XX.X% | SR低下 or ATR発動 or モメンタム失速 |

**ルール**: SRランク上位3位以内の銘柄をSELL推奨する場合は「SELL推奨時必須根拠」のいずれか1つ以上を定量的に確認・記載すること。コスト・過熱・マクロ逆風のみを根拠とするSELL推奨は「条件付きSELL（○○発動時）」として記載する。
