### 固有分析フレーム（会議1専用）

本会議では以下の分析フレームを**必ず適用**し、他の会議と視点を差別化する:

1. **リスク・リターン効率フロンティア**: 全銘柄をSR vs ボラティリティの2軸でマッピングし、効率フロンティアからの距離で銘柄を評価する
2. **テールリスク3指標比較**: ヒストリカルVaR、パラメトリックVaR、Cornish-Fisher VaRの3つを比較し、テールリスクの深刻度を多面的に評価する
3. **Rf感応度シナリオ**: 金利変動がポートフォリオのリスク調整後リターンに与える影響を定量的に議論する

**禁止**: 本会議ではアロケーション比率や入替銘柄の具体名には言及しない（会議2・3の領域）。リスク・リターンの効率性のみに集中すること。

---

## 議論の焦点（必ず取り上げるべき論点）

### 1. シャープレシオ分析（各銘柄・ポートフォリオ全体）
- `05_shared_calculations.md` のシャープレシオテーブルを引用
- 銘柄間のリスク効率格差を議論
- 非効率銘柄（シャープレシオ < 0.5）の特定と対処方針
- リスクフリーレートの妥当性（`0a_market_environment.md` の金利データ参照）

### 2. VaR(95%)/CVaR の水準と許容度
- `05_shared_calculations.md` のVaR/CVaR数値を引用
- 月間VaRの生活費換算（「月給のX%に相当する損失リスク」）
- CVaRによるテールリスクの評価（VaRを超えた場合の平均損失）
- データ点数による信頼度の議論（6-11ヶ月: 参考値、12ヶ月以上: 本格値）

### 3. 最大ドローダウンの分析
- `05_shared_calculations.md` のドローダウンデータを引用
- ピーク→ボトムの期間と回復期間の評価
- 資産額換算での影響度（「X万円の含み損が最大Y日間続いた」）
- 過去のドローダウンからの回復パターン

### 4. ストレスシナリオ（過去の暴落時の推定損失）
- `05_shared_calculations.md` のストレスシナリオテーブルを引用
- 米国テック-20%、全世界株式-15%、円高進行等のシナリオ別影響
- 発生確率と市場環境根拠の議論
- 資産換算での具体的損失額と月収換算
- 経済象限シナリオ（ダリオ型4象限）との連携

### 5. リスク調整後リターンの銘柄間比較
- シャープレシオランキングの上位・下位を比較
- 「ハイリスク・ローリターン」銘柄の特定
- 入替候補の検討（同カテゴリ内でより効率的な銘柄はないか）

### 6. 現金比率とリスクバジェット
- 現在の現金比率の妥当性（防御力 vs 機会損失）
- 200MAシグナルに基づく動的現金比率の検討
- リスクバジェットの配分（どの銘柄にどれだけのリスクを割り当てるべきか）

### 7. マクロ→個別への因果連鎖分析
- `0a_market_environment.md` の感応度マッピングを起点に、マクロ変数からポートフォリオへの因果チェーンを定量的に追跡する
  - 金利動向 → 債券ETF価格変動 → ポートフォリオDD（最大ドローダウン）への影響
  - 為替動向 → 外国株ETF（S&P500連動等）→ リターン寄与の増減
  - 地政学リスク → 特定セクターETF → 集中リスクの顕在化
- 各因果チェーンに `05_shared_calculations.md` のβ値・相関係数を紐づけて定量評価する
- `0a_market_environment.md` が未取得の場合はスキップ可
