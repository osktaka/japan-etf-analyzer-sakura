# Phase 0a: 市場環境調査 指示書

## 前提

- 作業ディレクトリ: `{WORK_DIR}`（メインエージェントから渡される）
- Docker内パス: `/app/{WORK_DIR}`

## データ受け渡しルール

- **入力**: なし
- **出力**: 収集結果を `{WORK_DIR}/0a_market_environment.md` に保存
- **メインへの戻り値**: 完了メッセージ1行のみ。データ全文やテーブル全体を返さないこと

## スキップ判断基準

このフェーズにスキップ条件はない。常に実行する。

---

## 収集手順

**重要**: 主要指標（日経平均、TOPIX、ドル円、S&P500等）は必ず**終値（確定値）**を取得すること。取引時間中の場合は前営業日の終値を使用し、「前営業日終値」と明記する。

### 時点統一ルール

全ての主要指標は**同一基準日（前営業日終値）**で揃える。日付は必ず YYYY-MM-DD 形式で併記すること。基準日が異なる指標がある場合は、その旨を明記し、可能な限り同一日のデータを再取得する。

### ソース出典ルール

定量数値（指数値、利回り、為替レート等）には**出典URLを必須**で付記する。出典URLが取得できない場合は断定表現を禁止し、「推定」と明記すること。例: 「日経平均: 約38,000円（推定・出典未確認）」

1. WebSearchで以下のキーワードを検索（3回程度に分けて並行実行）
   - 「日本 ETF 市場 最新動向」
   - 「日経平均 終値 今日」または「日経平均 終値 YYYY年M月D日」（**取引時間中の場合は前営業日を指定**）
   - 「日本国債 10年 利回り 最新」（リスクフリーレート取得用）
   - 「米国株 経済指標 最新」
2. 必要に応じてWebFetchで詳細情報を取得
3. 取得した情報を以下の形式でまとめる

**注意**: 取引時間中の値（例: 日経平均57,731円）と終値（例: 56,942円）では大きく乖離する場合がある。必ず終値を取得すること。

## まとめ形式

- 主要指標は以下のテーブル形式で記載する（**終値または前営業日終値を明記**）:

| 指標 | 基準日 | 値 | 前日比 | 出典 |
|------|--------|-----|--------|------|
| 日経平均株価 | YYYY-MM-DD | XX,XXX円 | +X.X% | URL |
| TOPIX | YYYY-MM-DD | X,XXX | +X.X% | URL |
| ドル円 | YYYY-MM-DD | XXX.XX円 | +X.XX円 | URL |
| 米10年債利回り | YYYY-MM-DD | X.XX% | +X.XXbp | URL |
| 日本国債10年利回り | YYYY-MM-DD | X.XX% | +X.XXbp | URL |

  - 基準日は全指標で統一する（時点統一ルール参照）
  - 出典URLが取得できない場合は「推定」と記載（ソース出典ルール参照）
- 最近の政治経済トピックを箇条書き5-10項目
- 分析への示唆（市場環境が保有銘柄に与える影響）
  - 例: 円安傾向なら外貨建て資産の評価額が上振れ、為替リスクにも注意
  - 例: 金利上昇局面なら債券ETFの価格下落リスク、金融セクターには追い風
  - 例: 地政学リスク高まりならディフェンシブ銘柄・ゴールドの評価を上方修正
  - 各示唆には、影響を受ける経済情勢タグ名を付記する（Phase 1のモメンタム連関分析で使用）
  - 例: 金利上昇局面 → 影響タグ: 「金利上昇」に追い風、「金利低下」に逆風
  - 例: 円安傾向 → 影響タグ: 「円安」に追い風、「円高」に逆風
  - ※ タグ名はPhase 1の補助情報として使用。判定はパフォーマンス実績と併用される

### リスクフリーレート

`0a_market_environment.md` の末尾に以下のフォーマットで記載する（Phase 1のシャープレシオ計算で使用）:

**取得手順（優先順位）**:
1. **公的ドメイン限定WebSearch**: `日本国債10年利回り site:mof.go.jp OR site:boj.or.jp` で検索し、最新の値を取得する
2. 数値抽出の成功判定: 検索結果から `X.XX%` 形式の数値（正規表現 `\d+\.\d+%`）が抽出できること
3. 取得失敗時（検索結果なし、数値抽出失敗、公的機関以外のソースのみ）: 即座にフォールバック値 **0.5%** を使用

```
## リスクフリーレート
- 日本国債10年利回り: X.XX%（YYYY年M月D日時点）
- 取得元: [公的機関のURL]（必須）
```

取得できなかった場合:
```
## リスクフリーレート
- 日本国債10年利回り: フォールバック値 0.5% を使用
- 理由: 公的機関からの取得失敗
```
