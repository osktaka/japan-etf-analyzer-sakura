## 収集手順

**重要**: 主要指標（日経平均、TOPIX、ドル円、S&P500等）は必ず**終値（確定値）**を取得すること。

### 基準日の決定ルール

基準日は以下のロジックで決定する:

1. **東証取引終了後（JST 16:00以降）に実行**: **当日終値**を基準日とする
2. **東証取引時間中（JST 9:00〜15:30）に実行**: **前営業日終値**を基準日とし、「前営業日終値」と明記する
3. **東証取引開始前（JST 9:00未満）に実行**: **前営業日終値**を基準日とする
4. **休日・祝日に実行**: **直近営業日の終値**を基準日とする

※ 16:00を閾値とするのは、東証の終値確定（15:30閉場）から余裕を持たせるため。

### 時点統一ルール

全ての主要指標は**同一基準日**で揃える。基準日は上記「基準日の決定ルール」に従い、日付を必ず YYYY-MM-DD 形式で併記すること。基準日が異なる指標がある場合は、その旨を明記し、可能な限り同一日のデータを再取得する。

### ソース出典ルール

定量数値（指数値、利回り、為替レート等）には**出典URLを必須**で付記する。出典URLが取得できない場合は断定表現を禁止し、「推定」と明記すること。例: 「日経平均: 約38,000円（推定・出典未確認）」

1. WebSearchで以下のキーワードを検索（3回程度に分けて並行実行）
   - 「日本 ETF 市場 最新動向」
   - 「日経平均 終値 YYYY年M月D日」（**基準日の決定ルールに従い、当日or前営業日を指定**）
   - 「日本国債 10年 利回り 最新」（リスクフリーレート取得用）
   - 「米国株 経済指標 最新」
2. 必要に応じてWebFetchで詳細情報を取得
3. 取得した情報を以下の形式でまとめる

**注意**: 取引時間中の値（例: 日経平均57,731円）と終値（例: 56,942円）では大きく乖離する場合がある。必ず終値を取得すること。

## まとめ形式

- 主要指標は以下のテーブル形式で記載する（**終値または前営業日終値を明記**）:

| 指標 | 基準日 | 値 | 前日比 | 出典 |
|------|--------|-----|--------|------|
| 日経平均株価 | YYYY-MM-DD | XX,XXX円 | +X.X% | URL |
| TOPIX | YYYY-MM-DD | X,XXX | +X.X% | URL |
| ドル円 | YYYY-MM-DD | XXX.XX円 | +X.XX円 | URL |
| 米10年債利回り | YYYY-MM-DD | X.XX% | +X.XXbp | URL |
| 日本国債10年利回り | YYYY-MM-DD | X.XX% | +X.XXbp | URL |

  - 基準日は全指標で統一する（時点統一ルール参照）
  - 出典URLが取得できない場合は「推定」と記載（ソース出典ルール参照）
- 最近の政治経済トピックを箇条書き5-10項目
- 分析への示唆（市場環境が保有銘柄に与える影響）
  - 例: 円安傾向なら外貨建て資産の評価額が上振れ、為替リスクにも注意
  - 例: 金利上昇局面なら債券ETFの価格下落リスク、金融セクターには追い風
  - 例: 地政学リスク高まりならディフェンシブ銘柄・ゴールドの評価を上方修正
  - 各示唆には、影響を受ける経済情勢タグ名を付記する（Phase 1のモメンタム連関分析で使用）
  - 例: 金利上昇局面 → 影響タグ: 「金利上昇」に追い風、「金利低下」に逆風
  - 例: 円安傾向 → 影響タグ: 「円安」に追い風、「円高」に逆風
  - ※ タグ名はPhase 1の補助情報として使用。判定はパフォーマンス実績と併用される

### ポートフォリオ感応度マッピング

取得した市場指標と保有銘柄カテゴリの感応度を3段階でマッピングし、以下のテーブル形式で記載する。
保有銘柄情報は `{WORK_DIR}/00_portfolio_data.json` から取得する（Phase 0で収集済み）。

```
## ポートフォリオ感応度マッピング

| 市場要因 | 現在の動向 | 影響銘柄 | 感応度 | 順風/逆風 |
|---------|-----------|---------|--------|---------|
| 円安進行 | ドル円XXX円台 | 2558(全世界株式)等 | 高/中/低 | 順風/逆風（理由） |
| 金利上昇 | 日本10年債X.XX% | 2621(米国債)等 | 高/中/低 | 順風/逆風（理由） |
| ... | ... | ... | ... | ... |
```

- 市場要因は、上記「主要指標」テーブルの各指標から導出する（追加の検索は不要）
- 感応度の判定基準: **高**=当該要因で評価額が5%以上変動しうる、**中**=1-5%、**低**=1%未満
- 保有銘柄が多い場合は、影響度「高」の組み合わせを優先して記載する

### 経済象限判定

現在の市場環境が以下の4象限のどれに該当するかを判定し、記載する:

```
## 経済象限判定

- **現在の象限**: 成長+インフレ / 成長+デフレ / 停滞+インフレ / 停滞+デフレ
- **判定根拠**: {GDP成長率・CPI・景況感指数等の根拠を簡潔に}
- **象限別推奨アセット配分**:
  - 成長+インフレ: 株式・コモディティ優位、債券不利
  - 成長+デフレ: 株式・債券優位、コモディティ不利
  - 停滞+インフレ: コモディティ・短期債優位、株式不利
  - 停滞+デフレ: 長期債・現金優位、株式・コモディティ不利
- **現在のポートフォリオとの整合性**: {現在の保有アセット配分が象限推奨と合致しているか1-2文で評価}
```

- 判定に必要な情報は「主要指標」と「政治経済トピック」から導出する（追加の検索は不要）
- 判定が困難な場合（象限の境界にある等）は「○○寄りの△△」と記載し、両方の象限の推奨を参照するよう促す

#### 定量的判定ルール（ロバスト性向上）

**判定に使う3指標**:
1. **GDP成長率（前期比）**: 直近四半期の実質GDP成長率。プラス→「成長」、マイナス→「停滞」
2. **CPI前年比**: 消費者物価指数の前年同月比。2%超→「インフレ」、2%以下→「デフレ（低インフレ）」
3. **日銀短観・景況感指数（業況判断DI）**: プラス→「成長」寄り、マイナス→「停滞」寄り

**各指標の3段階判定**:

| 指標 | 上昇 | 横ばい | 下降 |
|------|------|--------|------|
| GDP成長率 | > +0.5% | -0.5%〜+0.5% | < -0.5% |
| CPI前年比 | > 2.5% | 1.0%〜2.5% | < 1.0% |
| 短観DI | > +10 | -5〜+10 | < -5 |

**多数決ルール**:
- 3指標中2つ以上が「成長」方向 → 成長象限
- 3指標中2つ以上が「停滞」方向 → 停滞象限
- インフレ/デフレは CPI を主軸とし、GDP・短観を補助判断に使用
- **境界ケース（全てバラバラ等）**: 隣接2象限のアセット配分をブレンドして推奨する

**確信度**:
- 3/3一致 = **高**（象限確定）
- 2/3一致 = **中**（象限確定、少数派指標を注記）
- 全てバラバラ = **低**（境界ケース、隣接象限をブレンド）

**トレンド判定ルール**: 前日と判定が変わるリスクを低減するため、各指標は**3ヶ月方向（トレンド）**で判定する。単月の変動で象限を切り替えない。具体的には直近3ヶ月の移動方向（改善/横ばい/悪化）を判定根拠とする。

**出力フォーマット（必須）**: 以下の項目を必ず含めること。Phase 0.5（項目13）およびreport-guide.mdセクション8.5で参照される。

```
- **現在の象限**: {4象限のいずれか}
- **判定根拠**: {GDP成長率・CPI等の定量根拠を1-2文}
- **推奨アセット配分**: {象限に応じた適性アセット}
- **ポートフォリオ整合性評価**: {現在の保有配分が象限推奨と合致しているか1-2文}

### 3指標判定（経済象限のロバスト性向上用）
- GDP成長率: {値}%（判定: 上昇/横ばい/下降、3ヶ月トレンド: 改善/横ばい/悪化）
- CPI前年比: {値}%（判定: 上昇/横ばい/下降、3ヶ月トレンド: 改善/横ばい/悪化）
- 短観DI: {値}（判定: 上昇/横ばい/下降、3ヶ月トレンド: 改善/横ばい/悪化）
- **確信度**: 高/中/低
- **境界ケース時のブレンド推奨**: {該当する場合のみ記載}
```

### リスクフリーレート

`0a_market_environment.md` の末尾に以下のフォーマットで記載する（Phase 1のシャープレシオ計算で使用）:

**取得手順（優先順位）**:
1. **公的ドメイン限定WebSearch**: `日本国債10年利回り site:mof.go.jp OR site:boj.or.jp` で検索し、最新の値を取得する
2. 数値抽出の成功判定: 検索結果から `X.XX%` 形式の数値（正規表現 `\d+\.\d+%`）が抽出できること
3. 取得失敗時（検索結果なし、数値抽出失敗、公的機関以外のソースのみ）: 即座にフォールバック値 **0.5%** を使用

```
## リスクフリーレート
- 日本国債10年利回り: X.XX%（YYYY年M月D日時点）
- 取得元: [公的機関のURL]（必須）
```

取得できなかった場合:
```
## リスクフリーレート
- 日本国債10年利回り: フォールバック値 0.5% を使用
- 理由: 公的機関からの取得失敗
```
