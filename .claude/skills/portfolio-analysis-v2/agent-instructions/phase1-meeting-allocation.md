## 議論の焦点（必ず取り上げるべき論点）

### 1. 相関分析（銘柄間相関行列、高相関ペアの特定）
- `05_shared_calculations.md` の相関行列テーブルを引用
- 高相関ペア（相関 > 0.8）の特定と分類ラベル（実質重複/高リスク連動型/不安定相関等）
- 「実質重複」ペアの整理方針（信託報酬の安い方に一本化すべきか）
- 「高リスク連動型」のSR段階別処理（SR ≥ 2.5は許容、SR < 1.5は整理推奨）
- 低相関ペアの分散効果の評価
- 危機時の相関上昇リスク（平時の低相関が暴落時に高相関化する可能性）

### 2. セクター/テーマ配分の偏り（タグデータ活用）
- `00_portfolio_data.json` の `tag_data` を引用
- 地域タグの分布（日本国内/先進国/新興国）
- セクタータグの分布（テクノロジー/金融/ヘルスケア等）
- テーマタグの分布（高配当/ESG/AI・半導体等）
- 特定セクター/テーマへの過度な集中がないか検証
- 運用会社の集中リスク

### 3. 欠落しているアセットクラス（国際分散、債券、REIT等）
- 現在のポートフォリオに含まれていないアセットクラスの特定
- 国際分散の度合い（先進国株式/新興国株式/外国債券）
- 債券・REIT・コモディティ・ゴールド等の防御資産の有無
- 経済象限（ダリオ型4象限）に基づく欠落アセットの重要度評価
- 追加すべきアセットクラスの具体的なETF候補

### 4. 現金比率の適切性
- 現在の現金比率と総資産に占める割合
- 防御力としての現金（暴落時の買い増し余力）
- 機会損失としての現金（過大な現金保有はリターンを圧迫）
- 200MAシグナルに基づく動的現金比率の提案
- ドルコスト平均法との組み合わせ検討

### 5. HHI（集中度指数）の評価
- `05_shared_calculations.md` のHHI値を引用（存在する場合）
- HHI値の解釈（0.15未満: 分散良好、0.15-0.25: やや集中、0.25超: 集中）
- 銘柄数が少ない場合の集中リスク
- 上位3銘柄の保有比率合計

### 6. 配分比率の最適化提案
- 現在の配分比率 vs 理想的な配分比率
- リスクパリティベースでの再配分案
- 段階的リバランスの手順提案（一度に大きく変更しない）
- コスト（売却益課税・信託報酬）を考慮した実行可能な提案

### 7. トップダウンアロケーション評価
- 経済象限判定（`0a_market_environment.md` または `05_shared_calculations.md` のダリオ型4象限）に基づく理想的アセットクラス配分を導出する
- 理想配分 vs 現在のポートフォリオ配分のギャップ分析を行う
  - 各アセットクラス（株式/債券/REIT/コモディティ/現金）の乖離幅を定量化
  - 乖離が10%以上のアセットクラスは「要対応」としてリバランス方向を具体的に提案する
- 経済象限が変化した場合（前回分析時からの移行）の配分変更インパクトも議論する
- `0a_market_environment.md` が未取得の場合はスキップ可
