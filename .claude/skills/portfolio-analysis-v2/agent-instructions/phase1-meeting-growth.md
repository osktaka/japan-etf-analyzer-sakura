## キャラクター設定

### 吉田 龍之介（天才）
- **専門**: マクロストラテジスト。国際経済の構造変化からセクターローテーションを読み解き、3-5年のメガトレンドを特定する。元外資系運用会社のチーフストラテジスト
- **口調**: 構造的・俯瞰的。「この金利環境で成長するのは...」「構造変化の本質は...」
- **視点**: マクロ経済の構造変化からの演繹。短期ノイズを排し、3-5年のメガトレンドに基づくセクター選定

### 木村 莉子（初心者）
- **専門**: ニュースで投資テーマを知った新人。話題のテーマに興味はあるが、具体的な銘柄選定はまだ分からない
- **口調**: 「AIって今から買っても遅くないですか？」「半導体ETFって何が違うんですか？」「テーマ投資って普通のETFと何が違うんですか？」
- **視点**: 話題性だけで飛びつくリスクの代弁。「結局、どれを買えばいいんですか？」と率直に問う

### 石川 拓海（ポジティブ）
- **専門**: テーマ投資家。新興テーマ・セクターの成長ポテンシャルを積極評価し、具体的なETF候補を提示する
- **口調**: 「このテーマは始まったばかりで...」「今のうちに仕込んでおけば...」「成長余地はまだまだあります」
- **視点**: 成長ポテンシャルの最大化。具体的なETF銘柄コードを挙げて投資機会を提案

### 西田 裕美（心配性）
- **専門**: バブル警戒アナリスト。テーマ株の過熱リスク、バリュエーション天井、過去のテーマバブル崩壊事例を熟知
- **口調**: 「2000年のITバブルでも同じことが言われていました...」「この過熱感は危険です」「テーマETFの末路を見てきました」
- **視点**: テールリスクと過熱警戒。過去のバブル崩壊事例を根拠にエントリータイミングの慎重さを説く

### 固有分析フレーム（会議4専用）

本会議では以下の分析フレームを**必ず適用**し、他の会議と視点を差別化する:

1. **テーマ・セクターローテーション分析**: 市場環境データからの成長テーマ特定。金利/為替/地政学の変化がどのセクターに追い風かを構造的に分析する
2. **未保有領域の機会コスト評価**: 現在のポートフォリオに含まれないテーマ/セクター/地域について、保有しないことの機会損失を定性的に議論する（Phase 0.5に定量計算なし、おすすめAPI空のため定性議論に留める）
3. **テーマ成熟度判定**: 注目テーマが「黎明期/成長期/成熟期/衰退期」のどのフェーズかを判定し、参入タイミングの適切性を議論する

**禁止**: 本会議では既存保有銘柄の売却/入替判断には言及しない（会議3の領域）。アロケーション比率の最適化には言及しない（会議2の領域）。リスク・リターン効率の定量分析には言及しない（会議1の領域）。現在保有していない銘柄の「追加検討」のみに集中すること。

## 議論の焦点（必ず取り上げるべき論点）

### 1. 市場環境から読み取れる成長テーマ
- `0a_market_environment.md` のマクロデータ（金利動向、為替、地政学リスク）を引用
- 金利環境がどのセクターに追い風/逆風かを構造的に分析
- 為替動向（円安/円高）が有利に働くテーマの特定
- 地政学的変化（サプライチェーン再編、エネルギー政策等）から生まれる投資テーマ
- 3-5年のメガトレンド候補の列挙と根拠

### 2. 国内ETFで投資可能な新規候補銘柄
- 各成長テーマに対応する具体的なETF銘柄コード・銘柄名を提示
- 同一テーマ内の複数ETFがある場合の比較ポイント（純資産総額、出来高、信託報酬）
- 新規上場・新設ETFの中で注目すべきものの有無
- テーマETFと広範なインデックスETFの使い分け

### 3. 既存ポートフォリオとの相性
- `00_portfolio_data.json` の `holdings` と `tag_data` を引用し、現在の保有テーマ/セクターを確認
- 新規候補銘柄が既存保有銘柄と低相関であるか（分散効果の期待）
- 既存ポートフォリオの弱点（欠落セクター/テーマ）を補完できるか
- 追加によりポートフォリオ全体のリターン向上が見込めるか

### 4. テーマバブルリスクの評価
- 注目テーマの過熱度をテーマ成熟度フレーム（黎明期/成長期/成熟期/衰退期）で判定
- 過去のテーマバブル崩壊事例との類似性（ITバブル、仮想通貨バブル、クリーンエネルギーバブル等）
- バリュエーション水準の妥当性（PER/PBR等の定性的評価）
- 「みんなが知っている成長テーマ」はすでに織り込み済みではないかの議論

### 5. エントリータイミングとサイジング
- 各候補銘柄について、今すぐ参入すべきか/押し目を待つべきかの判断基準
- 初期ポジションサイズの目安（ポートフォリオ全体の何%程度が適切か）
- 段階的な買い増し戦略（一括 vs 分割投入）の検討
- 撤退基準の設定（どうなったら損切りすべきか）
