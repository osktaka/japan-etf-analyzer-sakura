### 3.3 相関分析の注意事項

- 相関係数は値動きの「方向」のみを測り、「振れ幅（ベータ）」や「超過リターン」を反映しない。高相関でもリターン格差やベータ差が大きいペアは「高リスク連動型」として区別される
- 算出期間が短い（信頼度: 低）場合、相関係数の安定性が低いため長期判断への単独使用は避けること
- 「高リスク連動型」は市場と同方向に大きく動く銘柄であり、実質重複とは異なる。シャープレシオが高ければ効率的なリスクテイクとして評価できる
- 5銘柄未満のポートフォリオでは複合判定を適用せず、相関+リターン格差の2軸表示にフォールバックする

### 13.2 用語解説

| 用語 | 説明 |
|------|------|
| シャープレシオ | リスク1単位あたりのリターン。高いほど効率的 |
| VaR（バリュー・アット・リスク） | 一定確率で発生しうる最大損失額の推定値 |
| CVaR（条件付きVaR） | VaR超過時の平均損失額。テールリスク指標 |
| 最大ドローダウン | ピークからボトムまでの最大下落率 |
| 相関係数 | 2銘柄の値動き連動性（-1〜+1）。0に近いほど分散効果大 |
| ボラティリティ | 価格変動の大きさ。高いほどリスク大 |
| 信託報酬 | ETF運用管理の年間手数料。保有中自動差引 |
| モメンタム | 価格トレンドの方向性。上昇加速〜下降加速の5段階 |
| ベータ | 市場全体に対する値動きの感応度。1より大きいと市場より大きく動く |
| 追跡誤差（トラッキングエラー） | 2銘柄の月次リターン差のばらつき（年率換算）。小さいほど似た動き |
| 高リスク連動型 | 高相関だがリターン格差やベータ差が大きいペア。実質重複とは異なり、意図的な高リスクテイクとして機能しうる |
| 合意レベル | 4会議間の結論一致度。全会議一致（4/4）、3会議以上一致（3/4以上）、意見分裂（各会議で異なる結論） |

- セクション9（議論サマリー）以外では、会議キャラクター名（高橋、佐藤、天才、心配性、ポジティブ等）を直接引用しない
