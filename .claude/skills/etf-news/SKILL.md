# ETF ニュース取得スキル

```yaml
---
name: etf-news
description: 東証ETFの最新ニュース・情報を取得
user-invocable: true
allowed-tools: WebSearch, WebFetch, Read
aliases: ["/etf-news"]
---
```

## 概要

東証ETF関連の最新ニュースをWeb検索で取得し、投資判断に役立つ形式で整理して提供する。

## 使用方法

```
/etf-news                    # 全般ニュース（デフォルト）
/etf-news 新規上場            # 新規上場・廃止情報
/etf-news 分配金              # 分配金・決算情報
/etf-news 信託報酬            # 信託報酬変更情報
/etf-news 指数                # 指数動向ニュース
```

## 実行フロー

```
1. カテゴリ判定
   └─ 引数があればカテゴリ特定、なければ「全般」
        ↓
2. 検索クエリ生成
   └─ カテゴリに応じたクエリ + 現在年を付与
        ↓
3. WebSearch実行
   └─ 日本語ニュースを検索
        ↓
4. 結果整形
   └─ 投資判断に使える形式で出力
        ↓
5. ソース一覧付与
   └─ 参照元URLをリスト表示
```

## カテゴリ別検索クエリ

| カテゴリ | キーワード | 検索クエリ |
|----------|-----------|-----------|
| 全般（デフォルト） | なし / `全般` | `東証 ETF ニュース {現在年}` |
| 新規上場 | `新規上場` / `上場` / `廃止` | `ETF 新規上場 東証 {現在年}` |
| 上場廃止 | `上場廃止` / `廃止` / `繰上償還` | `ETF 上場廃止 繰上償還 {現在年}` |
| 信託報酬 | `信託報酬` / `コスト` / `手数料` | `ETF 信託報酬 引き下げ 変更 {現在年}` |
| 分配金 | `分配金` / `配当` / `決算` | `ETF 分配金 決算 {現在年}` |
| 指数動向 | `指数` / `TOPIX` / `日経` | `TOPIX 日経平均 ETF 動向 {現在年}` |

**注意**: `{現在年}` は実行時の年（例: 2026）に置換する。

   [要約（2-3文で投資判断に関係する内容を抽出）]


2. **[ニュースタイトル]** - [発信元] [日付]
   [要約]


3. **[ニュースタイトル]** - [発信元] [日付]
   [要約]

---
Sources:
- [ソース名1](URL1)

**重要**: 各ニュース記事の間には必ず空行を1行入れること。上記のように要約の後に空行を入れてから次の番号を記載する。

## エラー時の対応

### 検索結果が0件の場合

```markdown
## 東証ETFニュース（YYYY-MM-DD）

### [カテゴリ名]

検索結果が見つかりませんでした。

**代替案**:
- 別のカテゴリで検索: `/etf-news 全般`
- JPX公式サイトを直接確認: https://www.jpx.co.jp/equities/products/etfs/
```

### WebSearchが失敗した場合

JPX公式サイトからWebFetchで情報取得を試行する:

```
WebFetch: https://www.jpx.co.jp/equities/products/etfs/issues/01.html
→ 新規上場ETF情報を抽出
```

## 投資判断に役立つ情報の抽出ポイント

### 重視する情報

- 新規ETF上場（投資機会の拡大）
- 信託報酬引き下げ（コスト改善）
- 分配金増減（インカム収入への影響）
- 上場廃止・繰上償還（保有銘柄への影響）
- 指数の構成銘柄変更（パフォーマンスへの影響）

## 銘柄推薦時の基準

具体的なETF銘柄を推薦する際は、以下の観点を総合的に評価すること。

### 必須評価項目

| 項目 | 確認内容 | 良い基準 |
|------|----------|----------|
| 信託報酬 | 年間コスト | 0.3%以下が望ましい |
| 配当利回り | 実績分配金利回り | テーマに応じて比較 |
| 純資産総額 | 流動性・安定性 | 100億円以上推奨 |
| 出来高 | 売買のしやすさ | 日次1万口以上 |
| トータルリターン | 過去1年・3年実績 | 同カテゴリ内で比較 |

### 推薦時の出力フォーマット

```markdown
| コード | 銘柄名 | 信託報酬 | 配当利回り | 純資産 | 1年リターン | 総合評価 |
|--------|--------|----------|------------|--------|-------------|----------|
| XXXX | ○○ETF | 0.XX% | X.X% | XXX億円 | +XX% | ★★★☆☆ |
```

### 評価の観点

1. **コスト効率**: 信託報酬が同カテゴリ内で低いか
2. **インカム**: 配当利回りが魅力的か（高配当なら3%以上）
3. **成長性**: 過去リターンやテーマの将来性
4. **流動性**: 純資産・出来高が十分か
5. **リスク**: ボラティリティ、集中度

**重要**: 単にコストが低い、または配当が高いだけでなく、総合的に利益を目指せる銘柄を推薦すること。

### 銘柄コード確認ルール（必須）

銘柄コードを提示する前に、必ず以下の手順で存在確認を行うこと。

**確認方法**:
1. WebSearchで「東証 ETF {銘柄コード} {銘柄名}」を検索
2. JPX公式サイトまたはYahoo!ファイナンスで該当銘柄が表示されることを確認
3. 確認できない場合は提示しない

**禁止事項**:
- 記憶や推測だけで銘柄コードを提示すること
- 確認せずに「〜だと思う」で銘柄を挙げること

**確認済みの印**:
銘柄表に「✓確認済」列を追加するか、Sources欄に確認元URLを記載する。

## トレンド判断基準

銘柄・テーマを推薦する際は「これから上昇期待」のものを優先すること。

### 推薦すべきテーマの条件

| 条件 | 説明 | 検索キーワード例 |
|------|------|-----------------|
| 出遅れ・割安 | まだ上昇していない、PBR低い | 出遅れ 割安 PBR1倍割れ |
| 初動・本格化前 | 政策発表直後、これから需要拡大 | 初動 これから 本格化 |
| 構造的追い風 | 長期トレンドの恩恵がこれから | 脱デフレ 金利正常化 |

### 避けるべきテーマの特徴

| 特徴 | 説明 |
|------|------|
| 既にピーク | 前年に大幅上昇済み、「一服」報道あり |
| 織り込み済み | 好材料が株価に反映済み |
| 物色一巡 | 主要銘柄が買われ尽くした |

### テーマ成熟度の判断

```
【初動】→【成長期】→【成熟期】→【一服】
   ↑推薦     ↑推薦      △注意     ×避ける
```

**検索時の工夫**: 「これから」「出遅れ」「初動」「本格化」「割安」などのキーワードを追加して検索する。

### 要約に含めるべき内容

- **何が**（対象ETF、指数）
- **どうなるか**（変更内容、影響）
- **いつから**（適用日、基準日）
- **投資家への影響**（メリット/デメリット）
