# 東証取引見通しスキル

```yaml
---
name: market-outlook
description: 今日の東証取引見通し（米国市場・CME日経先物・政治経済情報ベース）
user-invocable: true
allowed-tools: Read, Bash, Task
aliases: ["/market-outlook"]
---
```

## 概要

朝の取引前に、米国市場・CME日経先物・為替・政治経済ニュースを総合的に収集・分析し、当日の東証取引見通しを提供するスキル。一般モードとポートフォリオモードの2種類を備え、デモポートフォリオ保有銘柄への影響分析にも対応する。

データ収集・検証はサブエージェントに委譲し、メインエージェントは総合判断と出力整形に専念する。

## 使用方法

```
/market-outlook                # 一般モード（市場全体の見通し）
/market-outlook portfolio      # ポートフォリオモード（保有銘柄への影響分析を追加）
```

## 実行フロー

```
1. モード判定（メイン）
   ├─ 引数なし → general / "portfolio" → portfolio
   └─ 日付パラメータを算出（date, prev_business_day）
        ↓
2. データ収集+検証（サブエージェント）
   ├─ Task(general-purpose) で agent-instructions/market-data-collection.md に従い実行
   └─ 構造化Markdownが返却される
        ↓
3. 総合判断・テンプレート出力（メイン）
   ├─ サブエージェントの戻り値を元に総合判断を作成
   └─ 出力フォーマットに従い整形・出力
```

## サブエージェント起動プロンプト

```
以下の指示書を読み、市場データの収集と検証を実行してください。

指示書: .claude/skills/market-outlook/agent-instructions/market-data-collection.md

パラメータ:
- mode: {mode}
- date: {date}
- prev_business_day: {prev_business_day}

指示書内の {mode}, {date}, {prev_business_day} を上記パラメータで読み替えてください。
{year_month} は {date} の年月部分です。

戻り値は指示書の出力テンプレート形式のみで返却してください。
```

## コンテキスト管理ルール

- `agent-instructions/` 配下のファイルはメインエージェントが直接読まない（サブエージェントが読む）
- サブエージェントの戻り値は構造化テーブルのみ（生テキスト・HTML断片は含まない）

## フォールバックルール

- サブエージェントの戻り値に `portfolio取得失敗` が含まれる場合、一般モードとして出力し、その旨を明記する

## 出力フォーマット（ポートフォリオモード追加セクション）

一般モードの出力に**加えて**、「主要リスク要因」の後に以下のセクションを追加する。

```markdown

| コード | 銘柄名 | 保有比率 | 今日の影響 | 要因 |
|--------|--------|---------|-----------|------|
| XXXX | ○○ETF | XX% | {追い風/逆風/中立} | {一言理由} |

### ポートフォリオ総合評価

{保有銘柄全体としてのマーケット環境影響を2-3文で分析}
```
