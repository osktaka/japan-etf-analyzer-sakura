# 東証取引見通しスキル

```yaml
---
name: market-outlook
description: 今日の東証取引見通し（米国市場・CME日経先物・政治経済情報ベース）
user-invocable: true
allowed-tools: WebSearch, WebFetch, Read, Bash
aliases: ["/market-outlook"]
---
```

## 概要

朝の取引前に、米国市場・CME日経先物・為替・政治経済ニュースを総合的に収集・分析し、当日の東証取引見通しを提供するスキル。一般モードとポートフォリオモードの2種類を備え、デモポートフォリオ保有銘柄への影響分析にも対応する。

`Bash` ツールは、ポートフォリオモードで `curl localhost:8902` によるAPI取得に必要（WebFetchはlocalhost不可のため）。

## 使用方法

```
/market-outlook                # 一般モード（市場全体の見通し）
/market-outlook portfolio      # ポートフォリオモード（保有銘柄への影響分析を追加）
```

## 実行フロー

```
1. モード判定
   └─ 引数なし → 一般モード / "portfolio" → ポートフォリオモード
        ↓
2. 市場データ収集（WebSearch 3並行）
   ├─ A: 米国市場 + CME日経先物
   ├─ B: 東証・為替
   └─ C: 政治経済ニュース
        ↓
3. [portfolioモードのみ] 保有銘柄取得 + 影響分析
   └─ Bash: curl -s http://localhost:8902/api/v1/demo/portfolio/holdings
        ↓
4. 見通し分析・出力
   └─ テンプレートに従い結果を整形
        ↓
5. ソース一覧付与
```

## 検索クエリ定義

| クエリ | 検索文字列 |
|--------|-----------|
| A: 米国市場 | `S&P500 ナスダック ダウ CME日経先物 終値 {日付}` |
| B: 東証・為替 | `日経平均 TOPIX 終値 ドル円 {前営業日}` |
| C: 政治経済 | `日本 経済 金融政策 マーケット 見通し {現在年月}` |

**注意**: `{日付}` `{前営業日}` `{現在年月}` は実行時に実際の日付・年月に置換する。
- `{日付}`: 本日の日付（例: 2026年2月20日）
- `{前営業日}`: 直前の東証営業日（土日祝を除く）
- `{現在年月}`: 現在の年月（例: 2026年2月）

## 時間帯別ルール（JST）

| 実行タイミング（JST） | 米国市場データ | 東証データ | 見通しの対象 |
|----------------------|--------------|-----------|------------|
| 6:00-9:00（推奨） | 前夜の終値 | 前営業日終値 | 当日の東証 |
| 9:00-15:00 | 前夜の終値 | 当日途中経過に言及 | 後場/翌日 |
| 15:00-翌6:00 | 取引中 or 前日終値 | 当日終値 | 翌営業日 |

**重要**: phase0a-market-research.mdの教訓に従い、全指標は**終値（確定値）**を優先する。リアルタイム値を使う場合は「取引中の値」と必ず明記すること。取引時間中の値と終値では大きく乖離する場合があるため、確定値の使用を徹底する。

## 出力フォーマット（ポートフォリオモード追加セクション）

一般モードの出力に**加えて**、「主要リスク要因」の後に以下のセクションを追加する。

```markdown
### デモポートフォリオへの影響

| コード | 銘柄名 | 保有比率 | 今日の影響 | 要因 |
|--------|--------|---------|-----------|------|
| XXXX | ○○ETF | XX% | {追い風/逆風/中立} | {一言理由} |

### ポートフォリオ総合評価

{保有銘柄全体としてのマーケット環境影響を2-3文で分析}
```

**ポートフォリオAPI呼び出し方法**:

```bash
curl -s http://localhost:8902/api/v1/demo/portfolio/holdings
```

- レスポンスはJSON配列（各銘柄のcode, name, current_value, weight等を含む）
- 保有比率上位5銘柄に絞って影響分析を行う
- Docker環境（`docker compose up -d`）が起動している必要がある

## 情報ソース優先順位

| 優先度 | ソース | 特徴 |
|--------|--------|------|
| 1 | 日本経済新聞 | 速報性、市況分析 |
| 2 | Bloomberg / Reuters | グローバル市場データ |
| 3 | Yahoo!ファイナンス | 国内市場データ |
| 4 | 各種経済メディア | 補足情報 |

## エラーハンドリング

| 状況 | 対応 |
|------|------|
| WebSearch結果0件 | クエリを変えて再検索（日付なし版で再試行） |
| WebSearch完全失敗 | WebFetchで日経新聞サイト等に直接アクセス |
| CME日経先物取得不可 | 「取得失敗」と明記し他指標で見通し作成 |
| ポートフォリオAPI失敗 | 一般モードにフォールバックし、その旨を明記 |
