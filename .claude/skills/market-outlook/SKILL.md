# 東証取引見通し・振り返りスキル

```yaml
---
name: market-outlook
description: 今日の東証取引見通し・振り返り（AM: 米国市場ベースの見通し / PM: 日本市場の結果レビュー）
user-invocable: true
allowed-tools: Read, Write, Bash, Agent, WebSearch, WebFetch
aliases: ["/market-outlook"]
---
```

## 概要

1日2回（AM/PM）実行に対応した東証マーケットスキル。

- **AM（見通し）**: 夜中の米国市場結果（S&P500・NASDAQ・CME日経先物・為替等）をベースに、当日の東証取引見通しを提供する
- **PM（振り返り）**: 日中の日本市場結果を集約し、値動きの要因分析・AM予想との比較を行う

一般モードとポートフォリオモードの2種類を備え、デモポートフォリオ保有銘柄への影響分析にも対応する。

## 処理時間・コンテキスト最適化

- **目標処理時間**: 15分以内（サブエージェントタイムアウト: 600秒）
- **WebSearchクエリ上限**: 合計5クエリ（AM: 2, PM: 3）
- **WebFetch上限**: 合計5URL
- **コンテキスト最小化**: yfinance取得済み数値のWebSearch再確認禁止、同一URL再アクセス禁止

### 処理フロー・タイムライン

| ステップ | 所要時間目安 | 内容 |
|---------|------------|------|
| 1. モード判定 | 〜10秒 | timing/mode判定、AMファイル存在確認 |
| 2. yfinanceデータ取得 | 〜90秒 | market_data_quick.py実行（11指標+テクニカル+クロスアセット+シグナル集計） |
| 3. WebSearch/WebFetch | 〜120秒 | 定性情報取得（AM: 2クエリ / PM: 3クエリ） |
| 4. ETF検索 | 〜30秒 | keyword→tag_ids→tag-momentumの3段フォールバック |
| 5. ドラフト生成 | 〜120秒 | テンプレートに基づくレポート生成 |
| 6. 自己検証 | 〜60秒 | 5カテゴリのチェック実行 |
| **合計** | **〜8分** | **30分上限の大幅内** |

**処理時間の制約**:
- WebSearchは1クエリあたり最大30秒でタイムアウト。応答がない場合はスキップ
- yfinanceは6mo分取得のため、ネットワーク状況で30-90秒の幅がある
- 全体で15分を超えた場合、WebFetch補完を省略して出力する

## パラメータ一覧

| パラメータ | 値 | 用途 |
|-----------|-----|------|
| VIX係数（通常） | 0.05% | シナリオ分析レンジ幅 |
| VIX係数（VIX>30） | 0.04% | 高VIX時の縮小係数 |
| 横ばい判定閾値 | ±0.5% | 的中判定の横ばい基準 |
| 微小変動閾値 | ±0.1% | 判定不能の基準 |
| 時間帯判定境界 | 15:30 JST | AM/PM自動判定 |
| 高ボラモード閾値 | VIX > 30 or 日経前日比 > ±3% | 高ボラモード発動 |
| 危機モード閾値 | VIX > 35 | 危機モード発動 |

**VIX係数の算出ロジック:**
- 通常時: `レンジ = CME ± (VIX × 0.05%)`（例: VIX=20 → CME±1.0%）
- VIX>30時: `レンジ = CME ± (VIX × 0.04%) × 1.5`（高ボラモードの1.5倍拡大適用後）
  - 0.04%への縮小は過大レンジ防止のダンパー。1.5倍拡大との組み合わせで適度な拡幅を実現
  - 例: VIX=35 → 基本: 35×0.04%=1.4% → ×1.5=2.1%（通常時35×0.05%=1.75%より広い）

## クロスアセット分析フレームワーク

プロのアナリストレポートに不可欠なクロスアセット分析を導入する。株式・債券・商品・為替の連動性を分析し、マクロ環境の全体像を提供する。

### リスクアペタイト判定

yfinanceデータから以下のシグナルを統合し、リスクアペタイト（市場のリスク選好度）を判定する:

| シグナル | リスクオン | リスクオフ | データソース |
|---------|-----------|-----------|-------------|
| VIX | < 20 | > 25 | yfinance |
| 金（Gold） | 下落 | 上昇 | yfinance (GC=F) |
| 米国債利回り | 上昇（景気楽観） | 下落（安全資産逃避） | yfinance (^TNX) |
| イールドカーブ | スティープニング | フラット化/逆転 | 算出値 (10Y-3M) |
| ドル円 | 円安（キャリー活発） | 円高（リスク回避） | yfinance |

**判定ルール:**
- **リスクオン**: 5シグナル中4つ以上がリスクオン方向
- **リスクオフ**: 5シグナル中4つ以上がリスクオフ方向
- **混合**: 上記以外

### 商品市場→東証セクター伝播マップ

| 商品 | 上昇時の恩恵セクター | 下落時の恩恵セクター |
|------|-------------------|-------------------|
| WTI原油 | エネルギー・資源、商社 | 化学、運輸・航空、電力・ガス |
| 金 | 金鉱株ETF | （直接的な悪影響は限定的） |

### イールドカーブ分析

| スプレッド(10Y-3M) | 状態 | 東証への示唆 |
|-------------------|------|------------|
| > 1.0% | ノーマル | 景気拡大期待、銀行・金融セクターに追い風 |
| 0〜1.0% | フラット | 景気減速懸念、ディフェンシブセクター選好 |
| < 0% | 逆転 | 景気後退リスク上昇、グロース→バリューシフトに注意 |

### マクロレジーム分類

クロスアセットシグナルの組み合わせから、現在のマクロレジームを4分類する:

| レジーム | 条件 | 東証への示唆 |
|---------|------|------------|
| ゴルディロックス（適温） | 株↑・金利安定・原油安定・VIX低 | 全セクターに追い風。グロース優位 |
| リフレ | 株↑・金利↑・原油↑・VIX低〜中 | シクリカル・バリュー優位。銀行・資源に追い風 |
| デフレ懸念 | 株↓・金利↓・原油↓・VIX↑ | ディフェンシブ・債券型ETFに退避。グロース250に注意 |
| スタグフレーション懸念 | 株↓・金利↑・原油↑・VIX↑ | 最も厳しい環境。全セクターに逆風、現金・短期債選好 |

※ レジーム判定は参考情報であり、厳密な分類ではない。複数のレジーム特徴が混在する場合は「混合」と記載する。

## 高ボラモード・危機時ガードレール

### 高ボラモード（VIX > 30 or 日経前日比 > ±3%）

高ボラモード発動時、以下の挙動ルールを適用する:

| 項目 | 通常時 | 高ボラモード時 |
|------|--------|-------------|
| difficulty（不確実性） | 判定に応じて1-5 | 最低4（★★★★）に引き上げ |
| シナリオレンジ幅 | CME基準 ± VIX×係数 | 通常の1.5倍に拡大 |
| レポート冒頭 | 通常の3行サマリー | 3行サマリー直後に市場環境注記を挿入 |

### 危機モード（VIX > 35）

高ボラモードの全ルールに加え、以下を適用:

| 項目 | 適用内容 |
|------|---------|
| confidence | 強制的に「低」 |
| 方向性判断 | 「予測困難な環境」を総合判断に明記 |

### 反動シナリオルール

前日比±4%超の翌日AMでは、シナリオ分析に反動シナリオ（前日の大幅変動からの揺り戻し）を必ず含める。

## 使用方法

```
/market-outlook              # 時間帯自動判定（15:30前=am, 15:30以降=pm）
/market-outlook am           # AM: 今日の東証見通し
/market-outlook pm           # PM: 本日の結果・振り返り
/market-outlook portfolio    # 自動判定 + ポートフォリオモード
/market-outlook am portfolio # AM + ポートフォリオ
/market-outlook pm portfolio # PM + ポートフォリオ
```

- 引数順序は自由（`portfolio pm` も可）
- am/pm未指定時は現在時刻（JST）で自動判定（15:30が境界）
- 有効引数: `am`, `pm`, `portfolio`。不正引数は無視して警告出力
- `am pm` 同時指定: 自動判定にフォールバック

## 実行フロー

```
1. モード判定（メイン）
   ├─ timing: 引数 or 現在時刻（15:30境界）
   ├─ mode: general / portfolio
   └─ パラメータ算出: date, prev_business_day, is_trading_day, year_month, current_time
        ↓
2. データ収集+ドラフト生成（サブエージェント: general-purpose x1）
   ├─ Agent(general-purpose) で agent-instructions/market-data-collection.md に従い実行
   ├─ yfinance実行 → 定量データ確定
   ├─ WebSearch(定性のみ) → ニュース・テーマ取得
   ├─ ドラフト生成（output-formats.md テンプレートに従い）
   └─ 即時バリデーション（異常値検出 + 数値出典記録）
        ↓
3. ファイル保存（メイン）
   ├─ AM: reports/market-outlook/YYYYMMDD_am.md
   └─ PM: reports/market-outlook/YYYYMMDD_pm.md
```

## 禁止表現リスト

レポート品質と法的リスク回避のため、以下の表現を禁止する。

| 禁止パターン | 理由 | 代替表現 |
|-------------|------|---------|
| 「必ず上がる」「確実に下落する」等の断定 | 投資助言に該当するリスク | 「上昇が見込まれる」「下落圧力が強い」 |
| 「○○を買うべき」「売り推奨」等の売買指示 | 金商法上の投資助言業に該当 | 「注目テーマとして○○が挙げられる」 |
| 確率値の使用（「80%の確率で上昇」等） | AI生成の確率値は根拠の有無によらず誤解を招く | 「データ整合性: 高/中/低」で表現 |
| 「暴落」「急騰」の安易な使用 | 過度な恐怖・期待を煽る | 具体的な数値（前日比-3%等）で事実を記述 |
| 特定銘柄の目標株価提示 | 投資助言に該当するリスク | テーマ・セクター単位での注目に留める |

**運用ルール**: 予想精度メタデータ（的中判定・CME乖離等）の蓄積は内部品質管理目的に限定する。予想精度の統計化（「的中率○%」等）のレポート内掲載・外部公開・宣伝利用は禁止する。

## 推奨表現リスト

禁止表現の代わりに使用すべき推奨表現パターン。レポートの一貫性と品質を保つために活用する。

### 方向性表現

| 場面 | 推奨表現例 |

| 下落見通し | 「下落リスクが意識される」「売り圧力が強まる可能性」 |
| 横ばい見通し | 「方向感に乏しく、レンジ内推移が見込まれる」「もみ合いの展開を想定」 |

### 確度表現

| 場面 | 推奨表現例 |
|------|-----------|
| 確度が高い | 「データ整合性が高い」「複数の指標が同方向を示している」 |
| 確度が中程度 | 「材料が拮抗しており方向感が読みにくい」「強弱材料が混在」 |
| 確度が低い | 「複数の不確定要因を抱える」「材料消化の方向性が不透明」 |

| 場面 | 推奨表現例 |
|------|-----------|

### 月次パラメータレビュー

毎月初に `market_outlook_accuracy.py --month YYYY-MM` を実行し、以下を確認:

1. **方向性一致率**: 60%未満の場合、因果チェーンの重み付けを見直す
2. **横ばい的中率**: 30%未満の場合、横ばい閾値の拡大（±0.5%→±0.7%等）を検討
3. **confidence別的中率**: 高>中>低の順になっていない場合、confidence判定ルールを再調整
4. **CME乖離**: 平均±300円超の場合、CME取得時刻の見直しまたは乖離バイアス補正を検討
5. **difficulty別的中率**: 低difficulty（1-2）の的中率が高difficulty（4-5）より低い場合、difficulty判定基準を見直す

### 予測精度の構造的限界と改善ロードマップ

#### 既知の構造的限界

| 限界 | 影響 | 緩和策 |
|------|------|--------|
| CME→東証の寄付乖離 | AM予想のレンジ精度に直結。AM7時のCMEと東証9時の寄付の間に2時間のタイムラグ | レンジ幅にCME乖離バッファ（過去平均±172円）を加味 |
| 場中の突発材料 | AM予想では捕捉不能な材料（地政学、企業決算等）で方向性が逆転 | difficulty 4-5に分類し、予想の信頼性低下を事前に宣言 |
| 横ばい予想の困難さ | 横ばい（±0.5%以内）は日経のボラティリティ考慮すると発生確率30%程度だが予想は極めて難しい | 強い根拠がない限り上昇/下落に寄せる（横ばい予想は極力回避） |
| WebSearchの情報鮮度 | 検索結果が前日以前の情報を返す場合がある | ソースの日付を必ず検証し、当日情報がない場合は「情報不足」と明記 |

#### 精度改善ロードマップ

| フェーズ | 条件 | アクション |
|---------|------|----------|
