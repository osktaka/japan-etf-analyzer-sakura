# 市場データ収集・検証 指示書

## 前提（共通 - AM/PM両方で使用）

- タイミング: `{timing}`（`am` または `pm`）
- モード: `{mode}`（`general` または `portfolio`）
- 日付: `{date}`（本日の日付。例: 2026年2月20日）
- 前営業日: `{prev_business_day}`（直前の東証営業日。例: 2026年2月19日）
- 営業日フラグ: `{is_trading_day}`（`true` または `false`。dateが東証営業日かどうか）
- 年月: `{year_month}`（`{date}` の年月部分。例: 2026年2月）
- 現在時刻: `{current_time}`（JST。例: 07:30）

## データ受け渡しルール（共通）

- **入力**: タイミング・モード・日付パラメータ（メインエージェントから渡される）
- **出力**: 構造化Markdownを直接返却（各timingの出力テンプレート形式）
- **戻り値制約**: 出力テンプレート形式のみで返却。WebSearch結果の生テキストやHTML断片は含めない

## ソース優先順位（共通）

| 優先度 | ソース |
|--------|--------|
| 1 | 日本経済新聞 |
| 2 | Bloomberg / Reuters |
| 3 | Yahoo!ファイナンス |
| 4 | 各種経済メディア |

## portfolioモードAPI取得（共通）

`{mode}` が `portfolio` の場合のみ実行。

```bash
curl -s http://localhost:8902/api/v1/demo/portfolio/holdings
```

- レスポンスはJSON配列（code, name, current_value, weight等）
- 保有比率上位5銘柄に絞る
- **API失敗時**: 出力の末尾に `<!-- portfolio取得失敗 -->` を含める

## AM専用セクション（timing=am のときのみ読む）

### AM: データ収集手順

**Step 1 [AM]: WebSearch 3並行**

| ID | クエリ名 | 検索文字列 |
|----|--------|-----------|
| A | 米国市場 | `S&P500 ナスダック ダウ CME日経先物 終値 {date}` |
| B | 東証・為替 | `日経平均 TOPIX 終値 ドル円 {prev_business_day}` |
| C | 政治経済 | `日本 経済 金融政策 マーケット 見通し {year_month}` |

**Step 2 [AM]: 不足データのWebFetch補完**

| 不足データ | WebFetch先 |
|-----------|-----------|
| S&P500/ダウ/NASDAQ | Bloomberg、Reuters等の市場サマリーページ |
| CME日経先物 | 日経新聞 先物ページ |
| ドル円 | Yahoo!ファイナンス 為替ページ |

**Step 3 [AM]: portfolioモード時のAPI取得**（共通セクション参照）

**Step 4 [AM]: 注目ETF収集**

Step 1-2で特定した注目テーマからキーワードを抽出し、以下の優先順でETFを検索する。3-5銘柄を目標とする。

1. **keyword検索**（テーマごとに実行）:
```bash
curl -s "http://localhost:8902/api/v1/etfs?keyword={テーマ}&momentum_labels=上昇加速,上昇維持&sort=return_1m&order=desc&limit=5"
```

2. **tag_idsフォールバック**（keyword検索が0件の場合）:
```bash
# タグ一覧を取得し、テーマに近いタグ名を選定
curl -s "http://localhost:8902/api/v1/tags"
# 選定したタグIDでフィルタ
curl -s "http://localhost:8902/api/v1/etfs?tag_ids={tag_id}&momentum_labels=上昇加速,上昇維持&sort=return_1m&order=desc&limit=5"
```

3. **tag-momentumフォールバック**（tag_ids検索も0件の場合）:
```bash
# 上昇テーマを特定し、関連ETFを取得
curl -s "http://localhost:8902/api/v1/market/tag-momentum"
# dominant_label が「上昇加速」のタグを選び、そのtag_idで再検索
curl -s "http://localhost:8902/api/v1/etfs?tag_ids={tag_id}&sort=return_1m&order=desc&limit=5"
```

4. **最終フォールバック**: 全て0件の場合、セクション省略 + `<!-- etf_recommendation_unavailable -->` を出力末尾に付与

## PM専用セクション（timing=pm のときのみ読む）

### PM: データ収集手順

**Step 1 [PM]: WebSearch 3並行**

| ID | クエリ名 | 検索文字列 |
|----|--------|-----------|
| A | 東証当日結果 | `日経平均 TOPIX ドル円 終値 {date}` |
| B | グロース・業種別 | `東証 業種別騰落 グロース250 REIT 売買代金 {date}` |
| C | 国内ニュース（当日重要） | `日本 株式市場 重要ニュース 今日 {date}` |

**ニュース選定ガイドライン（注目ニュース・イベント）**:
- 当日（{date}）に発生・報道されたニュースを最優先で選ぶ
- 影響度の判断基準: 日経平均・TOPIXの変動要因 > セクター単位の材料 > 個別銘柄ニュース
- 営業日: 3件のうち最低2件は当日のニュースとする
- 非営業日: 前営業日〜当日の報道から影響度順に選ぶ（当日報道があれば優先）
- 前日以前のニュースは、当日に新たな動き（続報・市場反応）がある場合のみ採用可

**Step 2 [PM]: 不足データのWebFetch補完**

| 不足データ | WebFetch先 |
|-----------|-----------|
| 日経平均/TOPIX/ドル円 | Yahoo!ファイナンス 市場概況ページ |
| セクター別騰落 | Yahoo!ファイナンス 業種別株価指数 |
| グロース250/東証REIT指数 | Yahoo!ファイナンス 指数一覧 |

セクター別騰落が取得できない場合、出力に `<!-- sector_data_unavailable -->` を含める。

**Step 3 [PM]: portfolioモード時のAPI取得**（共通セクション参照）

**Step 4 [PM]: 今日の注目ETF収集**

当日に動きのあったETFを特定する。3-5銘柄を目標とする。

1. **WebSearch**で当日の注目ETF情報を収集:
   - `東証 ETF 値上がり率 {date}`
   - `東証 ETF 売買代金 {date}`

2. **具体的ETFコード判明時**: 銘柄情報を補完
```bash
curl -s "http://localhost:8902/api/v1/etfs/{code}"
```

3. **コード不明時**: tag-momentumフォールバック
```bash
# 上昇加速のタグを特定
curl -s "http://localhost:8902/api/v1/market/tag-momentum"
# dominant_label が「上昇加速」のタグを選び、関連ETFを取得
curl -s "http://localhost:8902/api/v1/etfs?tag_ids={tag_id}&sort=return_1m&order=desc&limit=5"
```

4. **最終フォールバック**: 全て不十分な場合、セクション省略

**Step 5 [PM]: 明日の注目ETF収集**

当日のテーマ・ニュース・海外情勢からテーマを抽出し、翌営業日に注目すべきETFを特定する。3-5銘柄を目標とする。

1. **keyword検索**（テーマごとに実行）:
```bash
curl -s "http://localhost:8902/api/v1/etfs?keyword={テーマ}&momentum_labels=上昇加速,上昇維持&sort=return_1m&order=desc&limit=5"
```

2. **tag_idsフォールバック**（keyword検索が0件の場合）:
```bash
curl -s "http://localhost:8902/api/v1/tags"
curl -s "http://localhost:8902/api/v1/etfs?tag_ids={tag_id}&momentum_labels=上昇加速,上昇維持&sort=return_1m&order=desc&limit=5"
```

3. **tag-momentumフォールバック**（tag_ids検索も0件の場合）:
```bash
curl -s "http://localhost:8902/api/v1/market/tag-momentum"
curl -s "http://localhost:8902/api/v1/etfs?tag_ids={tag_id}&sort=return_1m&order=desc&limit=5"
```

4. **最終フォールバック**: 全て0件の場合、セクション省略 + `<!-- etf_recommendation_unavailable -->` を出力末尾に付与

## 正確性チェック（共通 - AM/PM両方で使用）

### 段階1: 終値確定判定

各市場の取引時間に基づき「終値」か「取引中」かを判定する。`{current_time}` を使用して判断する。

| 市場 | 取引時間（JST） | 終値確定タイミング |
|------|----------------|------------------|
| 米国（NYSE/NASDAQ） | 23:30-6:00 | JST 6:00以降 |
| 東証 | 9:00-15:30 | JST 15:30以降 |
| CME日経先物 | 8:00-翌7:15 | セッション終了後 |
| 為替（ドル円） | 24時間 | NY終値=JST 6:00頃 |

ルール:
- 取引中の場合、前営業日の終値を使用し備考に「前営業日終値」と明記
- やむを得ず取引中の値を使用する場合は「取引中」と必ず明記

### 段階2: 複数ソースクロスチェック

**AM対象:**

| 指標 | 許容差異 |
|------|---------|
| S&P500 | ±0.5% |
| 日経平均 | ±0.5% |
| ドル円 | ±0.5% |

**PM対象:**

| 指標 | 許容差異 |
|------|---------|
| 日経平均 | ±0.5% |
| TOPIX | ±0.5% |
| グロース250 | ±1.0% |

差異超過時: WebFetchで確定値を追加取得。

備考への検証状態付記:
- 2ソース一致: 「終値確定・2ソース確認」
- 1ソースのみ: 「終値確定・単一ソース」
- 取引中: 「取引中・参考値」

### 段階3: 異常値検出

**AM閾値:**

| 指標 | 閾値 |
|------|------|
| S&P500 | ±5% |
| 日経平均 | ±4% |
| ドル円 | ±2円 |

**PM閾値:**

| 指標 | 閾値 |
|------|------|
| 日経平均 | ±4% |
| TOPIX | ±3% |
| グロース250 | ±5% |
| ドル円 | ±2円 |

閾値を超える場合、原因を1文添付する。

## エラーハンドリング（共通）

| 状況 | 対応 |
|------|------|
| WebSearch結果0件 | クエリを変えて再検索（日付なし版で再試行） |
| WebSearch完全失敗 | WebFetchで日経新聞サイト等に直接アクセス |
| CME日経先物取得不可 [AM] | 「取得失敗」と明記し他指標で出力作成 |
| セクター別騰落取得不可 [PM] | セクション省略 + `<!-- sector_data_unavailable -->` |
| 注目ETF keyword検索0件 | tag_idsフォールバック検索。それも0件の場合はtag-momentumで上昇テーマから取得 |
| 注目ETF 全フォールバック失敗 | セクション省略 + `<!-- etf_recommendation_unavailable -->` |
| 注目ETF API失敗 | WebSearch結果のみで構成。それも不十分な場合はセクション省略 |
| ポートフォリオAPI失敗 | 出力に `<!-- portfolio取得失敗 -->` を含める |
