# 出力フォーマット定義

## 共通ルール

### 免責事項テンプレート

全レポートの冒頭（タイトル・更新日時の直後）に以下を記載する:

```
*本レポートはAIによる自動生成です。投資判断の参考情報であり、投資助言ではありません。*
```

### レポート利用ガイド

免責事項の直後に以下を記載する:

> **📖 このレポートの使い方**
> - 本レポートはAIが公開データを分析した参考情報です
> - 個別銘柄の売買推奨ではありません。投資判断はご自身の責任で行ってください
> - 「総合判断」→「シナリオ分析」→「ETF情報」の順に読むと効率的です
> - 数値は取得時点のものです。最新値は各情報源で確認してください

### VIX記述ルール

VIX特定水準（20、25、30等）を分岐点として言及する場合、心理的節目であり理論的根拠はない旨を併記すること。
例: 「VIXは25を超え警戒水準に達している（※25は心理的節目であり、理論的な閾値ではない）」

### メタデータ分割基準

- **構造化データ**（prediction等）= YAMLフロントマター（ファイル先頭）
- **運用フラグ**（sector_data_unavailable, etf_recommendation_unavailable, portfolio取得失敗等）= HTMLコメント（本文末尾に残す）

### メタデータキー（YAMLフロントマター）

- `prediction.direction`: 上昇|下落|横ばい
- `prediction.confidence`: 高|中|低
- `prediction.cme_nikkei`: 整数値
- `prediction.range_low`: ベースシナリオ下限（整数値）
- `prediction.range_high`: ベースシナリオ上限（整数値）
- `prediction.difficulty`: 1-5（整数値、★の数に対応）

### PM: 非営業日の場合

`is_trading_day=false`（土日祝）の場合、以下のセクションを変更する。それ以外のセクションは営業日と同様に出力する。

| セクション | 変更内容 |
|-----------|---------|
| 本日の結果 | テーブルを省略し `本日（{date}）は東証休場日のため取引データなし` に置換 |
| セクター別騰落 | セクション自体を省略 |
| 値動きの要因分析 | セクション自体を省略 |
| AM予想との比較（予想精度メタデータ含む） | セクション自体を省略（非営業日にAMレポートは存在しないため） |
| その他（注目ニュース、今日の注目ETF、明日の注目ETF等） | 選定基準に従い前営業日〜当日の報道から影響度順に選定 |

## 後方互換ルール

### 既存レポート（HTMLコメント形式）のパース方法

過去のAMレポートでは、メタデータがYAMLフロントマターではなくHTMLコメント形式で記録されている場合がある:

```html
<!-- prediction: 上昇 -->
<!-- confidence: 中 -->
<!-- cme_nikkei: 39500 -->
```

PM実行時にAMファイルを読み込む際、以下の順でパースを試みる:

1. ファイル先頭のYAMLフロントマター（`---`で囲まれたブロック）
2. YAMLフロントマターが存在しない場合、本文末尾の`<!-- prediction: ... -->`等のHTMLコメントからパース

### AMファイル先頭がYAMLフロントマターでない場合の処理

- 末尾の`<!-- prediction: ... -->`からパースを試みる（後方互換）
- HTMLコメント形式でもパースできない場合は「AM予想データの読み取りに失敗しました」と明記
- 新規作成するレポートは常にYAMLフロントマター形式で出力すること
