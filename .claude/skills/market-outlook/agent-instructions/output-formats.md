# 出力フォーマット定義

## 共通ルール

### 免責事項テンプレート

全レポートの冒頭（タイトル・更新日時の直後）に以下を記載する:

```
*本レポートはAIによる自動生成です。投資判断の参考情報であり、投資助言ではありません。*
```

### レポート利用ガイド

免責事項の直後に以下を記載する:

> **📖 このレポートの使い方**
> - 本レポートはAIが公開データを分析した参考情報です
> - 個別銘柄の売買推奨ではありません。投資判断はご自身の責任で行ってください
> - 「総合判断」→「シナリオ分析」→「ETF情報」の順に読むと効率的です
> - 数値は取得時点のものです。最新値は各情報源で確認してください

### VIX記述ルール

VIX特定水準（20、25、30等）を分岐点として言及する場合、心理的節目であり理論的根拠はない旨を併記すること。
例: 「VIXは25を超え警戒水準に達している（※25は心理的節目であり、理論的な閾値ではない）」

### メタデータ分割基準

- **構造化データ**（prediction等）= YAMLフロントマター（ファイル先頭）
- **運用フラグ**（sector_data_unavailable, etf_recommendation_unavailable, portfolio取得失敗等）= HTMLコメント（本文末尾に残す）
