# Phase 0.5: テクニカル指標計算（項目8-13）指示書

## 目的

Phase 0で取得した追加データ（OHLCV 30日、close 250日、配当データ）を用いて、トレーダー知見に基づく6項目のテクニカル指標を計算する。
本指示書は `phase05-shared-calculations.md` の項目1-7に続く追加計算として、同一エージェントが実行する。

## 前提

- 本指示書の計算結果は `05_shared_calculations.md` の末尾に追記される
- **計算のみ**を行い、解釈・判断は一切含めない（Phase 1ペルソナが解釈する）
- Phase 1ペルソナ（debateモード）は `00_portfolio_data.json` の生データを直接参照しない。ここで計算した結果テーブルのみを参照する

### 8. 200日移動平均防御シグナル（ma200_signal）

<!-- DO_NOT_RECALCULATE: ma200_signal -->

**入力**: `price_data_close_250d`

**計算手順**:
1. 各銘柄の `price_data_close_250d` から日次closeを時系列順に取得
2. 直近200日分のcloseデータがある銘柄のみ計算対象（200日未満の銘柄はスキップし、テーブルに「データ不足（N日分）」と記載）
3. 200日単純移動平均（SMA）を算出: `200MA = 直近200日closeの合計 / 200`
4. 現在価格との乖離率を算出: `乖離率(%) = (現在価格 - 200MA) / 200MA * 100`
5. シグナル判定:
   - 乖離率 > +5%: **上昇トレンド**
   - 乖離率 -5% 〜 +5%: **警戒**
   - 乖離率 < -5%: **防御**

**ポートフォリオ防御レベル**:
- 「防御」シグナルの銘柄の保有比率合計を算出
- 防御銘柄比率 0-10%: **攻撃モード**
- 防御銘柄比率 10-30%: **中立**
- 防御銘柄比率 30-60%: **防御モード**（ポートフォリオ全体が下降トレンド寄り）
- 防御銘柄比率 60%超: **最大防御**

**出力テーブル**:

```
## 8. 200日移動平均防御シグナル
<!-- DO_NOT_RECALCULATE: ma200_signal -->

| 銘柄コード | 銘柄名 | 現在価格 | 200MA | 乖離率 | シグナル |
|---------|------|--------|-------|-------|---------|
| 1475    | ...  | X,XXX円 | X,XXX円 | +X.X% | 上昇トレンド |
| ...     | ...  | ...     | ...   | ...   | ...     |

ポートフォリオ防御レベル: 中立（防御銘柄比率: XX.X%）
```

**スキップ条件**: `price_data_close_250d` が `_data_status` で `error` または `empty` の場合、セクション全体をスキップし「データ不足のためスキップ」と記載。

### 9. ATRベース退避ライン（atr_trailing_stop）

<!-- DO_NOT_RECALCULATE: atr_trailing_stop -->

**入力**: `price_data_daily_30d`

**計算手順**:
1. 各銘柄の `price_data_daily_30d` から日次OHLC（open, high, low, close）を時系列順に取得
2. True Range（TR）を算出:
   - `TR = max(high - low, abs(high - 前日close), abs(low - 前日close))`
   - 初日は `TR = high - low`（前日closeがないため）
3. ATR(14) = 直近14日間のTRの単純移動平均
   - 14日分のデータがない場合は利用可能な日数で計算し「参考値（N日分）」と注記
4. 退避ライン算出:
   - 注意ライン: `現在価格 - 1.5 * ATR(14)`
   - 退避ライン: `現在価格 - 2.0 * ATR(14)`
5. 状態判定:
   - 現在価格 > 注意ライン: **正常**
   - 注意ライン >= 現在価格 > 退避ライン: **注意**（価格がATR 1.5倍以内に接近）
   - 現在価格 <= 退避ライン: **退避検討**
   - ※ 通常、現在価格から算出しているため「正常」になるが、直近の急落でclose値とhigh/lowの乖離が大きい場合は注意/退避が点灯する

**注意**: `volume` カラムにNULLがある行はATR計算から除外しない（ATRはOHLCのみで計算するため影響なし）。ただし、`high` または `low` がNULLの行はスキップする。

**出力テーブル**:

```
## 9. ATRベース退避ライン
<!-- DO_NOT_RECALCULATE: atr_trailing_stop -->

| 銘柄コード | 銘柄名 | 現在価格 | ATR(14) | 注意ライン(1.5ATR) | 退避ライン(2ATR) | 状態 |
|---------|------|--------|---------|-----------------|----------------|------|
| 1475    | ...  | X,XXX円 | XXX円   | X,XXX円          | X,XXX円         | 正常 |
| ...     | ...  | ...     | ...    | ...              | ...            | ...  |
```

**スキップ条件**: `price_data_daily_30d` が `_data_status` で `error` または `empty` の場合、セクション全体をスキップ。

### 10. 分配金利回りZスコア（dividend_zscore）

<!-- DO_NOT_RECALCULATE: dividend_zscore -->

**入力**: `dividend_data` + `holdings`（各銘柄の `current_price`）

**計算手順**:
1. `dividend_data` から各銘柄の年度別配当合計を取得
2. 現在の年間配当利回りを算出:
   - 直近1年の配当合計（最新年度のデータ）を使用
   - `現在利回り(%) = 年間配当合計 / current_price * 100`
3. 3年分の年間利回りを算出（各年度の配当合計 / その年度末の推定価格）
   - 推定価格が不明な場合は `current_price` で代替し「推定値」と注記
4. Zスコアを算出:
   - `平均 = 3年分利回りの算術平均`
   - `標準偏差 = 3年分利回りの標準偏差`
   - `Zスコア = (現在利回り - 平均) / 標準偏差`
   - 標準偏差が0（全年度同一利回り）の場合は `Zスコア = 0` とし「分散なし」と注記
5. 判定:
   - Zスコア >= +1.5: **割安**（利回りが歴史的に高い水準）
   - Zスコア >= +0.84: **注意**（上位20%の利回り水準）
   - Zスコア < +0.84: **通常**
6. 3年分のデータが揃わない銘柄（2年以下）は「データ不足（N年分）」と記載してスキップ

**出力テーブル**:

```
## 10. 分配金利回りZスコア
<!-- DO_NOT_RECALCULATE: dividend_zscore -->

| 銘柄コード | 銘柄名 | 現在利回り | 3年平均利回り | Zスコア | 判定 |
|---------|------|---------|------------|--------|------|
| 1475    | ...  | X.XX%   | X.XX%      | +X.XX  | 通常 |
| ...     | ...  | ...     | ...        | ...    | ...  |
```

**スキップ条件**: `dividend_data` が `null`（取得失敗）または `_data_status` で `error` の場合、セクション全体をスキップし「配当データ取得失敗のためスキップ」と記載。`etfs` テーブルの `dividend_yield` による代替は行わない（Zスコア算出に3年分のデータが必要なため）。

### 11. 出来高異常検知（volume_stats）

<!-- DO_NOT_RECALCULATE: volume_stats -->

**入力**: `price_data_daily_30d`

**計算手順**:
1. 各銘柄の `price_data_daily_30d` から日次volumeを取得
2. volumeがNULLまたは0の行を除外（ETFによっては出来高が記録されない日がある）
3. 有効データが10日未満の場合は「出来高データ不足（N日分）」と記載してスキップ
4. 20日平均出来高を算出（有効データが20日未満の場合は利用可能な日数で計算し「参考値」と注記）
5. 出来高レシオを算出: `直近5日平均出来高 / 20日平均出来高`
6. 判定:
   - レシオ > 2.0: **急増**
   - レシオ > 1.5: **増加**
   - レシオ 0.5 〜 1.5: **通常**
   - レシオ < 0.5: **枯渇**

**出力テーブル**:

```
## 11. 出来高異常検知
<!-- DO_NOT_RECALCULATE: volume_stats -->

| 銘柄コード | 銘柄名 | 直近5日平均 | 20日平均 | レシオ | 判定 |
|---------|------|----------|---------|-------|------|
| 1475    | ...  | XX,XXX   | XX,XXX  | X.XX  | 通常 |
| ...     | ...  | ...      | ...     | ...   | ...  |
```

**スキップ条件**: `price_data_daily_30d` が `_data_status` で `error` または `empty` の場合、セクション全体をスキップ。

### 12. 再購入分析スコア（rebuy_score）

<!-- DO_NOT_RECALCULATE: rebuy_score -->

**入力**: 項目8（200MA）+ 項目9（ATR）+ 項目10（Zスコア）+ 項目6（モメンタム分布）

**計算手順**:
1. 各銘柄について以下4要素を0-100に正規化:
   - **200MA要素**（重み0.3）: 乖離率を正規化
     - 乖離率 +10%以上: 100点
     - 乖離率 0%: 50点
     - 乖離率 -10%以下: 0点
     - 中間値は線形補間
   - **モメンタム要素**（重み0.25）: momentum_labelに基づく点数
     - 上昇加速: 100点
     - 上昇中: 75点
     - 横ばい: 50点
     - 下降中: 25点
     - 下降加速: 0点
   - **Zスコア要素**（重み0.25）: 分配金ZスコアをZスコア値ベースで正規化
     - Zスコア >= +1.5: 100点（割安 = 高利回りで買い候補）
     - Zスコア >= +0.84: 75点
     - Zスコア 0付近: 50点
     - Zスコア <= -0.84: 25点
     - Zスコア <= -1.5: 0点
     - 中間値は線形補間
   - **ATR余裕度**（重み0.2）: 現在価格と退避ラインの距離を正規化
     - (現在価格 - 退避ライン) / ATR を正規化。0=0点、3以上=100点（線形補間）
     - 退避ラインからの距離 = 0: 0点
     - 中間値は線形補間
2. 総合スコア = `0.3 * 200MA要素 + 0.25 * モメンタム要素 + 0.25 * Zスコア要素 + 0.2 * ATR余裕度`
3. 判定:
   - 70以上: **継続保有**
   - 40-69: **観察**
   - 39以下: **入替検討**
4. 一部要素が算出不能（項目8/9/10がスキップ）の場合:
   - 算出可能な要素のみで重みを再配分して計算
   - 例: Zスコアがスキップの場合 → 0.4 * 200MA + 0.33 * モメンタム + 0.27 * ATR余裕度
   - 200MAとZスコアの**両方**がスキップの場合は再購入スコア自体をスキップ

**出力テーブル**:

```
## 12. 再購入分析スコア
<!-- DO_NOT_RECALCULATE: rebuy_score -->

| 銘柄コード | 銘柄名 | 200MA要素 | モメンタム | Zスコア要素 | ATR余裕度 | 総合スコア | 判定 |
|---------|------|---------|---------|----------|---------|---------|------|
| 1475    | ...  | XX      | XX      | XX       | XX      | XX.X    | 継続保有 |
| ...     | ...  | ...     | ...     | ...      | ...     | ...     | ...  |

※ 使用重み: 200MA=0.3, モメンタム=0.25, Zスコア=0.25, ATR=0.2
```

**スキップ条件**: 項目8（200MA）と項目10（Zスコア）の両方がスキップの場合、セクション全体をスキップ。

### 13. 経済象限判定（economic_quadrant）※Phase 0a完了時のみ

<!-- DO_NOT_RECALCULATE: economic_quadrant -->

**入力**: `{WORK_DIR}/0a_market_environment.md`

**実行条件**: `{WORK_DIR}/0a_market_environment.md` が存在する場合のみ実行する。存在しない場合は「Phase 0a未完了のためスキップ」と記載してセクション全体をスキップ。

**計算手順**:
1. `0a_market_environment.md` から以下の情報を抽出:
   - GDP成長率の方向性（上昇/下降）
   - インフレ率の方向性（上昇/下降）
   - 金利動向
   - 市場環境の要約
2. ダリオ型4象限に分類:
   - **象限1（成長上昇 + インフレ上昇）**: 実物資産・コモディティ有利
   - **象限2（成長上昇 + インフレ下降）**: 株式・成長資産有利
   - **象限3（成長下降 + インフレ下降）**: 債券・ディフェンシブ有利
   - **象限4（成長下降 + インフレ上昇）**: 現金・ゴールド有利（スタグフレーション）
3. 現在の象限に基づく推奨アセット傾向を記載（判定文ではなく傾向の事実のみ）
4. 動的現金比率レンジを算出:
   - 象限1: 5-10%（攻撃モード）
   - 象限2: 5-15%（攻撃〜中立）
   - 象限3: 15-25%（防御モード）
   - 象限4: 25-40%（最大防御）

**出力テーブル**:

```

<!-- DO_NOT_RECALCULATE: economic_quadrant -->

注意: 境界ケースの場合は隣接象限も候補として併記すること

| 象限 | 成長 | インフレ | 推奨アセット傾向 | 動的現金比率 |
|------|------|---------|---------------|-----------|
| 1    | 上昇 | 上昇    | 実物資産・コモディティ | 5-10%   |
| 2    | 上昇 | 下降    | 株式・成長資産       | 5-15%   |
| **3**| **下降** | **下降** | **債券・ディフェンシブ** | **15-25%** |
```

## 出力形式ルール（項目1-7と共通）

- 各項目はMarkdownのセクション（`##`）で区切る
- テーブル形式で数値を整理する
- **解釈や判断は一切含めない**（純粋な計算結果のみ）
- 例: 「200MAを下回っているため売却推奨」のような判定文は記載しない
- 例: 「出来高急増は機関投資家の動きを示唆」のような解釈も記載しない
- 各計算結果セクションの冒頭に項目別識別子付きの `<!-- DO_NOT_RECALCULATE: {識別子} -->` マーカーを付与する
