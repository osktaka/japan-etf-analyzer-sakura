# Phase 3: クロスレビュー実行指示書（独立エージェント用）

> analyst-A/B/Cが自身のペルソナに基づき、他エージェントの分析結果をレビューする指示書。

## 前提

- 作業ディレクトリ: `{WORK_DIR}`（メインエージェントから渡される）
- 担当ペルソナ: `{persona}`（`a` / `b` / `c` のいずれか。メインエージェントから渡される）
- ラウンド番号: `{round}`（`1` / `2` のいずれか。メインエージェントから渡される）
- ペルソナ詳細定義は `{skill_dir}/agent-instructions/phase1-debate-common.md` の「ペルソナ定義」セクションを参照すること

## データ受け渡しルール

- **メインへの戻り値**: 「{ペルソナ名} Round {N} 完了」の1行のみ。データ全文やテーブル全体を返さないこと

---

## ペルソナ間の対立軸

各エージェントに固有のペルソナが割り当てられている。クロスレビューでは、**相手のペルソナ前提を理解した上で**批評を行うこと。

### 対立軸マトリクス

| 組み合わせ | 主要な対立点 | 着眼点 |
|-----------|------------|-------|
| A（積極派） ↔ B（堅実派） | リターン追求 vs リスク回避・攻めの入替 vs 守りの継続 | 非効率銘柄を即入替か回復を待つか？ |
| A（積極派） ↔ C（異論派） | 成長確信 vs 懐疑・トレンド追従 vs 盲点指摘 | そのモメンタムは本物か？ |
| B（堅実派） ↔ C（異論派） | 安定信仰 vs 安定の罠・現状維持 vs 隠れたリスク | 分散しているつもりが実は集中していないか？ |

---

## 独立性維持ルール（必須）

クロスレビューを実施する際、以下のルールを厳守すること:

1. **参照制限**: analyst-Xがanalyst-Yをレビューする際、analyst-Zの分析結果を参照してはならない。2者間の直接比較に集中する
2. **ペルソナ一貫性**: 各ペルソナの発言は、そのペルソナの★★★重点項目に基づくこと。★の項目で強い主張をしない
3. **合意の検証**: 「全ペルソナ同意」と記載する前に、各ペルソナの立場から反対できる根拠がないか必ず検証する
4. **同意の制限**: 第1ラウンドでは「同意する点」を最大2項目に制限し、相違点の掘り下げを優先する
5. **反証のデータ要求**: analyst-Cが反対意見を述べる際は、定量データまたは具体的事例に基づくこと。データ根拠のない反対は記載しない
6. **転記数値の照合**: 分析結果内の共通計算結果が`shared_calculations.md`と一致するか照合する。不一致時は`shared_calculations.md`を正とし「計算値修正」と注記

`{WORK_DIR}/portfolio_data.json` の `compare_performance` / `compare_scores` があれば客観的根拠として参照する。

## Round 1: 相互レビュー

### 入力ファイル

| ファイル | 内容 |
|---------|------|
| `{WORK_DIR}/analyst_a_analysis.md` | analyst-A（積極派）の分析結果 |
| `{WORK_DIR}/analyst_b_analysis.md` | analyst-B（堅実派）の分析結果 |
| `{WORK_DIR}/analyst_c_analysis.md` | analyst-C（異論派）の分析結果 |
| `{WORK_DIR}/shared_calculations.md` | 共通定量計算結果（転記数値の照合用） |
| `{WORK_DIR}/candidate_verification.md` | Phase 2 入替候補の外部検証結果（存在する場合のみ） |

### 手順

1. 自分以外の2名の分析結果を読み込む（レビューは1対1。独立性維持ルール#1遵守）
2. 各分析に対し、見解の相違・見落とし・データ解釈の妥当性・総合判断の優先順位をレビュー
3. Phase 2の外部検証結果との整合性を確認する（candidate_verification.mdが存在する場合）:
   - Phase 1で推奨した入替候補がPhase 2で「要再検討」「非推奨」と判定された場合、その根拠を踏まえてレビューに反映する
   - Phase 2で「構造的リスク」が指摘された候補について、他のペルソナの推奨理由が短期的材料のみに基づいていないか検証する
4. 出力形式に従って記載する

### 出力ファイル

- `{WORK_DIR}/crossreview_round1_{persona}.md`

### 出力形式（2名それぞれに対して記載）

```
=== analyst-X による analyst-Y のレビュー ===

0. 相手のペルソナ前提:（1-2行で簡潔に）

1. 見解の相違:
   - [対立軸を踏まえた相違点と根拠]

2. 見落としの指摘:
   - [相手が軽視しがちな観点]

3. 同意する点:
   - [相手の優れた分析点]

4. 総合判断の比較:
   - トップ3アクションの対比
   - ペルソナ起因 vs データ解釈起因の分類
```

## Round 2: 反論・合意形成

### 入力ファイル

| ファイル | 内容 |
|---------|------|
| `{WORK_DIR}/analyst_a_analysis.md` | analyst-A（積極派）の分析結果 |
| `{WORK_DIR}/analyst_b_analysis.md` | analyst-B（堅実派）の分析結果 |
| `{WORK_DIR}/analyst_c_analysis.md` | analyst-C（異論派）の分析結果 |
| `{WORK_DIR}/shared_calculations.md` | 共通定量計算結果 |
| `{WORK_DIR}/crossreview_round1_a.md` | analyst-A の Round 1 レビュー結果 |
| `{WORK_DIR}/crossreview_round1_b.md` | analyst-B の Round 1 レビュー結果 |
| `{WORK_DIR}/crossreview_round1_c.md` | analyst-C の Round 1 レビュー結果 |
| `{WORK_DIR}/candidate_verification.md` | Phase 2 入替候補の外部検証結果（存在する場合のみ） |

### 手順

1. 自分に対する他2名のレビュー指摘を読み込む
2. 各指摘の受け入れ/反論を判断し、ペルソナ範囲内の歩み寄り点を明確にする
3. 修正後の総合判断を出力形式に従って記載する

### 出力ファイル

- `{WORK_DIR}/crossreview_round2_{persona}.md`

### 出力形式

```
=== analyst-X の第2ラウンド回答 ===

1. 受け入れる指摘:
   - [指摘内容と修正後の見解、歩み寄りの範囲]

2. 反論する指摘:
   - [指摘内容と反論の根拠]

3. 修正後の総合判断:
   - トップ3アクション + 合意度（合意/部分合意/不合意）
   - ペルソナを超えた合意項目を強調
```
