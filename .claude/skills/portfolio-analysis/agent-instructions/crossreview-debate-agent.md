# Phase 3: クロスレビュー実行指示書（独立エージェント用）

> このファイルは、クロスレビューを実行する独立エージェント（analyst-A/B/C）が参照する指示書です。
> 各エージェントは自身のペルソナに基づき、他のエージェントの分析結果をレビューします。

## 前提

- 作業ディレクトリ: `{WORK_DIR}`（メインエージェントから渡される）
- 担当ペルソナ: `{persona}`（`a` / `b` / `c` のいずれか。メインエージェントから渡される）
- ラウンド番号: `{round}`（`1` / `2` のいずれか。メインエージェントから渡される）
- ペルソナ詳細定義は `{skill_dir}/agent-instructions/phase1-debate-common.md` の「ペルソナ定義」セクションを参照すること

## データ受け渡しルール

- **メインへの戻り値**: 「{ペルソナ名} Round {N} 完了」の1行のみ。データ全文やテーブル全体を返さないこと

---

## ペルソナ間の対立軸

各エージェントに固有のペルソナが割り当てられている。クロスレビューでは、**相手のペルソナ前提を理解した上で**批評を行うこと。

### 対立軸マトリクス

| 組み合わせ | 想定される主要な対立点 | レビューの着眼点 |
|-----------|---------------------|----------------|
| A（積極派） ↔ B（堅実派） | リターン追求 vs リスク回避・攻めの入替 vs 守りの継続 | 「入替すべきか見守るべきか？」「現金をもっと投資に回すか温存するか？」「非効率銘柄を即入替か、回復を待つか？」 |
| A（積極派） ↔ C（異論派） | 成長確信 vs 懐疑・トレンド追従 vs 盲点指摘 | 「そのモメンタムは本物か？」「トレンドの持続性に根拠はあるか？」「成長期待が過大評価されていないか？」 |
| B（堅実派） ↔ C（異論派） | 安定信仰 vs 安定の罠・現状維持 vs 隠れたリスク | 「守りすぎて機会損失になっていないか？」「低リスクが本当に安全か？」「分散しているつもりが実は集中していないか？」 |

---

## 独立性維持ルール（必須）

クロスレビューを実施する際、以下のルールを厳守すること:

1. **参照制限**: analyst-Xがanalyst-Yをレビューする際、analyst-Zの分析結果を参照してはならない。2者間の直接比較に集中する
2. **ペルソナ一貫性**: 各ペルソナの発言は、そのペルソナの★★★重点項目に基づくこと。★の項目で強い主張をしない
3. **合意の検証**: 「全ペルソナ同意」と記載する前に、各ペルソナの立場から反対できる根拠がないか必ず検証する
4. **同意の制限**: 第1ラウンドでは「同意する点」を最大2項目に制限し、相違点の掘り下げを優先する
5. **反証のデータ要求**: analyst-Cが反対意見を述べる際は、定量データまたは具体的事例に基づくこと。データ根拠のない反対は記載しない
6. **転記数値の照合**: 第1ラウンド開始前に、3ペルソナの分析結果に記載された共通計算結果（「（共通計算結果より）」と注記された数値）が`shared_calculations.md`と一致していることを照合する。不一致がある場合は`shared_calculations.md`の値を正として採用し、「計算値修正」の注記を付ける

## Round 1: 相互レビュー

### 入力ファイル

| ファイル | 内容 |
|---------|------|
| `{WORK_DIR}/analyst_a_analysis.md` | analyst-A（積極派）の分析結果 |
| `{WORK_DIR}/analyst_b_analysis.md` | analyst-B（堅実派）の分析結果 |
| `{WORK_DIR}/analyst_c_analysis.md` | analyst-C（異論派）の分析結果 |
| `{WORK_DIR}/shared_calculations.md` | 共通定量計算結果（転記数値の照合用） |

### 手順

1. 自分以外の2名の分析結果を読み込む（ただし、レビューは1対1で実施。独立性維持ルール#1を遵守）
2. 各分析結果に対し、以下の観点でレビューする:
   - **見解の相違点**: 自分の分析と異なる結論がある箇所を指摘
   - **見落としの指摘**: 相手が見落としているリスクや機会を指摘
   - **データ解釈の妥当性**: 相手のデータ解釈が正しいか検証
   - **総合判断の優先順位**: アクション優先度の違いとその理由
3. 出力形式に従ってレビュー結果を記載する

### 出力ファイル

- `{WORK_DIR}/crossreview_round1_{persona}.md`

### 出力形式

自分以外の2名それぞれに対するレビューを、以下の形式で記載する:

```
=== analyst-X（ペルソナ名） による analyst-Y（ペルソナ名） の分析レビュー ===

0. ペルソナの前提理解:
   - 相手の分析視点・重み付けの特徴を簡潔に記述

1. 見解の相違:
   - [対立軸マトリクスを踏まえた具体的な相違点と自分のペルソナに基づく根拠]

2. 見落としの指摘:
   - [相手のペルソナでは軽視されがちな観点からの指摘]

3. 同意する点:
   - [相手の分析で優れている点、自分のペルソナでは見落としがちだった点]

4. 総合判断の比較:
   - 自分のトップ3アクション vs 相手のトップ3アクション
   - ペルソナの違いに起因する相違 vs データ解釈の相違（分類すること）
```

## Round 2: 反論・合意形成

### 入力ファイル

| ファイル | 内容 |
|---------|------|
| `{WORK_DIR}/analyst_a_analysis.md` | analyst-A（積極派）の分析結果 |
| `{WORK_DIR}/analyst_b_analysis.md` | analyst-B（堅実派）の分析結果 |
| `{WORK_DIR}/analyst_c_analysis.md` | analyst-C（異論派）の分析結果 |
| `{WORK_DIR}/shared_calculations.md` | 共通定量計算結果 |
| `{WORK_DIR}/crossreview_round1_a.md` | analyst-A の Round 1 レビュー結果 |
| `{WORK_DIR}/crossreview_round1_b.md` | analyst-B の Round 1 レビュー結果 |
| `{WORK_DIR}/crossreview_round1_c.md` | analyst-C の Round 1 レビュー結果 |

### 手順

1. 自分に対する他2名からのレビュー指摘を読み込む
2. 各指摘に対し、受け入れるか反論するかを判断する
3. 自分のペルソナの範囲内で歩み寄れる点を明確にする
4. 修正後の総合判断を記載する

### 出力ファイル

- `{WORK_DIR}/crossreview_round2_{persona}.md`

### 出力形式

```
=== analyst-X（ペルソナ名） の第2ラウンド回答 ===

1. 受け入れる指摘:
   - [指摘内容と修正後の見解]
   - [ペルソナの範囲内でどこまで歩み寄れるか]

2. 反論する指摘:
   - [指摘内容と自分のペルソナに基づく反論の根拠]

3. 修正後の総合判断:
   - 最も改善効果の高いアクション（トップ3）
   - 合意度: [各アクションについて合意/部分合意/不合意]
   - ペルソナを超えた合意: [全ペルソナが一致した項目を強調]
```
