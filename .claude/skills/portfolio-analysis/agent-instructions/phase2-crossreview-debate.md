# Phase 2: クロスレビュー観点（議論重視モード）

> このファイルは統合エージェント（phase34-integration.md）が参照するクロスレビュー観点です（議論重視モード）。
> 議論重視モードでは、クロスレビューを2ラウンド実施し、各独立分析者（analyst-A/B/C）の見解の相違・合意点を特定します。

## ペルソナ間の対立軸

議論重視モードでは、各エージェントに固有のペルソナが割り当てられている。クロスレビューでは、**相手のペルソナ前提を理解した上で**批評を行うこと。

### 対立軸マトリクス

| 組み合わせ | 想定される主要な対立点 | レビューの着眼点 |
|-----------|---------------------|----------------|
| A（ファンダメンタルズアナリスト） ↔ B（マーケットストラテジスト） | ボトムアップ vs トップダウン・個別銘柄の内在価値 vs 市場環境 | 「個別銘柄の指標と市場トレンドのどちらが株価を支配するか？」「ファンダメンタルズが良くても環境が悪ければ下がるのでは？」 |
| B（マーケットストラテジスト） ↔ C（リスクマネージャー） | トレンド追従 vs 最悪シナリオ備え・機会追求 vs リスク回避 | 「トレンドに乗る利益とテールリスクのどちらを重視すべきか？」「モメンタム追従がリスク集中を招いていないか？」 |
| A（ファンダメンタルズアナリスト） ↔ C（リスクマネージャー） | 過去指標の信頼 vs 将来シナリオ分析・数値楽観 vs 最悪想定 | 「過去の数値実績と将来ストレステストのどちらが信頼できるか？」「スコアが高くてもストレス耐性が低い銘柄をどう扱うか？」 |

---

## 第1ラウンド: 相互レビュー

各エージェントが他のエージェントの分析結果を受け取り、以下の観点でレビュー:

1. **見解の相違点**: 自分の分析と異なる結論がある箇所を指摘
2. **見落としの指摘**: 相手が見落としているリスクや機会を指摘
3. **データ解釈の妥当性**: 相手のデータ解釈が正しいか検証
4. **総合判断の優先順位**: アクション優先度の違いとその理由

**出力形式**:
```
=== analyst-X（ペルソナ名） による analyst-Y（ペルソナ名） の分析レビュー ===

0. ペルソナの前提理解:
   - 相手の分析視点・重み付けの特徴を簡潔に記述

1. 見解の相違:
   - [対立軸マトリクスを踏まえた具体的な相違点と自分のペルソナに基づく根拠]

2. 見落としの指摘:
   - [相手のペルソナでは軽視されがちな観点からの指摘]

3. 同意する点:
   - [相手の分析で優れている点、自分のペルソナでは見落としがちだった点]

4. 総合判断の比較:
   - 自分のトップ3アクション vs 相手のトップ3アクション
   - ペルソナの違いに起因する相違 vs データ解釈の相違（分類すること）
```

---

## 第2ラウンド: 反論・合意形成

第1ラウンドのレビュー結果を受けて、各エージェントが反論または同意を表明。

**出力形式**:
```
=== analyst-X（ペルソナ名） の第2ラウンド回答 ===

1. 受け入れる指摘:
   - [指摘内容と修正後の見解]
   - [ペルソナの範囲内でどこまで歩み寄れるか]

2. 反論する指摘:
   - [指摘内容と自分のペルソナに基づく反論の根拠]

3. 修正後の総合判断:
   - 最も改善効果の高いアクション（トップ3）
   - 合意度: [各アクションについて合意/部分合意/不合意]
   - ペルソナを超えた合意: [全ペルソナが一致した項目を強調]
```

---

## 合意形成ルール

- **全エージェント合意**: そのアクションを「合意度100%」としてレポートに記載
- **過半数合意**: 「合意度XX%」として記載。反対意見も併記
- **全エージェント不合意**: 各見解を併記し、ユーザーに判断を委ねる
