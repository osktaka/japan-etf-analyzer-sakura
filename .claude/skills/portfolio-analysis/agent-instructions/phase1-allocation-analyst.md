# Phase 1: allocation-analyst（アセットアロケーション分析）指示書

## 共通ルール

### 前提

- 作業ディレクトリ: `{WORK_DIR}`（メインエージェントから渡される）
- Docker内パス: `/app/{WORK_DIR}`

### データ受け渡しルール（共通原則）

- **入力**: `{WORK_DIR}/portfolio_data.json`（全収集データ）、`{WORK_DIR}/market_environment.md`（市場環境サマリー）、`{WORK_DIR}/trend_summary.md`（トレンドデータ、存在する場合のみ）
- **出力**: 分析結果を `{WORK_DIR}/` 配下の指定ファイルに保存（ファイル名は下記で定義）
- **メインへの戻り値**: 完了メッセージ1行のみ。データ全文やテーブル全体を返さないこと

### データ検証ルール（必須）

分析の前に、必ず `_metadata` セクションを確認し、以下を実行すること:

1. **フィールド名の確定**: `_metadata` に記載されたカラム名・perspective名を使用する。ハードコーディングしない。
2. **データ件数の確認**: `_metadata.{section}.count` が0でないことを確認する。
3. **スキップ前の原因調査**: データが空または取得できない場合、以下の順で原因を調査する:
   a. `_metadata` でデータ件数が0以上か確認 → 0以上なら「フィールド名の不一致」を疑う
   b. 実データの最初のレコードのキー一覧を出力して確認
   c. 正しいキー名で再取得を試みる
   d. それでもデータが取得できない場合のみ「データ不足」としてスキップ
4. **スキップ時の報告**: スキップする場合は、調査した内容（確認したキー名、件数等）を出力に含める
5. **`_data_status`の事前確認**: `_metadata._data_status` で自分が使うデータソースの取得状態を確認する。
   - `"error"` → そのデータを使う分析項目はスキップ（理由: 「取得失敗」+ `_data_status`のerror内容を転記）
   - `"empty"` → そのデータを使う分析項目はスキップ（理由: 「データ不足（空レスポンス）」）
   - `"ok"` → 通常通り分析を実施（ただし件数・期間の充足度も確認）

**注意**: 各データの存在確認は`portfolio_data.json`の該当セクションを実際に確認して判断すること（推測でスキップしない）。

### スキップ理由の記載ルール

出力ファイルに記載する際、理由を以下の3分類で明記すること:

- 「取得失敗（API/DBエラー）」: `_data_status` のstatusが "error" の場合
- 「データ不足（空レスポンス）」: `_data_status` のstatusが "empty" の場合
- 「データ不足（条件未充足）」: データは存在するが分析に必要な条件を満たさない場合（例: performance_cacheはあるが1yデータがない）

### 市場環境の活用（共通原則）

Phase 0aで収集した市場環境サマリー（`{WORK_DIR}/market_environment.md`）の情報も分析の判断材料に含めること。各アナリストの専門領域に関連する市場環境要因がある場合は、明示的に言及すること。具体的な活用例は以下で定義する。

### トレンドデータの活用（共通原則）

`{WORK_DIR}/trend_summary.md` が存在する場合、過去の分析結果との比較情報を分析に活用すること。存在しない場合（初回分析時等）はトレンドに関する言及をスキップし、通常通りの分析を行う。

**共通ルール**:
- 同じ指摘が過去N回連続している場合は「繰り返し指摘（N回連続）」と明記し、優先度を引き上げる
- メトリクスが改善/悪化トレンドにある場合は、その方向性を分析の判断に反映する
- 過去の提案が実行/未実行かを確認し、新規提案との整合性を確保する

## データ受け渡し

- **出力**: `{WORK_DIR}/allocation_analysis.md`
- **メインへの戻り値**: 「allocation-analyst分析完了」の1行のみ。分析結果全文を返さないこと。

## スキップ判断基準

- **現金比率の妥当性評価**: summaryデータにcash_balanceが含まれていない場合スキップ

**5銘柄未満時**: 項目A(地域別配分)/B(セクター別配分)/C(テーマ別配分)/F(集中度ヒートマップ)はスキップ。項目D(欠落アセットクラス)/E(現金比率)のみ実施する。スキップした項目にはスキップ理由を記載する。

### データ妥当性チェック（追加）
- `_data_status.summary` を先に確認し、"error" または "empty" の場合は現金比率分析をスキップ
- summaryが "ok" の場合のみ、`summary.data.cash_balance` の存在を確認して分析を実施

## 役割

地域・セクター・テーマ別の配分分析、欠落アセットクラスの特定

## 市場環境の活用

Phase 0aで収集した市場環境サマリー（`{WORK_DIR}/market_environment.md`）の情報も分析の判断材料に含めること。特に為替動向（円安/円高）が地域配分の評価に、政策動向（金融緩和/引き締め）がアセットクラス推奨に影響する場合は明示的に言及すること。
欠落アセット提案（項目D）では、市場環境の政策動向と保有銘柄の政策タグ（防衛関連/インフラ/半導体政策）を照合し、政策追い風セクターへのエクスポージャー有無にも言及すること。

## トレンドデータの活用

前述の共通ルール「トレンドデータの活用（共通原則）」を基本とする。特に以下の観点で活用すること:

- **構成変化の効果検証**: 過去の分析回からの銘柄入替・比率変更が、地域/セクター/テーマ別配分にどのような効果をもたらしたかを評価する。配分の改善/悪化トレンドを明示する
- **未実行アクションの蓄積度**: 過去に提案された配分改善アクション（欠落アセット追加、集中リスク緩和等）が未実行のまま蓄積している場合は「未実行提案（N回連続）」として優先度を引き上げる。蓄積が3回以上の場合は特に強調する
- **配分偏りの固定化検出**: 地域/セクター集中度が複数回にわたり同水準で推移している場合は「構造的偏り」として認識し、改善の緊急度を明示する

## 分析項目

### A. 地域別配分
タグ情報から地域別の評価額・比率を算出。

**出力形式**:
| 地域 | 評価額 | 比率 | 推奨比率 | 判定 |
|------|-------|------|---------|------|
| 国内 | 220万円 | 40% | 30-50% | 適正 |
| 米国 | 195万円 | 35% | 30-40% | 適正 |
| 先進国 | 83万円 | 15% | 10-20% | 適正 |
| 新興国 | 55万円 | 10% | 5-15% | 適正 |

### B. セクター別配分
タグ情報からセクター別の評価額・比率を算出。

**出力形式**:
| セクター | 評価額 | 比率 | 判定 |
|---------|-------|------|------|
| テクノロジー | 275万円 | 50% | 過度な集中 |
| 金融 | 110万円 | 20% | 適正 |
| ヘルスケア | 83万円 | 15% | 適正 |
| その他 | 83万円 | 15% | - |

**推奨**: テクノロジーの比率を40%以下に抑制。

### C. テーマ別配分
タグ情報からテーマ別の評価額・比率を算出。

**出力形式**:
| テーマ | 評価額 | 比率 |
|-------|-------|------|
| AI・半導体 | 165万円 | 30% |
| 高配当 | 110万円 | 20% |
| インデックス | 83万円 | 15% |
| ESG | 55万円 | 10% |
| その他 | 140万円 | 25% |

### D. 欠落アセットクラス
資産クラスタグから未保有の資産を特定。

**出力形式**:
```
保有資産クラス:
- 株式: 95%
- REIT: 5%

欠落資産クラス:
- 債券: 0%（推奨: 10-20%、安定性向上）
- コモディティ: 0%（推奨: 5-10%、インフレヘッジ）

推奨銘柄の選定:
- `recommendations.balance` から欠落資産クラスタグ（債券/コモディティ/REIT等）を持つ銘柄を抽出
- 該当なしの場合 → `recommendations.low-cost` も参照（長期保有前提のため低コスト優先）
- いずれにも該当なしの場合 → 一般的な代表銘柄を提示（例: 債券→2621, コモディティ→1540）
- 注意: おすすめAPIは大型指数連動型が上位固定のため、欠落クラスに該当する銘柄が上位に含まれない場合がある。その場合はフォールバック例を使用し、APIに該当なしの旨を記載する
```

**市場環境フィルタリング（必須）**:
欠落アセットを推奨する際、`{WORK_DIR}/market_environment.md` の「分析への示唆」セクションと照合すること:
- 推奨する資産クラスに逆風となる市場環境が示唆されている場合、リスク付記を必須とする
  （例: 金利上昇局面での長期債推奨→「現在金利上昇局面のため短期的に価格下落リスクあり」と付記）
- 逆風が明確な場合は「現時点では見送り推奨」と判定可能
- フィルタ後も候補が不足する場合は「市場環境リスク付きで提案」と明記

### E. 現金比率の妥当性評価
summaryのcash_balanceとtotal_valueから現金比率を算出、適正比率と比較。

**計算式**:
```
現金残高 = summary.data.cash_balance
現金比率 = 現金残高 / (summary.data.total_value + 現金残高)
```

**出力形式**:
```
現金残高: 50万円
現金比率: 8.3%（推奨: 5-10%）
判定: 適正
```

**現金のディフェンシブ機能評価（必須）**:

現金比率に応じた段階的評価:
- 10%未満: ディフェンシブ機能不足。買い増し余力・緊急対応力が限定的
- 10-20%: 基本的な防御力あり。買い増し余力を確保
- 20%超: 十分なディフェンシブ機能あり。追加の低リターン資産（債券・REIT等）は優先度低い

判定ルール:
- 現金比率が20%を超える場合、項目Dの欠落アセット提案で債券・REIT等の低リターン資産は「現金で十分なディフェンシブ機能があるため、追加は優先度低い」と判定すること
- ただし、現金以外に分散効果（株式との低相関）を求める場合は、市場環境フィルタを通した上で提案可能

### F. 集中度ヒートマップ
地域×セクターのマトリクスで集中度を可視化。

**出力形式（テキスト表現）**:
```
地域×セクター集中度:

        テック  金融  ヘルスケア  その他
国内      5%   15%      5%      15%
米国     35%    5%      5%       5%
先進国   10%    -       5%        -
新興国    -     -        -       10%

リスク集中: 米国×テック（35%）← 要注意
```
