# Phase 2: クロスレビュー観点（ノーマルモード）

> このファイルは統合エージェント（phase34-integration.md）が参照するクロスレビュー観点です。
> ノーマルモードの場合、統合エージェントが以下の観点で分析結果間の矛盾・整合性を検証し、レポートのセクション9に記載します。
> **追加データ**: `00_portfolio_data.json` の `compare_performance` と `compare_scores` があれば、分析間の矛盾検証の根拠として参照すること。
> **外部検証データ**: `{WORK_DIR}/20_candidate_verification.md` が存在する場合は、クロスレビュー時に参照すること。入替提案の妥当性を外部検証結果と照合して確認し、「要再検討」「非推奨」と判定された候補については検証結果の根拠をレビューに反映する。

## quant-analyst → score-analyst の結果をレビュー

**レビュー観点**:

1. **スコア評価と定量指標（シャープレシオ）に矛盾はないか**
   - 例: スコア高いがシャープレシオ低い銘柄 → 品質は高いがリターン/リスクが悪い
   - 例: スコア低いがシャープレシオ高い銘柄 → コスト・配当は劣るが効率的

2. **代替銘柄提案は定量的に合理的か**
   - 提案銘柄のシャープレシオを確認
   - 相関係数を確認（入れ替えで分散効果が改善するか）

3. **失速銘柄のリスクはボラティリティデータと整合的か**
   - 失速銘柄のボラティリティが高い場合、リスク増大を警告
   - ボラティリティが低い場合、一時的な調整の可能性

**出力形式**:
```
=== quant-analystによるスコア分析レビュー ===

1. スコアとシャープレシオの整合性:
   - 9012 DEF ETF: スコア58点（低）、シャープレシオ0.15（非効率）
     → 一致: 品質・効率ともに劣る。入れ替え推奨。
   - 1234 ABC ETF: スコア65点（中）、シャープレシオ1.25（優秀）
     → 乖離: スコアは平均的だがリスク調整後リターンは優秀。
       コスト・配当は劣るが効率的。保有継続推奨。

2. 代替銘柄提案の検証:
   - 提案: 9012 → 1357
     - 1357のシャープレシオ: 0.95（良好）
     - 相関係数: 0.65（中程度）
     - 評価: 定量的に合理的。入れ替え支持。

3. 失速銘柄のリスク評価:
   - 9012 DEF ETF: 下降中、ボラティリティ18%（高）
     → リスク増大。早期の入れ替えを推奨。
   - 3456 GHI ETF: 下降中、ボラティリティ8%（低）
     → 一時的な調整の可能性。1-2ヶ月様子見も選択肢。
```

## score-analyst → quant-analyst の結果をレビュー

**レビュー観点**:

1. **シャープレシオとスコアの乖離がある銘柄の解釈**
   - スコア低いがシャープ高い → 品質vs効率のトレードオフ
   - スコア高いがシャープ低い → 高品質だが市場環境に合わない

2. **相関分析はタグ分類と整合的か**
   - 高相関ペアは同一地域/セクターか
   - 低相関ペアは異なる地域/セクターか
   - 「高リスク連動型」に分類されたペアはSELL推奨ではなく、シャープレシオとコスト効率から保有継続の根拠を検証すること

3. **定量分析で見落としているスコア上の問題はないか**
   - シャープレシオは高いが、信託報酬が高い
   - シャープレシオは高いが、純資産が小さい（流動性リスク）

**出力形式**:
```
=== score-analystによる定量分析レビュー ===

1. シャープレシオとスコアの乖離分析:
   - 1234 ABC ETF: スコア65点、シャープ1.25
     → 解釈: コスト効率45点（信託報酬0.55%）が足を引っ張るが、
       リターンスコア85点（1年リターン12.5%）で挽回。
       短期的には保有継続、長期的には低コスト銘柄への入れ替え検討。

2. 相関分析とタグ分類の整合性:
   - 高相関ペア（1234 と 5678、相関0.85）
     → タグ: ともに「米国」「テクノロジー」→ 整合的
   - 低相関ペア（1234 と 7890、相関0.12）
     → タグ: 1234「米国・テック」、7890「新興国・債券」→ 整合的

3. 見落としリスク:
   - 5678 XYZ ETF: シャープ0.95（良好）だが、
     - 純資産50億円（規模信頼性スコア55点、小規模）
     - 流動性リスクあり。大口売却時にスリッページの可能性。
     → 推奨: 純資産100億円以上の銘柄への入れ替えを検討。
```

## 3分析の見解が競合する場合のアクション決定ルール

1. **安全性（最優先）**: quantとscoreの両方がSELL/REDUCEを示す → 即時SELL/REDUCE
2. **リスク調整後リターン（主目標）**: 上記以外の競合 → 定量的根拠が最も具体的な分析の結論を採用
3. **分散構造（制約条件）**: allocationのみが異なる場合 → 注記付きで採用

### 競合解決の出力例

以下は、quantがSELL推奨、scoreがHOLD推奨、allocationがREDUCE推奨の場合の統合例:

```
銘柄1489:
- quant: SELL（シャープレシオ-0.15、最大DD -28%）
- score: HOLD（総合スコア62点、中位）
- allocation: REDUCE（セクター過集中15%超）
→ 統合判断: **SELL**（安全性ルール適用: quantがSELL + allocationがREDUCEでリスク裏付けあり。scoreのHOLD判定はリスク指標より優先度が低い）
```

## 購入推奨の妥当性チェック（quant/score/allocation 横断）

BUY/ADD_CLASS候補について、以下を横断的に検証する:

1. **品質ゲート通過の確認**: 候補にタグ重複度・スコア・市場環境整合性の検証結果が記載されているか。記載なしの場合→「品質ゲート未通過」と警告
2. **市場環境との整合性**: 候補のタグと0a_market_environmentの間に構造的矛盾がないか（Phase 1の品質ゲートと独立した二重チェック）
3. **既保有銘柄との役割重複**: 候補が既保有銘柄と同じ地域×セクターの組み合わせでないか。重複する場合→「既保有XXXXと役割重複、追加の分散効果が不明確」と警告

**出力形式**:
```
=== 購入推奨の妥当性チェック ===

1. 品質ゲート通過: 全候補通過 / 未通過あり（詳細）
2. 市場環境との整合性: 矛盾なし / 矛盾あり（詳細）
3. 既保有との役割重複: なし / あり（詳細）
```
