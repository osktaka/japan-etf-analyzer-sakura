# Phase 3: クロスレビュー結果の統合ガイド（議論重視モード）

> このファイルは、Phase 3で独立エージェントが実施したクロスレビュー結果を統合する際に、統合エージェント（phase34-integration.md）が参照するガイドです。
> 独立エージェントが2ラウンドのクロスレビューを実施し、その結果ファイル（計6ファイル）を元に、統合エージェントがセクション9を構成します。
> **追加データ**: `portfolio_data.json` の `compare_performance` と `compare_scores` があれば、ペルソナ間の見解相違を検証する際の客観的根拠として参照すること。

## 統合手順

以下の手順で、6ファイルの内容をレポートのセクション9に統合する。

### 手順1: 対立点の抽出（→ セクション9.1）

Round 1ファイル（crossreview_round1_a/b/c.md）から、各ペルソナ間の見解の相違点を抽出し、テーブル化する。

- 各レビューの「1. 見解の相違」「4. 総合判断の比較」から対立点を特定
- 「ペルソナの違いに起因する相違」と「データ解釈の相違」を分類

### 手順2: 対立軸ごとの経緯要約（→ セクション9.2）

対立軸（A↔B、A↔C、B↔C）ごとに、Round 1での指摘とRound 2での応答を時系列で要約する。

- Round 1: 何を指摘したか
- Round 2: 指摘を受け入れたか、反論したか
- 最終的にどこまで歩み寄ったか

### 手順3: 合意形成結果の抽出（→ セクション9.3）

Round 2ファイル（crossreview_round2_a/b/c.md）から、各アクションの合意状況を抽出し、テーブル化する。

- 「3. 修正後の総合判断」の合意度を集約
- 各アクションについて合意形成ルール（後述）に基づき最終判定を行う

### 手順4: 少数派意見の抽出（→ セクション9.4）

合意度が67%以下のアクションについて、少数派意見の記載ルール（後述）に従い記載する。

## フォールバック

独立エージェントの実行結果が一部欠損している場合、以下のルールで対応する。

| 欠損状況 | 対応 |
|---------|------|
| 6ファイル中1-2ファイル欠損 | 存在するファイルのみで統合を構成する。欠損ペルソナの見解は「未取得」と記載 |
| 3ファイル以上欠損 | 統合エージェント内でクロスレビューをシミュレートするフォールバックに切り替える（従来方式） |

## 合意形成ルール

- **全エージェント合意**: そのアクションを「合意度: 100%」としてレポートに記載
- **過半数合意（2/3）**: 「合意度: 67%」として記載。反対意見も併記
- **全エージェント不合意**: 「合意度: 見解分かれる」として各見解を併記し、ユーザーに判断を委ねる

**デッドロック仲裁ルール**（全ペルソナ不合意時に適用）:
1. 以下の共通優先順位に照らし、上位の優先度に関する主張を優先する
   - 安全性（絶対条件） > リスク調整後リターン（主目標） > 分散・構造の健全性（制約条件）
2. 同一優先度内では、定量データの根拠が最も具体的な意見を採用する
3. 上記で解決しない場合のみ、読者に判断を委ねる旨を記載する

**現実性チェックルール（全ペルソナ合意100%の提案に適用）**:

全ペルソナが合意した提案であっても、以下に該当する場合は「合意度100%（現実性注釈あり）」と表記し、注釈を付記すること:

1. **理論的最悪シナリオ由来の提案**: ストレスシナリオの発生確率「低」に基づく提案には「発生確率が低いシナリオに基づく提案。優先度は市場環境次第」と付記
2. **市場環境との整合性が未検証の提案**: Phase 0aの市場環境調査と照合されていない提案には「市場環境との整合性を確認すること」と付記

**適用対象外（現実性チェック不要）**:
- データに基づく客観的判定（現金評価、スコア分析結果等）
- 過去実績データから直接導かれる提案（シャープレシオ、相関分析等）
- 発生確率「中」以上のシナリオに基づく提案

## 少数派意見の記載ルール（必須）

合意度が67%以下のアクションについて、レポートのセクション9.4に以下を必ず記載すること:

1. **反対ペルソナの特定**: どのペルソナが反対/留保したか
2. **反対理由**: データに基づく具体的根拠（1-2文）
3. **条件付き合意**: 「○○の条件が満たされれば賛成に転じる」等の条件を明記（該当する場合）

少数派意見は単なる「併記」ではなく、読者が意思決定する際の重要な判断材料として扱う。

## レポート記述ルール（debateモード固有）

以下のルールは、debateモード時にレポートを記述する際に適用する。

### 合意度の付記ルール

debateモードの場合、以下のセクションに `【合意度: 100% / 67% / 見解分かれる】` を付記すること:
- エグゼクティブサマリー
- セクション9（クロスレビュー）
- セクション10（最適化提案）
- セクション12（アクションアイテム）

### セクション9: クロスレビュー記載ルール

Phase 3で独立エージェントが実施したクロスレビュー結果（6ファイル）を統合し、9.1-9.4の構造で記載（report-guide.mdのdebateモード用テンプレートに従う）。
- 9.1: 主要対立点を一覧テーブルで俯瞰
- 9.2: 対立軸ごとに第1ラウンド→第2ラウンドの経緯を簡潔に記載
- 9.3: 最終的な合意度をテーブルで集計
- 9.4: 少数派意見を独立セクションとして記録（上記「少数派意見の記載ルール」に従う）

合意度の付記例:
- 「【合意度: 100%】海外資産追加（米国ETF 30%目標）。シャープレシオ改善と地域分散の両面で3ペルソナが一致」
- 「【合意度: 67%】現金比率の5%削減。積極派と異論派は支持、堅実派は市場環境の不透明さから留保 → 段階的削減で対応」

### セクション10: 合意度と定量目標の記載ルール

**合意度の記載**: 各提案に合意度を明記する。
- 合意度100%: 「quant/score両エージェント一致」等の補足を付ける
- 合意度80%等: 少数派の意見も補足する（例: 「score推奨、quantは1-2ヶ月様子見も選択肢と指摘」）

**定量目標のdebateモード分岐ルール**:
- 合意度100%=確定値で記載、67%=範囲で記載（例: 0.85-0.95）、見解分かれる=各ペルソナの目標値を併記
