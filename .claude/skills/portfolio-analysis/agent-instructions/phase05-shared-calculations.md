# Phase 0.5: 共通定量計算（debateモード限定）指示書

## 目的

debateモードのPhase 1で3ペルソナエージェントが重複して行っていた決定論的計算を、1回で済ませる。
本エージェントは**計算のみ**を行い、解釈・判断は一切含めない。

## エージェント種別

- subagent_type: general-purpose
- model: sonnet

## データ受け渡し

- **入力**: `{WORK_DIR}/portfolio_data.json`
- **出力**: `{WORK_DIR}/shared_calculations.md`
- **メインへの戻り値**: 「共通定量計算完了」の1行のみ。データ全文やテーブル全体を返さないこと

---

## 計算ロジック参照元

各計算項目の具体的な計算方法・出力形式は、以下のファイルを確認すること:

- `{skill_dir}/agent-instructions/phase1-quant-analyst.md` — 項目1-4の計算式・出力テーブル形式
- `{skill_dir}/agent-instructions/phase1-score-analyst.md` — 項目5-6の計算式・出力テーブル形式

---

## 計算対象（項目1-6）

### 1. シャープレシオ分析・リスク調整後ランキング

- `portfolio_data.json` の `performance_cache` から各銘柄の1年リターン・ボラティリティを取得
- `{WORK_DIR}/market_environment.md` の「## リスクフリーレート」セクションから日本国債10年利回りを取得する。該当セクションが存在しない場合はフォールバック値 **0.5%** を使用
- 計算式: `(年率リターン - リスクフリーレート) / 年率ボラティリティ`
- 使用したリスクフリーレートの値と出典を出力の冒頭に明記する
- 全銘柄のシャープレシオをランキング表として出力
- 出力形式は `phase1-quant-analyst.md` の項目A・Eに準拠

### 2. 相関分析

- `portfolio_data.json` の `price_data` から月初価格を抽出し、月次リターンを計算
- 全ペアのピアソン相関係数を算出
- 高相関ペア（>0.7）と低相関ペア（<0.3）を抽出
- 出力形式は `phase1-quant-analyst.md` の項目Bに準拠

### 3. 最大ドローダウン

- `portfolio_data.json` の `valuation_history` から累積最大値を計算
- ピーク日・ボトム日・最大ドローダウン率・回復期間を算出
- 出力形式は `phase1-quant-analyst.md` の項目Cに準拠

### 4. ストレスシナリオ基礎数値

- 基礎シナリオ（米国テック-20%、全世界株式-15%、円高進行）の影響額を計算
- 各シナリオについて: 対象銘柄・評価額変化・ポートフォリオ影響率を算出
- **追加シナリオの提案はPhase 1のペルソナエージェントが行う**（ここでは基礎シナリオの数値計算のみ）
- 出力形式は `phase1-quant-analyst.md` の項目Dのテーブル形式に準拠（発生確率・市場環境根拠の列は空欄とする）

### 5. 加重平均スコア表

- `portfolio_data.json` の `score_cache` と保有比率から、5軸x6視点の加重平均スコアを計算
- 計算式: `ポートフォリオスコア（軸X、視点Y） = Sum(銘柄iのスコア x 銘柄iの保有比率)`
- 最弱軸・最強軸を特定し、差分を算出
- 出力形式は `phase1-score-analyst.md` の項目Aに準拠

### 6. モメンタム分布

- `portfolio_data.json` の `etf_data` から各銘柄の `momentum_label` を取得
- ラベル別の銘柄数・保有比率を集計
- 下降中/下降加速の銘柄リストを出力
- 出力形式は `phase1-score-analyst.md` の項目Bの分布部分に準拠（要因分析・判定はペルソナ側で行う）

## フォールバック

`portfolio_data.json` の特定データが欠落している場合（`_data_status` のstatusが "error" または "empty"、あるいは必要なフィールドが存在しない場合）:

- その項目のセクションに「**データ不足のためスキップ**（理由: [具体的な欠落データ]）」と記載する
- Phase 1のペルソナエージェントが従来通り自身で計算・判断できるよう、スキップ理由を明確にする

---

## 出力形式ルール

- 各項目はMarkdownのセクション（`##`）で区切る
- テーブル形式で数値を整理する
- **解釈や判断は一切含めない**（純粋な計算結果のみ）
- 例: 「シャープレシオが低いため見直し推奨」のような判定文は記載しない
- 例: 「高相関ペアがリスク集中を示唆」のような解釈も記載しない
