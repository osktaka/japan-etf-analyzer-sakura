# Phase 0.5: 共通定量計算（debateモード限定）指示書

## 目的

debateモードのPhase 1で5ペルソナエージェントが重複して行っていた決定論的計算を、1回で済ませる。
本エージェントは**計算のみ**を行い、解釈・判断は一切含めない。

## エージェント種別

- subagent_type: general-purpose
- model: sonnet

## データ受け渡し

- **入力**: `{WORK_DIR}/00_portfolio_data.json`
- **出力**: `{WORK_DIR}/05_shared_calculations.md`
- **メインへの戻り値**: 「共通定量計算完了」の1行のみ。データ全文やテーブル全体を返さないこと

## 計算対象（項目1-6）

### 1. シャープレシオ分析・リスク調整後ランキング

- `00_portfolio_data.json` の `performance_cache` から各銘柄の1年リターン・ボラティリティを取得
- `{WORK_DIR}/0a_market_environment.md` の「## リスクフリーレート」セクションから日本国債10年利回りを取得する。該当セクションが存在しない場合はフォールバック値 **0.5%** を使用。なお、**Phase 0.5はPhase 0完了時点で起動可能（Phase 0a完了を待たない）**。`0a_market_environment.md` が未生成の場合、リスクフリーレートはフォールバック値 **0.5%** を使用する
- 計算式: `(年率リターン - リスクフリーレート) / 年率ボラティリティ`
- 使用したリスクフリーレートの値と出典を出力の冒頭に明記する
- 全銘柄のシャープレシオをランキング表として出力
- 出力形式は `phase1-quant-analyst.md` の項目A・Eに準拠

### 2. 相関分析

- `00_portfolio_data.json` の `price_data` から月初価格を抽出し、月次リターンを計算
- 全ペアのピアソン相関係数を算出
- 高相関ペア（>0.7）と低相関ペア（<0.3）を抽出
- 出力形式は `phase1-quant-analyst.md` の項目Bに準拠

### 3. 最大ドローダウン

- `00_portfolio_data.json` の `valuation_history` から累積最大値を計算
- ピーク日・ボトム日・最大ドローダウン率・回復期間を算出
- 出力形式は `phase1-quant-analyst.md` の項目Cに準拠

### 4. ストレスシナリオ基礎数値

- 基礎シナリオ（米国テック-20%、全世界株式-15%、円高進行）の影響額を計算
- 各シナリオについて: 対象銘柄・評価額変化・ポートフォリオ影響率を算出
- **追加シナリオの提案はPhase 1のペルソナエージェントが行う**（ここでは基礎シナリオの数値計算のみ）
- Phase 0.5では発生確率の判定は行わない（Phase 1のペルソナエージェントが判定する）
- ただし、`0a_market_environment.md` の「分析への示唆」から基礎シナリオの発生条件に関連する記述があれば、テーブル下に「市場環境メモ」として箇条書きで転記する（判定はしない）
- 出力形式は `phase1-quant-analyst.md` の項目Dのテーブル形式に準拠（発生確率・市場環境根拠の列は空欄とする）

### 5. 加重平均スコア表

2つのテーブルを出力する:

**保有比率の算出（共通）**:
- `holdings` の各銘柄の `current_value` からポートフォリオ総額を算出
- 保有比率 = `current_value / 総額`（**小数値 0.0〜1.0** で扱う。例: 32.2% → 0.322）
- **絶対禁止**: パーセンテージ値（32.2等）をそのまま掛け算しないこと。必ず100で割って小数に変換する

**テーブル1: 5軸加重平均**（視点に依存しない）
- `00_portfolio_data.json` の `score_cache` と保有比率から、5軸（配当力・コスト効率・規模信頼性・売買品質・リターン）の加重平均を計算
- 計算式: `Σ(銘柄iの軸Xスコア × 銘柄iの保有比率)` ※保有比率は小数（0-1）、スコアは0-100点
- **5軸すべてのスコアが揃っていることを確認する**。score_cacheの各銘柄レコードから5軸（dividend_power, cost_efficiency, scale_reliability, trading_quality, return_performance）を取得し、欠落している軸がある場合はスキップせず、score_cacheの別のperspectiveレコードや`_metadata.score_cache.axes`を参照して取得する（5軸スコアは視点によらず同一値のため）
- 最弱軸・最強軸を特定し、差分を算出

**テーブル2: 視点別総合スコア加重平均**（視点ごとに異なる）
- `score_cache` の各銘柄の `total_score` を視点別に保有比率で加重平均
- 計算式: `Σ(銘柄iのtotal_score(視点Y) × 銘柄iの保有比率)` ※保有比率は小数（0-1）
- 6視点（balance, dividend, growth, low-cost, stability, volume）それぞれの値を出力

**バリデーション（必須）**:
- 計算結果が **0〜100の範囲** に収まることを確認する
- 範囲外の場合は保有比率のスケール誤り（パーセンテージと小数の混同）を疑い、計算を見直す

- 出力形式は `phase1-score-analyst.md` の項目Aに準拠

### 6. モメンタム分布

- `00_portfolio_data.json` の `etf_data` から各銘柄の `momentum_label` を取得
- ラベル別の銘柄数・保有比率を集計
- 下降中/下降加速の銘柄リストを出力
- 出力形式は `phase1-score-analyst.md` の項目Bの分布部分に準拠（要因分析・判定はペルソナ側で行う）

### 7. VaR/CVaR分析

- 相関分析（項目2）で算出した月次リターンデータを再利用
- 各銘柄の保有比率（**小数 0-1**。項目5と同じ算出方法）で加重し、ポートフォリオ月次リターンを算出
- VaR(95%) = ポートフォリオ月次リターンの5パーセンタイル
- CVaR(95%) = VaR以下の月次リターンの平均値
- 想定損失額 = VaR（またはCVaR）× ポートフォリオ総評価額
- 出力形式は `phase1-quant-analyst.md` の項目Fに準拠
- 各計算結果セクションの冒頭に `<!-- DO_NOT_RECALCULATE: var_cvar -->` マーカーを付与する

**スキップ条件（4段階）**:
- 月次リターンデータが6ヶ月未満: スキップ（「データ不足のためスキップ」と記載）
- 6-11ヶ月: 算出するが「参考値（データ点数: N点、信頼度: 低）」と注記
- 12-23ヶ月: 算出（「データ点数: N点、信頼度: 中」と注記）
- 24ヶ月以上: 算出（「データ点数: N点、信頼度: 高」と注記）

## 出力形式ルール

- 各項目はMarkdownのセクション（`##`）で区切る
- テーブル形式で数値を整理する
- **解釈や判断は一切含めない**（純粋な計算結果のみ）
- 例: 「シャープレシオが低いため見直し推奨」のような判定文は記載しない
- 例: 「高相関ペアがリスク集中を示唆」のような解釈も記載しない
- 各計算結果セクションの冒頭に項目別識別子付きの `<!-- DO_NOT_RECALCULATE: {識別子} -->` マーカーを付与する
  - 項目1: `<!-- DO_NOT_RECALCULATE: sharpe_ratio -->`
  - 項目2: `<!-- DO_NOT_RECALCULATE: correlation -->`
  - 項目3: `<!-- DO_NOT_RECALCULATE: max_drawdown -->`
  - 項目4: `<!-- DO_NOT_RECALCULATE: stress_scenario -->`
  - 項目5: `<!-- DO_NOT_RECALCULATE: weighted_score -->`
  - 項目6: `<!-- DO_NOT_RECALCULATE: momentum -->`
  - 項目7: `<!-- DO_NOT_RECALCULATE: var_cvar -->`
- Phase 1のペルソナエージェントは、このマーカーがある項目の数値を変更してはならない
- フォーマット例:
  ```
  ## 1. シャープレシオ分析・リスク調整後ランキング
  <!-- DO_NOT_RECALCULATE: sharpe_ratio -->
  使用リスクフリーレート: 1.32%（日本国債10年利回り）

  | 銘柄コード | 銘柄名 | 1年リターン | ボラティリティ | シャープレシオ | ランク |
  ```

## ペルソナ別活用パラメータの基礎数値（analyst-D/E向け共通計算）

以下の基礎数値を `05_shared_calculations.md` 内の末尾セクションに追加出力する。解釈はPhase 1のペルソナエージェントが独自に行う。

### analyst-D（マクロ戦略派）向け: マクロストレスシナリオ基礎数値

項目4の基礎シナリオに加え、以下のマクロシナリオの数値を計算して出力する:

| マクロシナリオ | 仮定 | 計算対象 |
|------------|------|--------|
| 金利急騰シナリオ | 金利+2%（全銘柄のデュレーション感応度を0.5として概算） | 各銘柄の評価額変化額・ポートフォリオ影響率 |
| 為替急変シナリオ（円高） | 円高+20%（外国資産構成比率を用いて概算） | 各銘柄の評価額変化額・ポートフォリオ影響率 |
| 為替急変シナリオ（円安） | 円安-20%（外国資産構成比率を用いて概算） | 各銘柄の評価額変化額・ポートフォリオ影響率 |

- 各銘柄の外国資産比率が `etf_data` のタグやカテゴリから推定可能な場合は推定値を使用。不明の場合は「外国資産比率: 不明（平均値で代替）」と注記する
- 発生確率・市場環境解釈はanalyst-Dが独自に判定する（ここでは数値のみ）
- 出力識別子: `<!-- DO_NOT_RECALCULATE: macro_stress -->`

### analyst-E（長期構造派）向け: 信託報酬の長期複利効果テーブル

保有銘柄の信託報酬差異を長期複利効果で数値化した基礎テーブルを出力する:

- `etf_data` の各銘柄の信託報酬（expense_ratio）を取得
- 最低コスト銘柄を基準として、各銘柄との信託報酬差分を計算
- 差分が長期複利で生む累積損失（概算）をテーブル化:

| 銘柄コード | 銘柄名 | 信託報酬 | 最低コストとの差分 | 5年複利影響 | 10年複利影響 | 20年複利影響 |
|---------|------|---------|----------------|-----------|------------|------------|
| ...     | ...  | 0.XX%   | +0.YY%         | -YY%      | -ZZ%       | -WW%       |

- 計算式: `(1 - 差分/100)^N - 1`（Nは期間年数）
- **解釈（どのETFのコストが問題か等）はanalyst-Eが独自に判断する**
- このセクションには数値テーブルのみを出力し、判定文・推奨文は記載しない
- 信託報酬データが取得できない銘柄は「信託報酬: 不明」と記載してスキップ
- 出力識別子: `<!-- DO_NOT_RECALCULATE: expense_ratio_effect -->`
