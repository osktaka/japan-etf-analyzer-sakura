### 13.2 用語解説

| 用語 | 説明 |
|------|------|
| シャープレシオ | リスク1単位あたりのリターンを示す指標。高いほど効率的な運用 |
| VaR（バリュー・アット・リスク） | 一定期間内に一定の確率で発生しうる最大損失額の推定値 |
| CVaR（条件付きVaR） | VaRを超える損失が発生した場合の平均損失額。テールリスクの指標 |
| 最大ドローダウン | 資産価値がピークからボトムまで最大何%下落したかを示す指標 |
| 相関係数 | 2つの銘柄の値動きの連動性を示す指標。-1〜+1の範囲で、0に近いほど分散効果が高い |
| ボラティリティ | 価格変動の大きさを示す指標。高いほどリスクが大きい |
| 信託報酬 | ETFの運用管理にかかる年間手数料。保有中に自動的に差し引かれる |
| モメンタム | 価格の勢い・トレンドの方向性を示す指標。上昇加速〜下降加速の5段階で評価 |
