- 合計 70〜100 行程度（「ひと目で読める」量を厳守）

【構成と行数目安】
冒頭（1行）: ポートフォリオの核心を1文で（例: 「配当力強化が急務、象限4での守りを最優先」）

1. 基本情報（3〜4行）
   - 分析日・総資産・前回比・保有銘柄数・現金比率

2. 最優先アクション（6〜9行）
   - レポートの「アクションアイテム」または「最優先アクション」セクションから上位3件
   - 各アクションに方向性一致度・トリガー数値を付記（例: 「1329全量縮小（方向性一致度 5/5、39,263円確保）」）

3. 主要リスクとモメンタム（8〜12行）
   - 下降・失速銘柄比率（モメンタムセクションから）
   - 高相関ペア（相関分析セクションから、0.75以上のペアのみ）
   - 最大ドローダウン・VaR(95%)
   - 現在の象限（スタグフレーション/リスクオン等）と根拠1行

4. ポートフォリオ総合評価（5〜7行）
   - 総合スコア（点数）・シャープレシオ
   - 5軸スコア（最弱軸・最強軸のみ、他は省略）
   - アセット配分（国内/海外/現金比率）

5. 市場環境（2〜3行）
   - レポートのセクション0から主要指標と示唆を1〜2文で

6. 象限脱出・環境変化トリガー（3〜5行）
   - 現在の象限とその脱出条件（レポートのまとめ・クロスレビューセクションから）
   - 脱出条件が不明な場合は省略可

7. 前回比較（3〜5行、トレンドセクションがある場合のみ）
   - 総資産・スコア・主要リスク指標の前回比

【スタイル】
- 箇条書き中心、数値は必ず記載
- 解説・分析は不要、ファクトと判断のみ
- Markdown 見出し（##）を各セクションに使用
- 省略不可の情報: アクションのトリガー数値・方向性一致度、相関係数、モメンタム比率
